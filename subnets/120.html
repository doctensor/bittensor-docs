What it is

Affine pays miners for improving one shared language model that reasons through math-style tasks. Since 2026-11-14 each round trains up to six uploaded files, tests every result on 2,000 public tasks, and crowns at most one winner, who is paid with the last nine winners.

How it works

Miners

No mining client: a hotkey uploads one JSON file of prompts, its own outputs and rewards (up to 250 prompts, 2,000 rollouts). One registration buys one turn, ever. Rounds take up to 6 files in registration order; 235 seats wait.

Validators

Only the owner's validator sets weights (one permit, UID 0), hourly. Each round trains one LoRA per file and scores it against the unchanged head: a file is eligible if its gain is above 1 standard error (z above 1) and its token-cap hit rate stays within 33% (or the head's plus 2 points); the eligible file with the largest gain wins.

Incentive

The last 10 distinct winners ("kings") split the weight equally while their hotkey stays registered; nothing burns. On 2026-11-14 the chain weights named those 10; incentive still paid dropped king 851, not yet new king 957.

Roles and requirements

Miner Medium barrier

Uploads one batch file; paid only if its single turn passes the held-out test.

  • The team trains each file on its own 8-GPU box; a local tool previews the result. A charged hotkey never enters again; an invalid file is skipped, not charged.
  • At the last file check (18:14 UTC) 8 of the 235 waiting seats had a valid file (185 not judged, 42 invalid).

Validator High barrier

Sets the weights; in practice only the owner's validator does.

  • Trainer, judge, payout and the hourly weight writer are public on the v2 branch; every task is public, so no secret seed remains.

Getting started

  1. Read the current guide (affine.io llms.txt) and the v2 code (branch v2 of the repo).
  2. Register a hotkey with the burn (about 1.41 TAO on 2026-11-14), then publish the one-time activation with the repo's command.
  3. Build one batch file in the published format; pre-check it with the local tool.
  4. Upload it and run the guide's check command until it says valid; 235 seats wait.

Caveats

  • v2 is one day old: 5 of 10 rounds crowned no winner, and rules or code may change again.
  • The team site is the only source for round scores; the chain confirms who is paid, not why.
  • Team posts after 2026-11-01 22:00 UTC were not read (archive down); repo commit messages carry the owner's later decisions.
