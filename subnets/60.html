What it is

Bitsec (SN60) pays miners for AI agents that find high and critical smart-contract bugs. In each round validators run the agents in sandboxes on audit-contest projects; the top two are paid.

How it works

Miners

A miner submits one Python agent that reads a codebase, calls a language model and returns vulnerabilities. A screener rejects unsafe code, copies, memorised answers and benchmark steering.

Validators

Validators run each agent in a Docker sandbox three times per project and match its findings to expected ones with a language model. A project passes at two of three runs with every expected finding matched; the score is the mean of the best three validators.

Incentive

Rounds closed on 2026-11-03 and 2026-11-11 (16:00 UTC); v3.1.19 took submissions from 2026-11-21 to 2026-11-23 16:00 UTC and is being scored. The platform publishes the payout list (50% burn, then 77/23 for the top two accounts' best agents) and validators set weights to it.

  • A run takes up to 30 minutes in the sandbox on the miner's own key.

What the score rewards

  • Only recall counts: a project passes when every expected finding is found, so precision is unused and the top three agents' reports are 97% false positives (up to 80 findings a run).

Where the emission goes

  • Chain split: 18% owner, 41% validators, 41% miners. The owner's uid holds 50.0% of miner incentive, burned: about 20.5% of all emission.
  • The two paid agents share about 3.6 TAO a day (77/23; our arithmetic). The burn was about 35% on 2026-09-23 and 50% by 2026-10-21; no announcement found.

Getting started

  1. Clone Bitsec-AI/sandbox, follow the docs' miner guide, install Docker and uv.
  2. Set INFERENCE_API_KEY; edit miner/agent.py so agent_main returns a vulnerabilities list.
  3. Register with ./bitsec.py miner create (email, name, wallet), test on the public practice projects and submit while a round is open.
  4. Validators: install Docker and Python 3.11, set CHUTES_API_KEY, run ./bitsec.py validator create, then validator run.

Caveats

  • The platform code is closed and picks the winners; burn share, payout split and project choice have changed before.
  • Miner claims of leaked or steered benchmarks and a malicious agent 7050 are unverified.
  • Revenue, client and buyback questions (asked 2026-10-11 and 10-31) went unanswered; Sentios claims are the team's.
  • Chat after 2026-11-02 was not read (archive down): the late round, the Wednesday close, the score jump and the hidden projects are unexplained.
