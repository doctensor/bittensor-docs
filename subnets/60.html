What it is

Bitsec (SN60) pays miners for AI agents that find high and critical bugs in smart-contract code. Each week validators run private agents in sandboxes on audit-contest projects and the top two are paid. The team also sells Sentios, a security product.

How it works

Miners

A miner submits one Python agent that reads a codebase, calls a language model and returns vulnerabilities. A screener rejects unsafe code, copies, memorised answers and steering toward known benchmark solutions.

Validators

Validators pull jobs from the platform, run each agent in a Docker sandbox on every round project and match its findings to the expected ones with a language model (DeepSeek V3.2 since 2026-10-26). A project passes only if every expected finding is matched; the platform combines runs and validators (docs: three runs, three validators).

Incentive

Rounds close on Mondays at about 15:00 UTC (next: 2026-11-02). The platform publishes the payout list (50% burn, then 77/23 for the top two agents) and validators set weights to it; ties go to the agent with more confirmed vulnerabilities.

Roles and requirements

Miner Medium barrier

Builds an AI agent that finds high and critical bugs; paid only if it ranks in the top two.

  • The agent must expose agent_main; the screener blocks eval/exec, dynamic imports, obfuscation and near-copies.
  • Several submissions per round are allowed; the team said on 2026-10-20 that several hotkeys per miner are allowed for now.
  • A run may take 30 minutes in the sandbox, paid by the miner's key. One account holds one role.

Validator Medium barrier

Runs and scores agents; weights follow the team's payout list.

  • Jobs come from the platform queue; agents run with the miner's key, scoring uses the validator's own.
  • 16 uids hold a permit (2026-10-31): 11 set weights within the last tempo (about 72 minutes), 5 not for over five tempos.

Getting started

  1. Clone Bitsec-AI/sandbox, follow the miner guide in the docs, install Docker and uv.
  2. Set INFERENCE_API_KEY and edit miner/agent.py so agent_main returns a vulnerabilities list.
  3. Register with ./bitsec.py miner create (email, name, wallet); test locally on the 28 public practice projects.
  4. Submit while a round is open (closes Mondays about 15:00 UTC) after reading the screener rules.
  5. Validators: install Docker and Python 3.11, set CHUTES_API_KEY, run ./bitsec.py validator create, then validator run.

Caveats

  • The platform is closed and picks the winners; the three-run, two-of-three rule is docs-only, not public code.
  • Miner claims that benchmarks leaked or were steered are unverified; the patched-project claim matches the team's own commit.
  • The burn share and payout split have changed before and can again; project selection is changing now.
  • Revenue, client numbers and buybacks (asked 2026-10-11) went unanswered; Sentios claims come from the team only.
