What it is

Recall is a hosted memory and retrieval-augmented generation (RAG) API: store text in a vector database, query it and get grounded answers, with an MCP endpoint for AI agents. The miner, validator and web code is private, so the mechanism is the team's account, not checked code.

How it works

Miners

Per the team: miners store data, embed text, rerank and generate answers for users' databases. The explorer lists 17 UIDs, but on testnet 353, not mainnet; four report an RTX 4090 and 23 to 25 processed requests (2026-10-30).

Validators

Per the team: one master validator publishes a signed score bundle on IPFS; other validators verify it and set weights from it. The reward formula and what the four tier scores measure are not published.

Incentive

On chain (2026-10-30) all 16 validators put 100% of weight on UID 0, the owner's hotkey, which holds all incentive and 74% of emission. RecycleOrBurn is Burn, so the miner share (41%) is withheld; the same held since 2026-09-10. Whether this is the intended launch state is unknown.

Roles and requirements

Miner High barrier

Stores data and serves embedding, rerank and generation (per the team).

  • Explorer miners (testnet) run an RTX 4090 with 135 GB RAM.
  • Chain: the miner share is withheld, so no independent miner is paid.

Validator High barrier

Applies the master validator's signed scores and sets weights (team).

  • Chain: 16 permit holders, all with 100% weight on UID 0.
  • Team: validators check each miner's TLS certificate against its hotkey.

Product and limits

  • Users sign in, create vector databases, store text, query and generate answers; agents use a remote MCP endpoint.
  • Free defaults (docs): 20 databases, 50 GiB, 1,000 embeddings and 10,000 queries per hour.
  • Miners are not in trusted enclaves, so they may see plain text; do not store secrets.

Who holds the alpha

  • Chain: one coldkey holds 67.5% of the alpha read, staked to the owner's hotkey; the owner's own coldkey holds 1.3%.
  • The owner said on 2026-10-29 his alpha is locked on a separate key; consistent with the chain, but control and any lock are not shown.

Getting started

  1. Users: sign in on rec4ll.com, create a database, store text, query and generate within the free limits.
  2. Agents: connect the remote MCP endpoint (OAuth) or use the REST API with a key.
  3. Miners and validators: no public code or guide was found; follow the #recall announcements.

Caveats

  • No public code: scoring and onboarding cannot be checked, and test results are team-reported on private networks.
  • Mainnet launch not shown: zero miner incentive at every block sampled since 2026-09-10, and the dashboard reads testnet 353.
  • Promised dates slipped (end-June beta, 2026-07-07, '48 to 72 hours' on 2026-09-28, 2026-10-12 rollout).
  • Commit-reveal was switched off on 2026-10-13 with no reason found; usage claims come only from the team and members.
  • Chain figures are dated snapshots; the stake read covered 77% of staked alpha and a coldkey is not proof of who controls it.
