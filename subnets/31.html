What it is

Recall is a hosted memory and retrieval-augmented generation (RAG) API: store text, query it and get grounded answers, with an MCP endpoint for agents. Code is private.

How it works

Miners

Per the team: miners store data, embed text, rerank and generate answers. Six of 244 listed uids are online on two machine specs (RTX 4090 each) and restarted together three times (2026-11-09, 2026-11-10, 2026-11-13).

Validators

Per the team: a master validator publishes a signed score bundle on IPFS; others verify it and set weights. The formula is not published.

Incentive

On chain (2026-11-13) six uids earn 16.5 to 16.8% each, as since 2026-11-02. UID 0 holds 30.4% of per-uid emission as a validator; miners get exactly half; the split is 18/41/41 again since 2026-11-11 (25/20/55 before).

  • Chain: six uids earn; 238 others are registered without incentive, 7 of them since 2026-11-08 with no weights set.

Validator High barrier

Applies the master validator's signed scores and sets weights (team).

  • Chain: 12 permit holders weight the same six miners near-equally (2026-11-13); uids 150 and 185 lost their permits that day.
  • Team: validators check each miner's TLS certificate against its hotkey.

Product and limits

  • Users create vector databases, store text, query and generate answers; agents use a remote MCP endpoint (a free default Recall Memory database).
  • Free tier (docs): 20 databases (20 new per day), 8 million vectors, 50 GiB, 1,000 embeddings, 10,000 queries per hour.
  • Third-party operators (the miners) see text in plaintext while processing it; embedding and rerank text may also go to up to two other miners to check the answer, and a miner outside your database's miners gets it when none of yours can answer (privacy policy, 2026-11-09; the opt-out switch of 2026-11-08 is gone). Stored text is encrypted at rest. Do not store secrets.
  • Docs of 2026-11-08: search distance became a similarity score (higher is closer).

Getting started

  1. Users: sign in on rec4ll.com, create a database, store text, query and generate within the free limits.
  2. Agents: connect the remote MCP endpoint (OAuth) or the REST API with a key.
  3. Miners and validators: no public code or guide found.

Caveats
