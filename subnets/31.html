What it is

Recall is a hosted memory and retrieval-augmented generation (RAG) API: store text, query it and get grounded answers, with an MCP endpoint for agents. Code is private.

How it works

Miners

Per the team: miners store data, embed text, rerank and generate answers. The explorer shows six of 255 uids online on one machine spec (RTX 4090, 135 GB RAM) and build, not restarted since 2026-11-04.

Validators

Per the team: a master validator publishes a signed score bundle on IPFS; others verify it and set weights. The formula is not published.

Incentive

On chain (2026-11-07) six uids earn 16.6 to 16.7% each, none owner-linked, unchanged since 2026-11-02. UID 0 holds 28.8% of per-uid emission as a validator (74.1% on 2026-10-31). Miners get exactly half of per-uid emission, although 55% is configured.

Roles and requirements

Miner High barrier

  • Team catalog: default embedding bge-small; bge-m3 and Qwen3 embedding models need CUDA.
  • Chain: six uids earn; 249 other registered uids show no probes or incentive (explorer, 2026-11-07).

Validator High barrier

Applies the master validator's signed scores and sets weights (team).

  • Chain: 14 permit holders; 13 weight the same six miners with uid 199 on top, 1 puts 100% on UID 0 (2026-11-07).
  • Team: validators check each miner's TLS certificate against its hotkey.

Product and limits

  • Users create vector databases, store text, query and generate answers; agents use a remote MCP endpoint (Recall Memory: a free default database for coding agents).
  • Free tier (docs): 20 databases including Recall Memory, 8 million vectors, 50 GiB, 1,000 embeddings and 10,000 queries per hour.
  • Third-party operators (the miners) see text in plaintext while processing it; stored text is encrypted at rest. Do not store secrets.

Service status and payout

  • Team status page (2026-11-07): all five functions operational. Generation 99.7% over 1 hour, 80% over 7 days; embedding and vector database 100%, rerank 98%, retrieval quality 97% (the team's own line for it is 92%).
  • Generation failed from about 06:00 to 20:30 UTC on 2026-11-04 and from about 04:53 to 08:53 UTC on 2026-11-06 (no miner restart that time). The organic request counter is 0 (5 on 2026-11-06).
  • Chain: incentive moved from UID 0 to six miners on 2026-11-02 and stayed near-equal through both outages.

Getting started

  1. Users: sign in on rec4ll.com, create a database, store text, query and generate within the free limits.
  2. Agents: connect the remote MCP endpoint (OAuth) or the REST API with a key.
  3. Miners and validators: no public code or guide found.

Caveats
