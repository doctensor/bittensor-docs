What it is

Recall is a hosted memory and retrieval-augmented generation (RAG) API with an MCP endpoint for agents. Miner and validator code is public (MIT) since 2026-11-16; the scoring API is private.

How it works

Miners

Per the code: a Docker stack (Go miner, vector database, embedding and rerank services, optional generation sidecar on Chutes) behind one public HTTPS port; the Recall API probes four tiers.

Validators

Per the code: the master validator (owner hotkey, UID 0) scores from the private Recall API and publishes a signed weight bundle; the other 6 permit holders submit it.

Incentive

On chain (2026-11-27) 242 uids earn 0.06 to 0.43% each; UID 0 holds 31.9% of emission as a validator, miners 50%; split 18/41/41 (owner, validators, miners).

  • Repo docs (2026-11-17): one hotkey per coldkey earns, the newest.

Validator High barrier

Relays the master validator's signed weights (code).

  • Chain: 7 hotkeys hold permits (12 on 2026-11-19); seven former holders earn as miners. None weights UID 0.
  • Code: a secondary cannot change scores; stake can be delegated to a child hotkey.

Product and limits

  • Users create vector databases, store text, query and generate answers; agents use a remote MCP endpoint.
  • Free tier (docs): 20 databases, 8 million vectors, 50 GiB, 10,000 queries per hour.
  • Miners see text in plaintext and two other miners may check embedding and rerank text (privacy policy, 2026-11-09); stored text is encrypted at rest. Do not store secrets.

How scoring works

  • Code: each epoch splits 100 units over four tiers: vector database 30, embedding 22, rerank 18, generation 30.
  • Code: each tier pays 40% as readiness to every eligible miner by pass rate, no customer needed, and 60% for customer work; evidence counts over 6 hours.
  • Code (2026-11-22): nothing burns; unearned units go to earning miners up to a cap, then equally to all; validators refuse bundles weighting the owner UID. New miners earn nothing, then half pay for five epochs.
  • Chain: near-equal pay and zero weight on UID 0 fit readiness-only payout.

Getting started

  1. Users: sign in on rec4ll.com, create a database, store and query text.
  2. Agents: use the remote MCP endpoint (OAuth) or the REST API.
  3. Miners: register from a coldkey with no other miner hotkey; follow SETUP.md in recall-miner.
  4. Validators: follow SETUP.md in recall-validator (permit and stake needed).

Caveats

  • Scoring evidence comes from the private Recall API; the published rules cannot be checked against its probes.
  • Hardware profiles repeat across many uids (49, 31, 30, 30, 29); separate coldkeys may be one operator (an inference).
