What it is

MANTIS pays miners for signals that help predict market moves. Miners upload encrypted predictions about once a minute; validators open them after a delay and score what each adds. A newer challenge, FLOW, takes full Bitcoin trades with optional collateral.

How it works

Miners

Each miner encrypts prediction vectors for every challenge and uploads one file per hotkey to its own Cloudflare R2 bucket, committed on chain, about every 60 seconds. For FLOW it also submits Bitcoin trades for four time regimes and may post collateral, held in a contract on Bittensor's EVM.

Validators

Validators download the files, decrypt them after a delay (code default one week), score each challenge with walk-forward regressions, merge near-copy miners into one signal and set weights every 360 blocks. Price data comes from a team-run feed.

Incentive

Challenge scores are combined by fixed weights (table below). The code burns 45% of weight on the owner's uid 0. New miners get a small floor weight for about 12 days. FLOW pays on path-adjusted, size-weighted trade returns.

Getting started

  1. Register a hotkey on subnet 123 (burn 0.15 TAO on 2026-10-30).
  2. Install the dependencies in MINER_GUIDE.md, including the pinned time-lock wrapper (not the PyPI package).
  3. Create a Cloudflare R2 bucket and commit its public URL on chain; the object key must equal your hotkey.
  4. Build predictions for every active challenge, encrypt with generate_and_encrypt.py and upload about once a minute; backtest with the team's iteration tool first.
  5. For FLOW, follow flow_post.py to open a collateral position and post bets before each trade opens.
  6. To validate, read install_reqs.sh and autoupdate.sh; no step-by-step validator guide exists.

Caveats

  • The team's own validator is the one that pays; which version or FLOW share others run is not visible.
  • The price feed is team-run and froze on 2026-09-01 and 2026-10-12; every challenge depends on it.
  • Scoring detail goes out by direct message only; the public data archive lagged seven weeks until 2026-10-30.
  • FLOW payout trusts the owner: only the owner posts realised losses and settles, outside the repo; the live contract was not compared with the source.
