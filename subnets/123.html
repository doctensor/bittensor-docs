What it is

MANTIS pays miners for signals that help predict market moves. Miners upload encrypted predictions about once a minute; validators open them after a delay and score what each adds. A newer challenge, FLOW, pays full Bitcoin trades backed by posted collateral.

How it works

Miners

Each miner encrypts prediction vectors for every challenge and uploads one file per hotkey to its own Cloudflare R2 bucket, committed on chain, about every 60 seconds. For FLOW it also submits Bitcoin trades for four time regimes, each with a collateral bet posted first (EVM contract); unposted trades earn nothing.

Validators

Validators download the files, decrypt them after a delay (code default one week), score each challenge with walk-forward regressions, merge near-copy miners into one signal and set weights every 360 blocks.

Incentive

Challenge scores are combined by fixed weights (table below). The code puts at least 52% of weight on the owner's uid 0 (burn). New miners get a small floor weight for about 12 days. FLOW pays on path-adjusted, size-weighted trade returns.

Getting started

  1. Register a hotkey on subnet 123 (burn 0.15 TAO on 2026-11-13).
  2. Install MINER_GUIDE.md's dependencies, including the pinned time-lock wrapper (not the PyPI package).
  3. Create a Cloudflare R2 bucket and commit its public URL on chain; the object key must equal your hotkey.
  4. Build predictions for every active challenge, encrypt with generate_and_encrypt.py, upload about once a minute; backtest with the team's tool first.
  5. For FLOW, follow flow_post.py: fund a collateral position (at least 1 alpha), then post a bet before each trade opens.
  6. To validate, read install_reqs.sh and autoupdate.sh; there is no validator guide.

Caveats

  • The team's own validator is the one that pays; uid 0 holds 53.6% of incentive, 52% by code plus an unquantified FLOW share.
  • The price feed is team-run and froze on 2026-09-01 and 2026-10-12, and per issue #12 again on 2026-11-11; every challenge depends on it.
  • Scoring detail goes out by direct message only; the public archive lagged seven weeks until 2026-10-30.
  • The team is trusted: its owner key reads every payload on arrival (docs: 'for trading'); only it settles FLOW, outside the repo, and the live contract was not compared with the source.
