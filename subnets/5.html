What it is

Hone trains AI with verifiable rewards: a team-run server issues coding tasks (fix a bug, add a feature or write a terminal script); miners' AI agents answer and validators grade the answers on hidden tests in a sandbox.

How it works

Miners

Miners run an AI agent behind a public port. For each task it downloads a workspace and uploads a signed patch or Bash script plus a trajectory (the record of its work); any model may be used.

Validators

About every 7.6 minutes a validator leases a task from the team's server and offers it to 128 of the roughly 246 eligible miners, picked at random. It grades answers on hidden checks in a Docker sandbox and sets weights every 180 blocks.

Incentive

A task scores 1 only if every hidden check passes, else 0. A miner's score is the average of its latest 100 results (a new miner's ramps up over 12). Since 2026-11-05 the release pays by rank: best miner 1, each next 0.995 times the one above (ties go to the lower uid), scaled to sum to 1 (before: in proportion to score). Emission: 18% owner, 41% validators, 41% miners; nothing is burned.

Roles and requirements

Miner Low barrier

Runs an AI agent that solves a coding or terminal task and returns a patch or script plus its trace.

  • Validators wait up to an hour per miner, so keep connections alive (keepalive fix merged 2026-10-20).
  • One coldkey holds 40 uids and about 20% of weight; issue #26 (2026-11-06) asks if one solve may be sent from several hotkeys.

Validator Medium barrier

Leases tasks from the team's server, sends them to miners, grades answers in Docker and sets weights.

  • On 2026-11-07, 11 of 64 permit slots were held; ten set weights within 72 minutes, the owner hotkey last on 2026-04-01 (it earns nothing).
  • The one with 72% of dividends holds 49,499 alpha here (about 602 TAO).

Rank-based pay (merged 2026-11-05)

  • Pull request #24 (merged 20:48Z) pays by rank: best miner weight 1, each next 0.995 times the one above. #25 (21:14Z) set the new-miner ramp at 12 results (4 before, 20 in #24).
  • Team estimate: top miner about 0.7% of weights (0.5% before), top 50 about 32% (23%). On 2026-11-07 all ten active validators set that shape and last-epoch incentive matches (top 0.7%, top five 3.5%).

Who holds the seats

  • Three coldkeys hold 87 of 256 uids (34%): 40, 32 and 15. Validator vectors give them about 20%, 15% and 6% of weight, 41% together (2026-11-07). A coldkey is not one person.
  • The four best-paid uids (incentive ranks 1 to 4) sit under the 40-uid coldkey, registered 2026-10-20 to 2026-10-28.

History of the slot

  • The slot (registered 2024-03-04) was OpenKaito until May 2025; a new owner announced the relaunch on 2026-07-26 and the RLVR subnet went live on 2026-07-29.

Recent activity

  • 2026-11-07 (GitHub; on-chain data; honedashboard.com) All ten active validators now set rank-shaped weights (top 0.7%). Dashboard median miner accuracy is 85% to 90% on 3 of 13 listed validators (80% to 94% on 2026-11-05).

Getting started

  1. Clone hone-subnet; read README.md and docs/DEMO_MINER.md. A miner needs a funded hotkey on netuid 5 (about 0.4 TAO), Python 3.10-3.12 and a public TCP port.
  2. Practise on the retired tasks in tests/fixtures with scripts/try_task.py (Docker required).
  3. Use any model or agent, submit its trace with each answer and keep validator connections open.
  4. Validators: run setup_validator.sh then start_validator.sh as a non-root docker-group user (12 GB RAM, 25 GB disk, direct route, 1,000 TAO stake).

Caveats

  • Tasks, hidden checks and the problem server are team-run and not public, so accuracy and task quality cannot be checked independently.
  • Four validators (uids 1, 22, 58, 245) set identical weight vectors on 2026-11-07, a fifth differs in one entry: cause unknown. One holds 72% of dividends; the team said on 2026-10-04 it effectively controls scoring.
  • Describes main at ccfaaf3 (checked 2026-11-07). Commit-reveal is off.
  • Dashboard accuracy is reported verdicts from 3 of 13 listed validators (pooled pass rates 83-88% on 2026-11-07); harder problems since 2026-10-14 make older figures not comparable.
  • Own-model training and the commercial product are unverified; who runs the 40-uid coldkey is unknown.
