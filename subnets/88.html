What it is

Investing88 is run by Mobius Fund as a decentralized hedge fund. Miners submit portfolio allocations in a simulated environment, either for Tao/Alpha staking or for US stocks and ETFs. Validators score the daily results, and the team combines top strategies into ensemble strategies that it uses for its own products, including the 88 Quant Fund, the 88 Public Index and an 88 Root validator. Pages describing external client revenue are older than the current state of the project.

How it works

Miners

A miner picks one asset class (it cannot be changed after the first submission) and keeps a strategy file named after its hotkey: a single Python dict of allocations, with negative values meaning shorts for stocks. The miner program, or the zero-code KYM web app, submits it to the team's API whenever the file's timestamp changes. US stock orders count as market-on-open if filed before 09:28 ET and market-on-close if filed before 15:50 ET. To limit UID spam, a coldkey needs 192 alpha staked plus 64 alpha paid, and chat on 2026-10-07 added that every new UID requires 64 alpha. New UIDs appear on the dashboard after one day and have a 3-day immunity period.

Validators

Validators fetch profit-and-loss, days-active, similarity and asset-ratio data from the team's API roughly every half hour, apply the scoring code in the public repo and set weights. The PnL itself is computed by the team's API, not by validators. The code zeroes out strategies that ended their window below their start value, reduces scores for near-duplicate strategies, inactivity, and heavy cash or short exposure, and rescales each asset class to its share of emissions. The team also keeps a public blacklist of UIDs it judges to be coasting.

Incentive

The score is the product of four terms (return over maximum drawdown, a profit-versus-loss ratio, a Kelly-normalized win-odds term and daily compounded return) over a 50-day rolling window, with new miners scaled down for their first 30 days and the top two profit days clipped. Emissions are split by a team-set asset ratio; the live ratio on 2026-10-21 was 45.5% Tao/Alpha, 45.5% US stocks and 9% to UID 142, a staging hotkey for incentivized conviction. The team says that 9% is passed on weekly to investors in proportion to alpha locked as conviction, with the owner wallet excluded.

Getting started

  1. Read the repo README and strat/README.md, then run the bundled simst tool on the example strategy files to backtest ideas before registering.
  2. Register a hotkey on netuid 88 and make sure the coldkey holds the required alpha (192 staked plus 64 paid per the README; the team has said every new UID needs 64 alpha).
  3. Either install the repo and start the miner with pm2, or use the KYM web app for zero-code submission.
  4. Put a strategy file named after your hotkey in Investing/strat/ (asset class key '_': 0 for Tao/Alpha, 1 for US stocks) and wait for the first submission to register the neuron.
  5. Check the dashboard after the next daily score run (00:00 UTC for Tao/Alpha, 06:00 UTC for stocks) and watch the 3-day immunity window.

Caveats

  • Chain weights, the validator set and actual incentive paid to miners were not read. The asset ratio and blacklist come from the team's API and the dashboard as read on 2026-10-21.
  • Validators rely on the team's API for PnL, days, similarity and the asset ratio, so the public scoring code cannot be checked end to end. Two of those endpoints timed out from the research machine on 2026-10-21, though the assets page responded.
  • The 9% incentivized-conviction distribution is run by the team off-chain; the repo only routes the share to UID 142. Whether weekly distributions have actually run was not verified.
  • The subnet overview doc was written around late 2025 and describes a client-facing revenue plan; in September 2026 the team said first clients had not yet been onboarded. No revenue or fund performance figures were verified.
  • Entry costs are described slightly differently in the README (192 staked plus 64 paid) and in chat (64 alpha per new UID); it is not clear whether the 192 is one-time per coldkey.
  • Blacklisting rests on team judgement, including KYM user data, and has been applied without prior warning since 2026-09-21. Planned items (MT5/MetaTrader integration, a scoring update) are not in the repo as of its last commit on 2026-09-24.
