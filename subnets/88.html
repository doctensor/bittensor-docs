What it is

Investing88, run by Mobius Fund, calls itself a decentralized hedge fund. Miners submit simulated Tao/Alpha or US-stock portfolios (MetaTrader accounts since 2026-11-06); validators score their daily risk-adjusted returns from the team's API. The team says it turns top strategies into funds such as the 88 Quant Fund.

How it works

Miners

A miner picks one asset class (Tao/Alpha staking, US stocks or, since 2026-11-06, MetaTrader) and cannot switch later. Tao/Alpha and stock miners file a strategy: a Python dict of allocations named after the hotkey (negative means short, stocks only), sent by the miner program or the KYM app to the team's API. MetaTrader miners link an MT5 account in KYM instead. Scores update daily at 00:00 UTC (Tao/Alpha), 02:00 UTC (MetaTrader) and 06:00 UTC (stocks).

Validators

Validators fetch PnL, days-active, similarity and asset-ratio data from the team's API, run the public scoring code and set weights; they cannot recompute the PnL. The code zeroes strategies that ended below their start value and cuts scores for near-duplicates, inactivity and heavy cash; since 2026-10-29 it can graylist a uid (the team's lists were empty on 2026-11-07).

Incentive

Score = return over drawdown x profit-versus-loss ratio x Kelly-normalized win odds x daily compounded return over a rolling 50-day window; new miners are scaled down for 30 days and the top two profit days are clipped. The team sets each asset class's share.

Getting started

  1. Read the repo README and strat/README.md; backtest ideas with the simst tool.
  2. Register a hotkey on netuid 88 (0.01 TAO burn); fund the coldkey with 192 alpha staked plus 64 paid per the README (the team says 64 per UID).
  3. Run the miner with pm2 or the KYM app, with a strategy file named after your hotkey in Investing/strat/ (key '_': 0 Tao/Alpha, 1 US stocks); for MetaTrader link an account in KYM.
  4. Check the dashboard after the next daily score; a new uid has 3 days of immunity.

Caveats

  • PnL, days, similarity and the ratio come only from the team's API, so scoring cannot be checked end to end.
  • Fund performance, revenue and customers are team or user statements; the fund pages show projections only.
  • MetaTrader is in the code but unproven: no scored miner, undocumented account checks, and miners give the team an MT5 investor password.
  • Chat after 2026-11-01 was not read (archive down).
