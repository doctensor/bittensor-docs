What it is

Investing88, run by Mobius Fund, calls itself a decentralized hedge fund. Miners submit simulated Tao/Alpha or US-stock portfolios; validators score their daily risk-adjusted returns from the team's API. The team says it turns top strategies into funds such as the 88 Quant Fund.

How it works

Miners

A miner picks one asset class, Tao/Alpha staking or US stocks, and cannot switch later. The strategy is a file named after the hotkey: a Python dict of allocations (negative means short, stocks only). The miner program or the KYM web app sends it to the team's API. Scores update daily at 00:00 UTC (Tao/Alpha) and 06:00 UTC (stocks).

Validators

Validators fetch PnL, days-active, similarity and asset-ratio data from the team's API, run the public scoring code and set weights. The API computes the PnL itself, so validators cannot recompute it. The code zeroes strategies that ended below their start value and cuts scores for near-duplicates, inactivity and heavy cash. Since 2026-10-29 it can graylist a uid; the team's lists were empty on 2026-10-30.

Incentive

Score = return over drawdown x profit-versus-loss ratio x Kelly-normalized win odds x daily compounded return, over a rolling 50-day window. New miners are scaled down for 30 days and the top two profit days are clipped. The team sets each asset class's share of incentive (table below).

Getting started

  1. Read the repo README and strat/README.md; backtest ideas with the simst tool.
  2. Register a hotkey on netuid 88 (0.01 TAO burn); fund the coldkey with 192 alpha staked plus 64 paid per the README (the team says 64 per UID).
  3. Run the miner with pm2 or use the KYM web app, with a strategy file named after your hotkey in Investing/strat/ (key '_': 0 Tao/Alpha, 1 US stocks).
  4. Check the dashboard after the next daily score; a new uid has 3 days of immunity.

Caveats

  • PnL, days, similarity and the asset ratio come only from the team's API, so scoring cannot be checked end to end.
  • Fund performance, revenue and customers are team or user statements; the fund pages show no data.
  • The staging uid's stake leaves its hotkey weekly, as the team says; who receives it is not visible.
  • MetaTrader is announced for November but is not in the repo; how the API will verify accounts is undocumented.
