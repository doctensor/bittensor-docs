What it is

Nepher Robotics runs tournaments in which each round fixes one robot and one NVIDIA Isaac Lab task, such as a Unitree Go2 quadruped solving mazes from LiDAR. Miners upload trained control policies, validators score them on hidden scenes, and after a team review up to three miners share the miner rewards.

How it works

Miners

Miners register a hotkey, train a policy for the current task and submit a signed agent archive with nepher-cli. Only the latest upload per hotkey counts; an automated scan checks it, and flagged uploads wait for an admin.

Validators

Validators run each eligible agent in a throwaway Docker container (no wallet, outbound firewall) and report scores to the team's backend, which combines them by stake weight.

Incentive

Each tournament runs contest, evaluation, review and reward stages. The team approves up to three winners, or none; they get the miner weight in the reward window, 70/20/10 percent by default.

Roles and requirements

Miner Medium barrier

Trains a robot-control policy in simulation and uploads it.

  • Account and API key at nepher.ai/account; platform deposits are one-way and larger ones earn a bonus.
  • Final scoring uses your latest upload per hotkey after an automated scan. Others' evaluation logs can be downloaded; a winner's submission only if paid for.
  • Several uids may submit; only one gets a reward (team, 2026-10-27).

Validator High barrier

Scores uploaded agents in an Isaac Sim sandbox and sets weights.

  • Evaluating needs an admin-activated account: ask the team on Discord to link your hotkey (docs). A CPU-only mode only sets weights.
  • On 2026-10-31, 15 uids held a permit and 10 had set weights; five had not for over 6 hours, the stalest for about 53 days.

Where the reward weight goes

  • Tournaments outside a reward window give 1% to their current leader; weight with no receiver goes to uid 0, the owner's hotkey.
  • On 2026-10-31 all 10 validators with weights put 67.9% on uid 9, fitting the Task Generation podium (70/20/10 scaled by 0.97) plus three 1% leaders. Uid 2 led on 2026-10-28 and is now third; why is not public.
  • The top uid earns about 11 TAO a day, so a two-day window (widened from one day on 2026-10-28) pays about 22 TAO before selling costs.

Getting started

  1. Register a hotkey on subnet 49 with btcli (burn 0.05 TAO).
  2. Sign up at nepher.ai/account, create an API key and fund the platform balance.
  3. Install Python 3.12, Isaac Sim 6.1 and Isaac Lab 3.0.0, then clone the tournament's task repository and train.
  4. Submit with nepher-cli (npcli); keep the hotkey registered until the reward window ends.
  5. Validators: sign up with the validator role and ask the team on Discord to activate it, then follow the validator guide.

Caveats

  • Podium approval, score aggregation and the security scan run in a closed backend.
  • Scan rules and the 2026-10-26 incident cause are not public. Which tournaments receive weight is inferred from chain data; chain figures are validator opinions, not payouts.
  • Sandbox fixes sit on unmerged subnet-repo branches, so what validators run is unknown.
