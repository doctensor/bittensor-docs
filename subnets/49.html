What it is

Each tournament fixes one robot and one NVIDIA Isaac Lab task. Miners upload trained control policies, validators score them on fixed benchmark scenes, and after a team review up to three miners share the rewards.

How it works

Miners

Miners register a hotkey, train a policy for the current task and submit a signed agent archive with nepher-cli. An automated scan checks it; flagged uploads wait for an admin.

Validators

Validators run each eligible agent in a throwaway Docker container (no wallet, outbound firewall) and report scores to the team's backend, which combines them by stake weight.

Incentive

Each tournament runs contest, evaluation, review and reward stages. The team approves up to three winners, or none; they get the miner weight in the reward window, 70/20/10 percent by default.

How the Go2 maze is scored

  • Score = share of mazes finished x (0.25 + 0.75 x quality); finishing none scores 0.
  • Quality: 45% speed against the shortest route, 25% path directness, 20% body steadiness, 10% staying under the dog's 5 m/s peak.
  • Public and final runs use 60 fixed mazes on different terrain sets.

Where the reward weight goes

  • Tournaments outside a reward window give their leader 1%; unclaimed weight goes to uid 0, the owner's hotkey.
  • On 2026-11-07 all 10 validators with weights put 68.6% on uid 241 (about 11 TAO a day), 19.6% on uid 234 and 9.8% on uid 9: the Task Generation podium. The same winning agent moved from uid 238 to uid 2 to uid 241 since 11-04; uid 2 held 1,630 alpha on 11-05 and 101 now.
  • The PoC window ends 11-07 17:20 UTC and Go2 Phase 2 pays from 11-09 08:33; in between, weight should go to the 1% leaders and uid 0 unless the PoC window moves again.

Getting started

  1. Register a hotkey on subnet 49 with btcli (burn 0.05 TAO).
  2. Sign up at nepher.ai/account, create an API key and fund the platform balance.
  3. Install Python 3.12, Isaac Sim 6.1 and Isaac Lab 3.0.0, clone the tournament's task repository and train.
  4. Submit with nepher-cli (npcli); keep the hotkey registered until the reward window ends.
  5. Validators: sign up as a validator, ask the team on Discord to activate it, then follow the validator guide.

Caveats

  • Podium approval, score aggregation and the security scan run in a closed backend.
  • The 2026-10-26 outage has no public cause; scan rules are not public and three flagged-upload reports had no team answer by 11-02. Chain weights are opinions, not payouts.
  • Only the sandbox image pin reached main (11-06); the hardening branch (unprivileged user, no burn on lookup failure) is unmerged, so what validators run is unknown.
