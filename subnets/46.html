What it is

Instant is an inference subnet: miners serve one uncensored open model (GLM-5.3-Flash) from their own GPU hosts and validators reward speed and verified output. The netuid was reused: 3D models until 2025, real estate after that, Instant since September 2026.

How it works

Miners

Miners run the team’s signed binary on a host that serves the model through TensorFold, the team’s public engine fork. The platform admits a host at 200 tokens per second or more and routes paying traffic first.

Validators

Validators need no GPU. They fetch a platform-signed summary, check its signature, score it with a private library and write weights with commit-reveal. The verifier replays every answer; validators see only the result.

Incentive

Score is 60% speed, 25% verified tokens, 10% successful requests and 5% success rate. Two or more bad proofs above 0.5% of checks scores zero. Weights are scaled by one minus the burn; the burn is the largest whole percent that still pays miners a team-signed USD target at chain prices, so it moves with the alpha price. It goes to the owner slot, which the chain withholds; the team can change the target without a validator release.

Getting started

  1. Check the Miner requirements above (four RTX PRO 6000 cards).
  2. Register a hotkey on subnet 46 (burn 0.1 TAO) and keep its file on the host.
  3. Run the installer from the miner releases repo; it downloads the checkpoint and waits for admission.
  4. Run the miner’s doctor, qualify (speed against the 200 tokens/s floor) and status commands.
  5. To validate instead, stake 1,000+ TAO on a registered hotkey and run the validator installer.

Caveats

  • The verifier and scoring library are closed, so scoring cannot be checked end to end.
  • Usage figures are team-run and partial (missing usage is unknown, not zero); the team called the AntSeed volume unusual on 2026-10-28.
  • Dashboard speeds are team-published; on 11-06 it listed uids 63 and 82 as providers while they earned nothing.
  • Operators can read prompts and replies while processing; zero retention does not change that.
  • The old docs domain redirects elsewhere; the identity’s Discord invite leads to the main Bittensor server.
