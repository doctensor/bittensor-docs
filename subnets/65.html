What it is

TPN, built by Taofu Labs, runs timed competitions: miners compress a base model into a quantized GGUF that fits a GPU-memory cap and scores highest on a closed benchmark and a KL check. It was a VPN subnet until a pivot on 2026-06-08.

How it works

Miners

A miner uploads one GGUF to Hugging Face, runs the benchmark and KL check on the team's paid service, and commits the file hash and run ids in a timelocked chain message.

Validators

The team's leader validator checks each run id with the benchmark service and ranks the entries; it downloads no model. Followers copy its results into weights.

Incentive

A round holds a fixed share of validator weight (25%; 35% for TPN-008), split by rank: five places in rounds 1 to 4, three in TPN-005, one since. The rest goes to uid 0 and is burned.

Scorecard

Chain figures as of 2026-11-13, main mechanism only. Owner share is a floor: it counts only emission to uids under the owner's keys.

Getting started

  1. Run `tpn competitions`: TPN-008 is scored; no later round is listed (2026-11-13).
  2. Install the CLI (Python 3.12, uv), get a Hugging Face account and register a hotkey (0.2 TAO burn).
  3. Quantize the base model into one GGUF under the cap (TPN-008: 25 GiB GPU memory); the benchmark service measures memory.
  4. Upload with tpn upload, make the repo public (tpn publish), top up credits, run tpn benchmark (KL run included), then tpn commit.

Caveats

  • Specs and results live on the team's leader API, not in git; followers copy it: one node is the single point of trust.
  • One operator behind TPN-007's top five and TPN-008's is inferred (shared account, one coldkey on four of five hotkeys), not stated.
  • Chat after 2026-10-31 was unreadable (archive timed out 2026-11-13); why ranks 1 and 2 were disqualified is unchecked.
  • After the TPN-008 payout ends (about 11-19) the code implies validators keep copying uid 198's row; not yet seen.
