What it is

TPN, built by Taofu Labs, runs timed competitions: miners compress a base model into a quantized GGUF that fits a GPU-memory cap and scores highest on a closed benchmark and a KL check. It was a VPN subnet until a pivot on 2026-06-08.

How it works

Miners

A miner uploads one GGUF to Hugging Face, runs the benchmark and KL check on the team's paid service, and commits the file hash and run ids in a timelocked chain message.

Validators

The team's leader validator checks each run id with the benchmark service and ranks the entries; it downloads no model. Followers copy its results into weights.

Incentive

A round holds a fixed share of validator weight (25%; 35% since TPN-008), split by rank: five places in rounds 1 to 4, three in TPN-005, one since. The rest goes to uid 0 and is burned.

Scorecard

Chain figures as of 2026-11-20, main mechanism only. Owner share is a floor: it counts only emission to uids under the owner's keys.

Who can validate
OpenAnyone with 1,000+ TAO stake can run a follower (16 of 64 permits held); one team leader scores.

Earners
2 uidstop 5 hold 100% of incentive. Two uids earn: the burned owner uid (65%) and TPN-008's winner, uid 198 (35%); sixteen validators earn dividends.
Validator agreement
Converged16 of 16 validators put most weight on uid 0; they copy one leader by design, so agreement says little.
Code
OpenMiner CLI and validator are public under MIT; the benchmark service and question set are closed.

Getting started

  1. Run `tpn competitions`: TPN-009 is open until about 11-26; TPN-008 is scored (2026-11-20).
  2. Install the CLI (Python 3.12, uv), get a Hugging Face account and register a hotkey (0.2 TAO burn).
  3. Quantize the base model into one GGUF under the cap (TPN-009: 14 GiB GPU memory); the service measures memory.
  4. Upload with tpn upload (private repo), top up credits, store a Hugging Face token on the service, run tpn benchmark --hf-token-id (KL run included), tpn commit, then tpn publish before scoring.

Caveats

  • Specs and results live on the team's leader API, not in git; followers copy it: one node is the single point of trust.
  • One operator behind TPN-007's top five and TPN-008's is inferred (shared account, one coldkey on four of five hotkeys).
  • Chat after 2026-10-31 was unreadable (archive hung 2026-11-20); the closed leader, not public code, disqualified ranks 1 and 2, reason unchecked.
  • Validators still copy uid 198's 35% row after TPN-008's payout; TPN-009's pay starts at its scoring end (about 11-26), so the row may hold until then (inference).
