What it is

TPN, built by Taofu Labs, runs timed competitions: miners compress a base language model into a quantized GGUF file that fits a memory cap and scores highest on a closed benchmark. One team-run leader validator ranks the entries. Until 2026-08-17 the subnet was a VPN project.

How it works

Miners

A miner uploads one GGUF of the round's base model to Hugging Face, runs the benchmark on the team's paid service and commits the file hash and run ids in a timelocked chain message.

Validators

The team's leader validator checks every run id, ranks the entries and prechecks the files in a Docker container; followers copy its results into weights.

Incentive

A round holds 25% of validator weight, split by rank: five places in rounds 1 to 4, three in TPN-005, one in TPN-006. The other 75% goes to uid 0 and is burned.

Scorecard

Chain figures as of 2026-10-30, main mechanism only. Owner share is a floor: it counts only emission to uids under the owner's keys.

Roles and requirements

Miner Medium barrier

Compresses the round's base model into one GGUF under the cap and pays for its own benchmark runs.

  • Runs failed often in October (no GPU capacity, worker errors, stuck credit holds); an unfinished run scores zero.
  • Production bans a hotkey whose file hash differs at precheck; the testnet branch removes the ban.

Validator High barrier

Followers copy the leader's results into weights; the leader seat, which scores entries, is the team's in practice.

  • 16 of 64 permit slots were held on 2026-10-30; all 16 had set weights within one tempo.
  • Two leaders can produce conflicting scoring state (docs); the admin key can cancel or retry any user's runs.

Next version (testnet branch)

Not live: the leader still lists RAM-based specs (2026-10-30).

  • Memory becomes GPU memory read from the benchmark service; the precheck container and hash ban are deleted.
  • A round can add a KL check: score = lowest benchmark score x exp(-KL); a missing KL run means no score.

Getting started

  1. Check the leader's public endpoint for an open round; none was open on 2026-10-30.
  2. Install the CLI (install_cli.sh: Python 3.12, uv), get a Hugging Face account and register a hotkey (0.2 TAO burn).
  3. Quantize the base model into one GGUF under the cap; the memory figure you commit must match the validator's within 1%.
  4. Upload with tpn upload, top up benchmark credits, run tpn benchmark well before the deadline, then tpn commit and tpn publish before scoring.

Caveats

  • No round is live; TPN-007's spec and whether validators move to the testnet branch are unknown.
  • Round specs and results live on the team's leader API, not in git, and followers copy it: one node is the single point of trust.
  • The benchmark is closed and runs only on the team's paid service; that the TPN-006 model beats its 17 GB target is the team's figure.
  • A miner said the TPN-005 top three were one model in three layouts; the leader data shows three different file hashes, so this is unverified.
