What it is

TPN, built by Taofu Labs, runs timed competitions: miners compress a base model into a quantized GGUF that fits a GPU-memory cap and scores highest on a closed benchmark and a KL check. It was a VPN subnet until a pivot on 2026-06-08.

How it works

Miners

A miner uploads one GGUF to Hugging Face, runs the benchmark and KL check on the team's paid service, and commits the file hash and run ids in a timelocked chain message.

Validators

The team's leader validator checks each run id with the benchmark service and ranks the entries; it downloads no model. Followers copy its results into weights.

Incentive

A round holds a fixed share of validator weight (25%; 35% for TPN-008), split by rank: five places in rounds 1 to 4, three in TPN-005, one since. The rest goes to uid 0 and is burned; between rounds validators copy each other's last weights.

Getting started

  1. Run `tpn competitions`: TPN-008 (Gemma 4 31B) is open until about 2026-11-12 12:00Z.
  2. Install the CLI (install_cli.sh: Python 3.12, uv), get a Hugging Face account and register a hotkey (0.2 TAO burn).
  3. Quantize the base model into one GGUF under the cap (TPN-008: 25 GiB GPU memory); the benchmark service measures memory.
  4. Upload with tpn upload, make the repo public (tpn publish), top up credits, run tpn benchmark (KL run included), then tpn commit.

Caveats
