What it is

Subnet 498, run by Technology Nucleus and branded CanopyMRV, aims to produce labeled satellite imagery for climate verification. Miners run vision models that outline tree crowns on image tiles; validators score them against a hidden labeled set and keep one miner's record per unlabeled image. Together these form the dataset the team plans to sell.

How it works

Miners

Any model works (the repo ships SegFormer, YOLO, self-hosted REST, OpenAI and Qwen2-VL backends); the result, a JSON of polygons, class and confidence, goes to Cloudflare R2 and its address is returned. Answers must match the batch ID and size limits; crude boxes and spiky outlines score zero. Optional --agentic mode (v2.0.0): a Gemini agent retunes settings or patches allowlisted files between rounds.

Validators

A validator mixes hidden labeled (golden) images with unlabeled public ones. Golden images score 60% on overlap with the true shape (0.5 IoU to match) and 40% on class, reduced for false positives and gamed geometry. v2.0.0 adds a Gemini-written diagnosis of each miner's weakest golden tiles (default on). A private vision-model step keeps at most one miner's record per public image. The round loop, task planner and selection step ship only as encrypted files.

Incentive

In the readable code a miner's round score is 0.7 x golden-set fidelity plus 0.3 x the larger of an adoption bonus (zero by design for now) and its selection share, smoothed over rounds. Miners under 5% of the top score get nothing; the rest share a floor (at most 20% of the total) plus a share proportional to score. Per-validator weights were not read.

Roles and requirements

Miner Medium barrier

Outlines tree crowns on batches of up to 30 satellite tiles within 600 seconds and uploads the result.

  • Limits: 16 MB file, a polygon-complexity cap.
  • One miner reported (2026-10-04) that the golden set is trees only, so shrub or field labels count as errors.

Validator High barrier

Plans tasks, scores miners against the hidden set and sets weights; on testnet one validator (uid 5; the team's, per chat) does so.

  • Testnet: 18 of 19 neurons hold a validator permit; uid 5 holds all dividends, while the median permit holder last set weights about 53 days ago.
  • The repo's testnet script runs the team's validator at 6-hour rounds; the real cadence is unread.
  • The team says the single-validator setup is temporary until more validators join (chat, 2026-10-19).

Getting started

  1. Clone Tech-Nucleus/DataAnnotation, make a virtual environment, run pip install -r requirements.txt.
  2. Copy .env.example to .env: wallet name, Cloudflare R2 credentials, a model backend (schema and limits: MINER.md).
  3. Register a hotkey on testnet netuid 498; the team offered faucet tokens in chat on 2026-09-21.
  4. Run python neurons/miner.py --netuid 498 --subtensor.network test with your wallet, hotkey, axon port and model path. Optional: add --agentic with a Gemini key (MINER.md).
  5. Answer only for each task's batch ID and check that tasks arrive: the validator stalled on 2026-10-01 and 2026-10-18.

Caveats

  • Testnet only: nothing here describes mainnet emissions or economics, and the team gave no mainnet date.
  • Encrypted validator modules mean public-image selection and the step from round results to on-chain scores cannot be verified from the repo.
  • Ground truth is the team's own AI pipeline checked against few certified human labels; the one published benchmark changed figures between chat and site.
  • The network is small and mostly team-run: three outside miners on 2026-10-04; the testnet script launches a team validator and three team miners.
  • The fidelity score trusts miner-supplied confidence (0.95 if missing, 25% of the composite); its effect on rewards was not traced.
  • The v2.0.0 agent mode and validator feedback are untested here and their effect on scoring was not traced; in agent mode an LLM edits miner code.
