What it is

Subnet 498, run by Technology Nucleus and branded CanopyMRV, aims to produce labeled satellite imagery for climate verification (carbon accounting, deforestation rules). Miners run vision models that outline tree crowns on image tiles; validators score them against a hidden labeled set and keep one miner's record per unlabeled image. Together these form the dataset the team plans to sell. Testnet only.

How it works

Miners

Miners get up to 30 image tiles per round and 600 seconds to answer. Any model works (the repo ships SegFormer, YOLO, self-hosted REST, OpenAI and Qwen2-VL backends); the result, a JSON of polygons, class and confidence, goes to Cloudflare R2 and its address is returned. Answers must match the round's batch ID and size limits; crude boxes and spiky outlines score zero.

Validators

A validator mixes hidden labeled (golden) images with unlabeled public ones. Golden images score 60% on overlap with the true shape (0.5 IoU to match) and 40% on class, reduced for false positives and gamed geometry. A private vision-model step keeps at most one miner's record per public image. The round loop, task planner and selection step ship only as encrypted files.

Incentive

In the readable code a miner's round score is 0.7 x golden-set fidelity plus 0.3 x the larger of an adoption bonus (zero by design for now) and its selection share, smoothed over rounds. Miners under 5% of the top score get nothing; the rest share a floor (at most 20% of the total) plus a share proportional to score. Per-validator weights were not read.

Roles and requirements

Miner Medium barrier

Outlines tree crowns on batches of up to 30 satellite tiles within 600 seconds and uploads the result.

  • Limits: 16 MB file, a polygon-complexity cap; an answer for an older batch ID scores 0.
  • The README quickstart clones a personal GitHub account, not the team's Tech-Nucleus repo.
  • One miner reported (2026-10-04) that the golden set is trees only, so shrub or field labels count as errors, and that task images fill the disk.

Validator High barrier

Plans tasks, scores miners against the hidden set and sets weights; on testnet one validator (the team's, per chat) did so.

  • Testnet: 18 of 19 neurons hold a validator permit, but none has set weights in over 5 tempos (2026-10-31).
  • The team says the single-validator setup is temporary until more validators join (chat, 2026-10-19).

Getting started

  1. Clone Tech-Nucleus/DataAnnotation (the README names a personal account), make a virtual environment, run pip install -r requirements.txt.
  2. Copy .env.example to .env: wallet name, Cloudflare R2 credentials, a model backend (schema and limits: MINER.md).
  3. Register a hotkey on testnet netuid 498; the team offered faucet tokens in chat on 2026-09-21.
  4. Run python neurons/miner.py --netuid 498 --subtensor.network test with your wallet, hotkey, axon port and model path.
  5. Answer only for each task's batch ID and check that tasks arrive: the validator stalled on 2026-10-01 and 2026-10-18.

Caveats

  • Testnet only: nothing here describes mainnet emissions or economics, and the team gave no mainnet date.
  • Encrypted validator modules mean public-image selection and the step from round results to on-chain scores cannot be verified from the repo.
  • Ground truth is the team's own AI pipeline checked against few certified human labels; the one published benchmark tile changed figures between a chat post and the site.
  • The network is small and mostly team-run: three outside miners on 2026-10-04, one team validator, which the team calls temporary.
  • A 2026-10-18 concern holds in the code: the fidelity score trusts miner-supplied confidence (0.95 if missing, 25% of the composite); the effect on rewards was not traced.
