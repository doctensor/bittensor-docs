What it is

On 2026-11-14 BEX Tracer (spot Chrome extensions) paid one entry 60%; ADA v3 (spot anti-detect browsers) paid 122 uids the other 40%.

How it works

Miners

A miner writes JavaScript for a challenge, packs it in a Docker image and commits its digest once per 24 hours. BEX files may make no outside requests. ADA v3 needs one file per anti-detect browser (AdsPower, Dolphin Anty, GoLogin, Multilogin, Octo Browser) plus a headless detector.

Validators

Commits are revealed after about a day, checked, compared and scored on the team's own server. Validator code fetches the scored results once a day from 14:00 UTC and sets weights about every 20 minutes (live pay came faster).

Incentive

An entry counts if it reaches the challenge's minimum score and is not too similar to others (limit 0.6; 0.8 against your own commits). A best entry holds full value for 10 days, then fades, faster each day, to zero at day 15; a resubmission restarts that only if accepted and higher. If a challenge has no accepted entry, its weight goes to the other; an accepted one takes it back. Miners sharing an IP, Docker Hub account or coldkey count as one.

Roles and requirements

Writes detection JavaScript, builds a Docker image and commits its digest; one commit per challenge per day.

  • BEX files: up to 750 lines, 10 s budget. ADA files: up to 500 lines.

  • The key comes from the team's storage service; whether every validator gets one is not public.

Getting started

  1. Read the live challenge's docs; one commit per challenge per 24 hours.
  2. Clone the challenge repo and test your detector with its harness; BEX detectors may make no outside requests.
  3. Push the Docker image to Docker Hub (private repo advised, one account for all images).
  4. Run the miner repo (3.0.5+) to commit the digest. Do not swap hotkeys: it has broken commit tracking.
  5. Check the dashboard that your entry is scored and accepted (about 25 h after the commit).

Caveats

  • Weights, minimums, decay and fade dates come from repo config, code, dashboards and chain fits; the scoring server is private.
  • The BEX bypass dispute is mostly miners' claims; staff did not say whether a fix is live.
  • Buyback, banking and client-news claims (2026-10-23 to 10-31) are not visible on chain or in code. Chat read to 2026-11-01; archive down 2026-11-14.
