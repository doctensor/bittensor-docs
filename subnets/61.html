What it is

On 2026-11-25 ADA v3 paid 91 uids almost evenly; BEX's paying entry ran out on 11-22 and the new Bot Virus v2 has not scored yet.

How it works

Miners

A miner packs a submission in a Docker image and commits its digest, once per challenge per 24 hours: JavaScript with no outside requests (BEX), one detector per anti-detect browser plus a headless one (ADA v3), or a Python bot that must complete a web page unflagged (Bot Virus v2).

Validators

Commits are revealed after about a day, checked, compared and scored on the team's own server. Validator code fetches the scored results once a day from 14:00 UTC and sets weights about every 20 minutes (live pay came faster).

Incentive

An entry counts if it reaches the challenge's minimum score and is not too similar to others (limit 0.6; 0.8 against your own commits). A best entry holds full value for 10 days, then fades, faster each day, to zero at day 15; a resubmission restarts that only if accepted and higher. If a challenge has no accepted entry, its weight goes to the others; an accepted one takes it back. Miners sharing an IP, Docker Hub account or coldkey count as one.

Roles and requirements

Miner Low barrier

Builds a detector or a bot as a Docker image; one commit per challenge per day.

  • Needs git, a wallet and the miner repo 3.1.15+ (2026-11-24).
  • Size limits: BEX 750 lines, ADA 500, Bot Virus 2,000 for bot.py plus a 500-line Dockerfile.
  • A score takes about 25 hours (docs: up to 48).

Validator High barrier

Fetches the team's scored results and sets weights; scoring runs on the team's server.

  • The key comes from the team's storage service; who gets one is not public.

Getting started

  1. Pick a challenge and read its docs; one commit per challenge per 24 hours.
  2. Test with the challenge repo's harness or practice page; BEX detectors may make no outside requests.
  3. Push the Docker image to Docker Hub (private repo advised, one account for all images).
  4. Run the miner repo (3.1.15+) to commit the digest. Do not swap hotkeys: it has broken commit tracking.
  5. Check the dashboard that your entry is scored and accepted (about 25 h after the commit).

Caveats

  • Weights, minimums, decay and fade dates come from repo config, code, dashboards and chain fits; the scoring servers are private.
  • Buyback, banking and client-news claims (2026-10-23 to 10-31) are not visible on chain or in code. Chat read to 2026-11-01; archive down 2026-11-25.
