What it is

Sluice describes itself as a market for routing policies: an app sends an AI request with limits on budget, latency, quality and privacy, miners propose which provider and model should serve it, and validators benchmark the proposals. It would route to providers such as Chutes and Targon rather than run models itself. All of this comes from the team's website and chat; no subnet code is public.

How it works

Miners

Per the team (not verifiable in code): miners are routing agents, not compute nodes. For each request they get task metadata and propose a provider and model with predicted scores for cost, latency, quality, reliability and privacy. Only the winning proposal is said to be rewarded. The website's demo app imitates a miner with one Google Gemini call; it is a front-end simulation, not the network.

Validators

Per the team: validators run the proposed routes, measure latency, quality, cost and privacy compliance, and compute a regret-weighted score against reference alternatives, which feeds Bittensor consensus. The site's score weights are 50% quality, 25% cost, 15% latency and 10% reliability. No validator code is published, so none of this was checked.

Incentive

The team's stated rule: the miner whose route scores best on a request is rewarded, regret weighting is meant to stop copying of safe defaults, and losing proposals earn nothing. Developers would pay providers as usual; TAO is only the reward and staking currency. On the testnet (2026-10-31) no neuron has incentive or dividends; uid 0, the owner's hotkey at the 2026-10-21 check, gets about 45% of the last epoch's testnet emission.

Roles and requirements

Miner Low barrier

Proposes which provider and model should serve each AI request, with predicted scores (team design; no miner code is public).

  • A proposal is a destination plus predicted scores; losing proposals earn nothing (FAQ).
  • No miner software is public, so nothing can be run today.
  • Testnet: five neurons (four not the owner's at the 2026-10-21 check), none active, none with incentive (2026-10-31).

Validator Barrier unknown

Runs the routes miners propose, scores latency, quality, cost and privacy, and sets weights (team design; no validator code is public).

  • The team says validators need stake; the amount is not stated.
  • All five testnet neurons hold validator permits (64 slots); the newest weight-set is about 87 days old (2026-10-31).
  • Weights use commit-reveal on testnet; no commits are waiting.

Caveats

  • Testnet only: nothing here describes mainnet participation or economics. The site roadmap uses relative weeks, with no calendar dates.
  • No subnet code is public, although the FAQ promises public reference miner and validator code. Scoring, regret weighting and the privacy attestation are team statements, unchecked.
  • Docs are mostly unfinished: Quick Start, Scoring Engine, Run a Miner, Run a Validator, Route API and Changelog are 'Drafting' placeholders.
  • The in-browser app is a simulation: one Google Gemini call, hard-coded provider figures and canned answer text. It does not show real routing.
  • Testnet is a snapshot: five neurons hold validator permits, none is active, the newest weight-set is about 87 days old (2026-10-31). Who runs the four non-owner neurons is unknown (owner check 2026-10-21).
  • Privacy is unclear: chat said version 1 may use the prompt for routing; the FAQ says miners get task metadata only. The site's score weights omit privacy, the FAQ counts it.
