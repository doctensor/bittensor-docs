What it is

CapabilityForge Next (SN119) says it will reward training data that measurably improves a learning-focused, youth-friendly language model, starting with math and science. Its README describes miners submitting data patches, validators checking rights and leakage, and a frozen-model test that decides rewards. No public code, scoring rules or miner guide yet.

How it works

Miners

Design only (README, 2026-09-09): generate bounded synthetic or properly licensed data patches with record-level provenance. The submission format and what a miner runs are unpublished.

Validators

Design only: check data rights, privacy, lineage, duplication, contamination and evaluation leakage, then train and test qualified patches against a frozen baseline under identical conditions. No validator code is public.

Incentive

The README says rewards follow measured capability gains (accuracy, reasoning, calibration, age-appropriate clarity, safety), not dataset size or compute. No formula or threshold is published.

Caveats

  • Every mechanism above is a design statement: the repo holds a README and two images (one commit, 2026-09-09). Scoring rules, evaluation sets and the miner interface are unpublished.
  • Chain data shows settings, not intent: validators all weighting uid 0 is what a subnet with no scoring looks like. The repo link appears only in the on-chain identity, never in the channel.
  • A separate GitHub account, capabilityforge, has one agent-subnet repo (cf-subnet, 2026-05-21). It never mentions SN119; any link is unverified.
  • The README says math and natural science first; a 2026-10-03 team post adds language. The 'world's first youth-friendly LLM' claim and the preview date are unchecked.
