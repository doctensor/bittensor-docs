What it is

Targon, built by Manifold Labs, rents out confidential cloud machines: GPU and CPU VMs in hardware enclaves, bare metal, sandboxes and reserved capacity. Miners supply attested servers running the team's TargonOS image; validators set weights from auction targets that the team's closed backend publishes.

How it works

Miners

Mining means installing TargonOS, the team's signed OS image, on a server with TPM 2.0 and an enclave (Intel TDX or AMD SEV-SNP) enabled; it attests to the team's service at every boot. Profiles are 8-GPU servers of one model (H100 to B300, RTX PRO 6000) or 48-thread CPU servers, plus 3 TB of storage.

Validators

Every 361 blocks (about 72 minutes) a validator asks random nodes for attestation evidence, sends it to the team's service and sets weights. That service returns each node's auction and cards, and supplies the targets and burn split.

Incentive

The code assumes miners get 41% of emission and turns it into a dollar pool. Each auction sets a target card count, target price and maximum price per card hour; a live card earns the pool divided by live cards, capped at the maximum. Any remainder goes to a team-set burn split, then the owner's uid.

Getting started

  1. Read docs/miner/miner.md and installing-targonos.md, then check hardware: 8 GPUs of one listed model (or a CPU profile), 3 TB storage, TPM 2.0, TDX or SEV-SNP enabled.
  2. Install TargonOS 0.1.0 (network boot or ISO) from the miner docs' release index; it wipes every eligible disk.
  3. Register a hotkey on subnet 4 (0.0005 TAO burn on 2026-10-30) and run the miner process with your node addresses and port 7777.
  4. Validators: start from docs/validator/validator.md; the hardware advice has changed, so check chat first.

Caveats

  • Auction targets, pool inputs, attestation checks and the burn split come from the team's closed backend and cannot be audited. How validators get database credentials is not documented.
  • Revenue, user and payout figures are the team's own; only the burns are on chain. Whether the three miner uids are independent was not re-checked.
  • The code hardcodes miners at 41%; eTAO (10-19) lets the owner change the chain split without a code change.
