What it is

Targon, built by Manifold Labs, rents confidential cloud machines: GPU and CPU VMs in hardware enclaves, bare metal, sandboxes and reserved capacity. Miners supply attested servers running the team's TargonOS image; validators set weights from auction targets that the team's servers publish.

How it works

Miners

Miners install TargonOS, the team's signed OS image (required since 2026-07-14), on a server with TPM 2.0 and an enclave (Intel TDX or AMD SEV-SNP); it attests to the team's service at each boot.

Validators

Every 361 blocks a validator asks random nodes for attestation evidence, sends it to the team's service and sets weights from what comes back: each node's auction, cards and the burn split.

Incentive

The code assumes miners get 41% of emission and turns it into a dollar budget. Each auction sets target cards, a target price and a maximum price per card hour; a live card earns target price x target cards divided by live cards, capped at the maximum. Any remainder goes to a team-set burn split, then the owner's uid.

Roles and requirements

Miner High barrier

Run TargonOS on an attested server and rent its GPUs through team auctions.

  • The miner process refuses validators without a permit or under 1,000 alpha (default).
  • Docs minimums: 128-192 threads on GPU profiles.

Validator High barrier

Check node attestations through the team's service and set weights from its targets.

  • Whether the team's VM service serves only permit holders is undocumented; a 2026-09-23 chat error shows it refusing a hotkey with no permit.

Product and revenue

  • Team says: $1,003,263 revenue 2026-10-08 to 11-06: 88% contracts (daily: $29,441 to 11-03, $31,779 on 11-05, $29,633 on 11-06), 11% VMs ($4.0-4.3K a day since 11-03); 15,924 users.
  • The dashboard restated past days twice by 11-06 (contracts 9% lower, then VM revenue 52% lower), not on 11-07. VM revenue peaked at $375K in May.
  • Hippius, a rival project, tested Targon's CPU VMs on 2026-10-15 (conflict disclosed): genuine AMD SEV-SNP proofs.

Burns and buybacks

  • Chain: on 2026-10-27 two burns removed 152,334 alpha from stake (the team's dashboard says 8,536 TAO); alpha-out is unchanged, so it is not a supply cut.
  • Team says: 1,772 TAO of that week's buys, the rest alpha from its own revenue; 5,939 purchases (6,881 TAO) since 2025-07-07, none after 10-27.

Auction targets and pay

  • Team says, 2026-11-07: its auction list targets 1,408 GPU cards across 11 GPU node types; 264 are live.
  • The code's rule fits the live numbers (B300 earns $6.50 a card hour). The team API pays 8% under the formula, 7% a day earlier: the code scales payouts down when the formula tops its budget, and the gap widened as the alpha moving price fell 1%.

Getting started

  1. Read docs/miner/miner.md and installing-targonos.md; check your hardware against the profile (GPUs, RAM, TPM 2.0, TDX or SEV-SNP).
  2. Install TargonOS 0.1.0 (network boot or ISO); it wipes every eligible disk.
  3. Register a hotkey on subnet 4 (0.0005 TAO burn on 2026-11-01) and run the miner process with your node addresses and port 7777.
  4. Validators: start from docs/validator/validator.md; hardware advice has changed, so check chat first.

Caveats

  • Attestation checks and the burn split come from the team's closed backend; the public list shows targets, not how they are set. Payout totals imply a fixed TAO price input near $214 (inference).
  • Revenue, user and payout figures are the team's own, and past revenue days were restated twice; only the burns are on chain.
  • The code hardcodes miners at 41%; eTAO (10-19) lets the owner change the chain split without a code change.
  • The three paid uids use different coldkeys, none owner-linked; that does not show they are unrelated to the team.
