What it is

ChipForge pays miners to design AI-accelerator chips; validators score them with open tools. Run by the Tatsu team: subnet 84 until 2026-05-01, subnet 108 since 2026-09-20. Quest 001 closed on 2026-10-15; Quest 2 opened on 2026-11-02.

How it works

Miners

Miners download the public Quest 2 package, build an NPU with a compiler and C runtime, test it in Docker, and submit a signed zip (one per hotkey). Winning designs are shown to registered hotkeys after 18 hours.

Validators

Validators run the team's evaluation server with its signed evaluator. A team-run challenge server decides records and sends the payout schedule they follow.

Incentive

A new best design is a 'record': it waits 24 hours, then is paid for 48; up to three share. Only a fifth of validator weight is for miners; the rest goes to UID 0.

Roles and requirements

Miner High barrier

Builds the chip, compiler and runtime, and submits the signed package.

  • 1 submission per hotkey, 60 minutes apart; a queued design can be replaced or withdrawn, 3 times each (2026-11-14).

Validator High barrier

Runs the team's evaluation server, scores designs and sets weights.

  • 7 hold permits, 6 set weights within 1 tempo; 4 run the team's software (neuron 1.0.10, evaluator V-0.5 ready, 2026-11-14; uid 191 got its permit on 2026-11-07).

Getting started

  1. Register a hotkey on subnet 108 (0.05 TAO on 2026-11-14) and clone ChipForge_SN108; the README covers setup.
  2. Download the Quest 2 package (no login) and read npu_v2.0.md; copy the starter template (CPU only, passes the quick check).
  3. Run the local checker in Docker: the quick check takes about 10 minutes, a full score hours.
  4. Submit a signed zip (up to 50 MB) before 2026-11-23 10:06 UTC; a queued design can be withdrawn or replaced.

Caveats
