What it is

SayGM is an AI model gateway (api.saygm.com) compatible with the OpenAI, Anthropic and Gemini SDKs, paid by prepaid credit. Miners resell their own provider API capacity at a discount from a worker on a rented confidential VM. The team runs the gateway and the files that set pay; validators copy them. Mainnet launch: 2026-06-23.

How it works

Miners

A miner installs gmcli, logs in through Taostats, adds its own provider API keys (Anthropic, OpenAI, Google and others) and deploys the team-approved worker to a Phala confidential VM; the registry checks the image hashes. The miner lists models at a discount to the gateway price and keeps the spread over its upstream cost.

Validators

The team runs a closed gateway, registry and epoch finalizer. Each epoch (361 blocks, about 72 minutes) the finalizer posts usage and prices to a public bucket. The public validator turns each miner's billed value into a share of the miner pool and sets weights, without checking the files' hashes or signatures.

Incentive

A miner's weight is its billed value divided by the pool: 360 alpha times 41% times the alpha price. Emission splits 18% owner, 41% validators, 41% miners, none burned or recycled. The unused rest of the pool goes to an affiliate-pool miner (UID 157), not to the owner as the validator code says.

Where the emission goes

  • Billed traffic is paid first: epoch 26,018 billed $993 of a $1,143 miner pool (team's public files).
  • The unbilled rest, 13% to 35% in recent samples, goes to the affiliate-pool miner (contract live since 2026-10-06), which pays referrers in alpha.
  • Buybacks (team figures): the latest cycle burned about $104k of $515k miner emissions (20.3%); the chain shows one 10,771 alpha burn on 2026-10-16.

Getting started

  1. Miners: open a funded Phala Cloud account and install the Phala CLI.
  2. Have provider API keys you may resell; read the miner terms in the repo first.
  3. Register a hotkey on netuid 28, install gmcli, then run gmcli doctor and gmcli init.
  4. Declare a discount per model; run v0.5.11 or newer and set up gmcli notifications.
  5. Validators: copy .env.mainnet to .env, set the hotkey seed, run docker compose up -d --build.

Caveats

  • Gateway, registry and finalizer are closed and validators do not check the files: usage and revenue figures are the team's.
  • Chain incentive lags the newest file: UID 157 holds 24% now, against 13% to 35% in single epochs.
  • The affiliate contract was not read on chain; per the litepaper its admin can upgrade it without a delay.
  • For Claude, GPT and Gemini the provider still sees the prompt; only -TEE model ids are confidential end to end (site).
  • Not read: who held the slot before the 2026-06-23 launch (registered 2025-02-07).
