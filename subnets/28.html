What it is

SayGM is an AI model gateway for the OpenAI, Anthropic and Gemini SDKs, paid by prepaid credit. Miners resell their own provider API capacity at a discount from a worker on a rented confidential VM. The team runs the gateway and the files that set pay; validators copy them. Mainnet launch: 2026-06-23.

How it works

Miners

A miner installs gmcli, adds its own provider API keys and deploys the team-approved worker to a Phala confidential VM; the registry checks the image hashes. It lists models at a discount to the gateway price and keeps the spread.

Validators

Each epoch (361 blocks, about 72 minutes) the team's closed finalizer posts usage and prices to a public bucket. The public validator turns each miner's billed value into a share of the miner pool and sets weights, without checking the files' hashes or signatures.

Incentive

A miner's weight is its billed value divided by the pool (360 alpha times 41% times the alpha price). Emission splits 18% owner, 41% validators, 41% miners, none burned or recycled; the unused rest goes to the affiliate-pool miner (UID 157).

Where the emission goes

  • Billed traffic is paid first: epoch 26,300 billed $729 of an $806 pool (91%); the share ran 64% to 164% over 27 epochs (team's files).
  • Until epoch 26,297 the unbilled rest (up to 36% of the pool) went to the affiliate-pool miner; its UID 157 was replaced on 11-13 and epochs 26,298 to 26,300 carry no remainder row.
  • 'Adjustment' payments (first seen 11-08) are absent from epochs 26,269 to 26,300; no public document explains them.
  • Buybacks (team figures): cycle 02 burned about $104k of $515k miner emissions (20.3%); one 10,771 alpha burn on chain, 2026-10-16.

Getting started

  1. Miners: open a funded Phala Cloud account, install the Phala CLI and have provider API keys you may resell (read the miner terms).
  2. Run gmcli init: it registers your hotkey on netuid 28, logs in, adds provider keys and deploys (try testnet netuid 482 first).
  3. Declare a discount per model; run the current release (v0.5.24) and set up gmcli notifications.

Caveats

  • Usage and revenue figures are the team's; validators do not check the files.
  • The affiliate contract was not read on chain; per the litepaper its admin can upgrade it without a delay.
  • For Claude, GPT and Gemini the provider still sees the prompt; only -TEE model ids are confidential end to end (site).
  • Slot history: registered 2025-02-07 as a meme subnet, taken over 2025-02-25 by a stake-majority validator group; owner coldkey changed three times since 2025-05 (chain).
