What it is

ChronoLLM pays miners to train language models that know only what was public up to a chosen year, so finance and research teams can backtest without hindsight. Each weekly round covers one year, walking back toward 1999 (2011 now). CrunchDAO has run the subnet since June 2026.

How it works

Miners

Each week miners train a model for the round's year, publish it on Hugging Face and commit a pinned link on chain before Monday 12:00 UTC. Models may be up to 2.2B parameters; everything resets each round.

Validators

A secure enclave fetches a private dataset and rejects copies, earliest entry first. A leak test checks that a model knows its own period but not later ones; the best 30 then duel on about 650 fresh prompts judged by an OpenAI model. In practice the owner's slot runs this.

Incentive

Score is 30% leak test plus 70% duel win rate; failing any check scores zero. The top 10 share miner pay on a steep curve (52% to first). Emission splits 18% owner, 41% validators, 41% miners; about 85% of validator pay goes to the owner's slot.

Roles and requirements

Miner Medium barrier

Trains a model for the round's year, publishes it on Hugging Face and registers it on chain by Monday 12:00 UTC.

  • Any Hugging Face causal-LM architecture; custom ones need a reviewed pull request.
  • Optional self-test: pass or fail on a sample dataset, 12 calls per day, CPU only.

Validator High barrier

Runs the weekly enclave evaluation and sets weights; in practice the owner's slot does this.

  • The private dataset comes from the team's backend, which refuses enclave images it has not approved (allowed 2026-10-28: dstack-0.5.12).
  • On 2026-10-31: 11 permits, 6 weight setters, all on one top entry; the owner's validator last set weights 2026-10-27.

Getting started

  1. Read docs/miner.md and check the live round page for the vintage year.
  2. Train a model of at most 2.2B parameters on pre-cutoff data; upload it to Hugging Face as safetensors.
  3. Optionally run the self-test, then register a hotkey on subnet 38.
  4. Pin the model to a commit SHA, submit before Monday 12:00 UTC and make the repository public within an hour.

Caveats

  • The evaluation data, backend and config are team-run with no change log; a zero score cannot say why.
  • One evaluator decides in practice: the owner's slot posted the results of rounds 13 to 16.
  • Copy checks have gaps: editing a file after submitting keeps the earlier timestamp (confirmed bug) and a reshuffled vocabulary passed (fix open).
  • Fairness and self-mining accusations (2026-10-12, 2026-10-29) are unresolved; the team gave no reason for the price falls. Customer claims are chat statements.
