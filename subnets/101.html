What it is

Tag101 tags X posts. Validators send posts from a team-run database to miners, who return up to three short tags. No tag is 'right', so rewards depend on how a miner's tags compare with other miners' tags and the post. The team plans to sell the tags as trend and search signals via SignalFeed.

How it works

Miners

A validator sends each miner an X post about every 15 minutes; the miner returns up to 3 short tags, using an OpenAI-compatible model (the stock miner) or its own logic.

Validators

Validators score answers with a shared scorer: all tags on a post are grouped into clusters, and a tag scores higher when different miners back it and it fits the post. Scores are averaged over 24 hours and become weights.

Incentive

A miner's reward depends on the others' answers by design. Emission splits 18% owner, 41% validators, 41% miners. A 90% weight share to UID 0 was switched off in code on 2026-10-08; the chain agrees. Emission was off 2026-07-03 to 07-31 during talks with the OpenTensor Foundation.

Who earns

  • 241 of 256 UIDs earn incentive; the best (UID 28) 0.6%, the top five 2.7% (2026-11-07).
  • The 247 miner UIDs sit under 27 coldkeys: one holds 115, another 23 (56% of UIDs together, 65% of incentive). The 115 earn 56.5% for 47% of miner UIDs; that coldkey holds 3.5% of staked alpha over 170 hotkeys.
  • At least 23 of the 27 coldkeys hold a UID registered since 2026-10-30. A member links eight smaller coldkeys to one funder (not tested); the team said smaller groups still score high.

Who sets the weights

  • The owner's wallet held 57.7% of staked alpha on 2026-11-07, all on its validator (UID 0), which takes 63.9% of dividends.
  • Shared scoreboards are blended only if they cover over half of validator stake; the owner's validator holds about 86%, so the blend follows it.
  • UID 56, an outside validator seen on at least seven other subnets, takes 8.7% of dividends. On 2026-11-05 a new registration took UID 218 from the ninth validator; its hotkey re-registered at UID 150 two blocks later and holds a permit.

Getting started

  1. Register a hotkey on netuid 101 (burn 0.011 to 0.038 TAO since 2026-11-01; a new UID replaces another and is protected for about a day).
  2. Clone github.com/tag101-ai/tag101, install Python 3.12 and run pip install -e . in a virtual environment.
  3. Copy deploy/miner.docker.example (PM2 files are alongside), fill in wallet, port, public IP and OPENAI_API_KEY, then build and start with the README's docker_node commands.
  4. Validators use validator.docker.example. Check your miner is being asked via the status link below.

Caveats

  • A chain key shows no person: who runs the 27 miner coldkeys is unknown.
  • Scores depend on other miners; only identical token sets are penalised, so one-token variants count separately.
  • Tasks and miner announcements run through a team server; validator versions and SignalFeed usage are hidden. Chat after 2026-10-31 was unreadable.
