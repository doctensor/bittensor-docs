What it is

Tag101 tags X posts. Validators send posts from a team-run database to miners, who return up to three short tags. No tag is 'right', so rewards depend on how a miner's tags compare with other miners' tags and the post. The team plans to sell the tags as trend and search signals via SignalFeed (sign-in needed).

How it works

Miners

A validator sends each miner an X post about every 15 minutes; the miner returns up to 3 short tags, using an OpenAI-compatible model (the stock miner) or its own logic.

Validators

Validators score answers with a shared scorer: all tags on a post are grouped into clusters, and a tag scores higher when different miners back it and it fits the post. Scores are averaged over 24 hours and become weights.

Incentive

A miner's reward depends on the others' answers by design. Emission splits 18% owner, 41% validators, 41% miners. A 90% weight share to UID 0 was switched off in code on 2026-10-08; the chain agrees.

Who earns

  • 243 of 248 miner UIDs earn something; the best earns 0.6%, the top five 2.5% (2026-10-30). On 2026-10-26 one coldkey held 125 UIDs and 67.6% of miner incentive; nine held 230 UIDs and 99.0%.
  • A member's review links the eight smaller coldkeys to one funder (not tested here). On 10-30 the team said smaller groups still score high; a member asked which independent UID does and had no answer yet.

Who sets the weights

  • The owner's wallet holds 57.9% of staked alpha, all on its validator (UID 0), which takes 63.8% of dividends (2026-10-30).
  • Validators use a blend of shared scoreboards only if it covers over half of validator stake; the owner's validator holds about 85% of validator-hotkey alpha, so a blend largely follows it.

Getting started

  1. Register a hotkey on netuid 101 (burn 0.0356 TAO on 2026-10-30; a new UID replaces another and is protected for about a day).
  2. Clone github.com/tag101-ai/tag101, install Python 3.12 and run pip install -e . in a virtual environment.
  3. Copy deploy/miner.docker.example (PM2 files are alongside), fill in wallet, port, public IP and OPENAI_API_KEY, then build and start with the README's docker_node commands.
  4. Validators use validator.docker.example. Use the status link below to check your miner is being asked.

Caveats

  • A chain key shows no person: who runs the nine coldkeys is unknown.
  • Scores depend on other miners by design; only identical token sets are penalised, so one-token variants count separately.
  • The coldkey grouping dates from 2026-10-26; a member put the leader at 117 UIDs on 10-28 (not checked).
  • Tasks and miner announcements run through a team server; validator versions and SignalFeed usage are not visible.
