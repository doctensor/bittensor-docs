What it is

GPUForge is a proposed subnet for verifiable GPU training: a publisher signs a training job, miners run it on H100 GPUs in a sandbox, and validators score only work they can verify. The public code is a pre-alpha library with no miner or validator, yet netuid 47 has emitted since 2026-01-17 and one uid collects all miner rewards.

How it works

Miners

Intended design: report H100 capabilities, attest hardware where supported, run a signed training job in an isolated sandbox, and return signed results and timing. No miner release exists. On chain, uid 149 (registered 2026-09-13) takes all incentive, is not linked to the owner's keys and has never set weights; its software is not known. Its coldkey is the largest alpha holder (24%, up 5% in 53 h).

Validators

Intended design: issue challenges, check attestation, correctness and throughput, then turn verified results into weights. The repo has verification libraries but no validator program and no weight-setting code. On chain, 10 of the 11 permit holders have set weights; 7 (all 6 active ones included) give uid 149 their top weight; uid 149 has set none.

Incentive

Planned rule: score verified work only; the site says final scoring rules are still being defined. Chain on 2026-11-13: about 5,888 alpha a day is emitted; uid 149 gets 50% and validator uid 1 32%; the owner's uid 0 fell from 33% to 0.05%. Emission is not proof of work done.

Roles and requirements

Miner High barrier

Intended: run signed training jobs on an H100 in a sandbox and return signed evidence. Nothing to run yet.

  • Anyone can register a uid, but no published software earns anything today.
  • The README warns against running untrusted jobs or production wallets with the current code.
  • Pay: one uid is paid, about 3.5 TAO a day gross (2026-11-13).

Validator High barrier

Intended: issue challenges and score verified results. No validator program is published.

  • 11 of 64 permit slots are held, 6 by active validators; 5 holders have not set weights for over 5 tempos (chain, 2026-11-13).
  • Owner uid 0 went quiet on 2026-11-09; the 3 validators favoring it have been silent 76 to 193 days.

Getting started

  1. No supported way to mine or validate yet; the README says instructions come later.
  2. Registering a uid costs 0.05 TAO (2026-11-13), but nothing published says what to run.
  3. Developers can read the README and run its offline configuration checks and unit tests.
  4. Follow the repository and the team's chat for a release announcement.

Caveats

  • Nothing the team published describes a running GPUForge network. What the 159 registered uids run is not known.
  • Handovers are chat-only: the chain shows only identity rewrites (2026-08-27, 2026-09-21); no owner-key change is dated.
  • Stored split gives miners 69.4%, but the chain readout gives uid 149 50% of emission; the real ratio is unseen.
  • Capability reports are self-reported; the README says the sandbox and attestation code is not approved for untrusted work.
  • No team post after 2026-09-30 in the chat read; chat since 2026-10-31 was not read (archive unreachable 2026-11-13).
