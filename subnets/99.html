What it is

Axonry (netuid 99) is a competition to improve a small language model by editing its weights. 187 entries since 2026-11-19; uid 127 now holds all incentive.

How it works

Miners

A miner writes a method, commits its digest on chain and opens a pull request; after review an AI agent runs it on 4 RTX 4090 for up to 6 hours. One hotkey, one entry.

Validators

A public script copies the owner-signed weights file about twice an epoch; validators evaluate nothing.

Incentive

A winning edit is worse on no benchmark and clearly better on two, judged against the current champion, and takes all the weight. The owner's file burned half on 11-19 and burns nothing since 11-21.

Getting started

  1. Install the tool (pip install axonry), read the competition repo's rules and try an idea with its toolkit.
  2. Fund the coldkey's account (16 entries wait for funds), commit the method's digest on chain, open the pull request within 24 hours.
  3. To validate: run axonry-validator with a permitted hotkey.

Caveats

  • Method, rules and results come from the team's own repos and files, and the owner runs the scoring; no outside audit. Scores of decided entries were re-graded on 11-20.
