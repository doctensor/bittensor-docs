What it is

Thirty Spokes is a model-routing subnet. Miners train a 'conductor', a fine-tune of Qwen3.6-35B-A3B, that hands agentic tasks to OpenRouter models. One owner-run validator duels each challenger against the king and scores quality minus cost. Public results stop at 2026-10-01.

How it works

Miners

A miner submits full weights on the pinned architecture (about 70 GB, bf16, no adapters). The 'conductor' picks an OpenRouter model for each agentic task and never writes the answer; worker calls run on the miner's own key.

Validators

One owner-run validator replays the king and each challenger on the same fresh slice of HLE and LiveCodeBench tasks, scoring quality minus a measured price. A challenger needs a paired gain above 0.05 plus three robustness checks. Each window publishes a reveal.

Incentive

Documented: king 85%, five ex-kings 5, 4, 3, 2 and 1%, unfilled slots burn to uid 0. On chain (2026-10-30): 85.0% on uid 25, 15.0% on uid 18, the former king. The owner hotkey earns 86.6% of dividends; owner cut 18%.

Getting started

  1. Check the public store's latest window first: still window 84 (2026-10-01) on 2026-10-30.
  2. Create an ed25519 hotkey (pass --crypto-type ed25519 to btcli) and register on netuid 99 (burn 0.5 TAO).
  3. Register your own OpenRouter key with a spend cap.
  4. Train full weights on Qwen/Qwen3.6-35B-A3B (bf16) and run the dev kit's local check.
  5. Rehearse on testnet netuid 526, then submit the ~70 GB tree: one shot per hotkey.

Caveats

  • The live validator goes beyond the published code (owner-set crown, 15% to an ex-king); the last commit is 2026-09-15, so what runs now is unconfirmed.
  • Weights are re-set on a timer, so a fresh update shows no active team.
  • Reveals for windows 3 to 5, 11 and 18 to 47 were never published; models.thirtyspokes.ai returned not-found (2026-10-30).
  • The owner share is a floor: other uids may sit under unrelated keys.
