What it is

SN45 pays miners for finding real-world events first. Since 4.0 (live 2026-11-11) miners search the open web for events in finance, technology, politics and sports and send each as a signed claim with its source page; validators judge the pages and set weights from a signed ledger. The output feeds AlphaRidge, the team's trading-analytics product, free for now per the team. It read news (3.x) until 4.0.

How it works

Miners

Miners send a signed claim for each new event (a merger, a rate decision, a funding round, a transfer): type, parties, figures, the source URL and a page quote. The first claim wins when its page is on the trusted list (837 sources); any other page is held 72 hours as a scoop until a trusted page confirms it.

Validators

A fixed check and a page judge (a model prompt run by the validators the API lists) test that the page states the event. Every validator rebuilds the ledger totals from signed rows, re-checks a private sample of paid claims on its own fetch and sets weights from the same data.

Incentive

Points = tier price (3 or 12) x source trust x age (full for 48 hours, a quarter at 30 days); a scoop confirmed later pays 5 times, an unconfirmed one costs 2 times as debt. A miner's share is its points over the larger of the 72-hour window total and a capacity of 100,000 points; the rest goes to burn uid 189, under the owner's keys.

Getting started

  1. Install Python 3.10+ (no GPU), clone Team-Rizzo/alpharidge-ai and run ./install.sh miner.
  2. Copy miner_env.example to .miner_env; set USER_AGENT_CONTACT and, for your own sources, MINER_FEEDS.
  3. Register with btcli subnet register --netuid 45, then run python -m neurons.miner --netuid 45.
  4. Read the trusted list (GET /dashboard/sources): only those pages win an event directly; others are held as scoops.
  5. Send a word-for-word quote from the page, keep the signed receipts and follow results on /dashboard/items.
  6. Validators: ./install.sh validator; set API_KEY only if the API lists you for page judging.

Caveats

  • Chain figures are single-epoch reads (2026-11-14). The 72-hour window opened with the switch, so launch-day claims (events up to 30 days old) may still count and the burn share may rise as they age out (inferred).
  • Pay figures are gross emission before costs and slippage; averages are a floor.
  • The live API serves a per-coldkey quality multiplier that the docs and validator code do not mention; its effect on pay is unverified.
  • Dashboard counts are team-run; both listed validators show 0 verdicts and 0 re-checks in the 7-day view.
  • Team chat after 2026-11-01 was unreadable (archive down), so announcements beyond the repos are unread.
