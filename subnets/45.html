What it is

SN45 reads financial news. Miners return a structured analysis of each article: sentiment per asset, tickers, numeric claims, quotes and event tags. Validators re-run a sample and set weights. The output feeds AlphaRidge, the team's trading-analytics product, free for now per the team. It began as a tweet classifier behind Talisman and was rebranded in June 2026.

How it works

Miners

Miners get leased batches of articles, label each relevant, borderline or irrelevant against a published rubric, prove they read it, and fully analyze only the relevant ones. Entity and sentiment models run on the miner's GPU, plus two LLM calls through the miner's own OpenRouter key (default DeepSeek V4 Flash): about 12 to 18 seconds per article.

Validators

Validators fetch articles from the team's coordination API, lease them to miners and re-run the analysis on a sample of each returned batch (code default: one article). A failed sample discards the whole batch unpaid; validator-side errors cost the miner nothing.

Incentive

Accepted articles earn a small fee, relevant ones a larger premium; points are priced in dollars (code default 4 cents), turned into a share of miner emission and scaled by reputation. What no verified work claims is weighted to burn uid 189, under the owner's keys (58% of incentive on 2026-11-07).

Validator High barrier

Leases articles to miners, audits samples and sets weights.

  • The team API admits any hotkey with a validator permit and stake above its threshold; there is no manual whitelist.
  • 10 of 64 validator slots are held; 9 set weights (the tenth is the burn uid), and only uids 3 and 176 (64% of dividends) report to the team API.

Getting started

  1. Check the hardware (8 GB VRAM GPU, 8 cores, 60 GB disk) and get an OpenRouter API key.
  2. Clone Team-Rizzo/alpharidge-ai, create a Python 3.12 virtual environment and run install.sh (about 44 GB of models).
  3. Copy miner_env.example to .miner_env and set API_KEY (validators: vali_env.example).
  4. Register with btcli subnet register --netuid 45, then run python -m neurons.miner --netuid 45.
  5. Behind nginx set underscores_in_headers on; if every batch is invalid, check the OpenRouter key and balance.
  6. Stay on the latest release and watch #alpharidge for update calls.
