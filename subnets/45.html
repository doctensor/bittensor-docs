What it is

SN45 pays miners for finding real-world events first. Since 4.0 (live 2026-11-11) miners find events in finance, technology, politics and sports and send each as a signed claim with its source page; validators judge the pages and set weights from a signed ledger. The output feeds AlphaRidge, the team's free trading-analytics product.

How it works

Miners

Miners send a signed claim for each new event: type, parties, figures, the source URL and a page quote. The first claim wins when its page is on the trusted list (837 sources); any other page is held 72 hours as a scoop until a trusted page confirms it.

Validators

A fixed check and a page judge (a model prompt run by the validators the API lists) test that the page states the event. Every validator rebuilds the ledger totals from signed rows, re-checks a private sample of paid claims and sets weights from the same data.

Incentive

Points = tier price (3 or 12) x source trust x age. Under the lead table (dashboard, since 11-26) an event pays 0.25 times and a confirmed scoop up to 10 times by its lead over the first trusted page; an unconfirmed one costs 1 time as debt. A miner's share is its points over the larger of the 72-hour window total and a capacity (16,000 points); the rest goes to burn uid 189, under the owner's keys.

Getting started

  1. Install Python 3.10+ (no GPU), clone Team-Rizzo/alpharidge-ai and run ./install.sh miner.
  2. Copy miner_env.example to .miner_env; set USER_AGENT_CONTACT and, for your own sources, MINER_FEEDS.
  3. Register with btcli subnet register --netuid 45, then run python -m neurons.miner --netuid 45.
  4. Read the trusted list (GET /dashboard/sources): only those pages win an event directly; others are held as scoops.
  5. Send a word-for-word quote from the page, keep the signed receipts and follow results on /dashboard/items.
  6. Validators: ./install.sh validator; set API_KEY only if the API lists you for page judging.
