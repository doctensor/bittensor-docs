What it is

Data Universe is Macrocosmos's subnet for collecting public social-media data, mainly X posts and Reddit posts. Miners scrape and store the data, upload bulk snapshots for jobs the network requests, and answer live on-demand requests; validators re-scrape samples to check it. The team sells the resulting data through its Gravity scraping jobs, Nebula visualisation, dataset marketplace, SDK and MCP tools.

How it works

Miners

Scrape X and Reddit with Apify actors or their own scrapers (a custom scraper is recommended in the miner doc). Each miner is scored on three paths: P2P (an index of locally stored data buckets), S3 bulk upload (one Parquet snapshot per active Gravity job, about every 2 hours) and on-demand (polling every 5 seconds for live requests from customers and returning scraped rows). Miners need no GPU.

Validators

S3 uploads are checked by one designated Macrocosmos-run validator whose result the others fetch. It samples files committed to a block hash, checks file format, duplicates, empty rows, job match (at least 95%) and live re-scrapes 20 entities (at least 80% must match). On-demand submissions are sampled hourly: up to 3 per miner, 5 entities schema-checked and 1 re-fetched from the live source. Scraper outages count as neutral rather than as a miner failure.

Incentive

In the code, a miner's score is P2P (capped at S3 plus on-demand) plus S3 plus on-demand, and the S3 term is capped at twice the on-demand term, so a miner with no on-demand activity earns nothing from bulk data (the code calls this cap temporary). S3 credit grows with the square of effective data size and is scaled by credibility to the power 2.5. After normalising, the validator code sends 70% of weight to the owner UID as a burn and spreads the rest over miners.

Getting started

  1. Read the miner data compliance policy at the top of the repo README.
  2. Check that your scraper can fetch data before paying to register: the miner guide shows a curl test for Reddit, which currently blocks unauthenticated JSON requests, and says the registration fee is non-refundable.
  3. Clone the repo, install it in a Python 3.10 or newer environment, and set up an Apify token or your own scraper.
  4. Create a wallet and register a hotkey on subnet 13.
  5. Start the miner with python neurons/miner.py --netuid 13 and your wallet and hotkey names (the miner guide uses pm2); --offline pre-scrapes without answering validators.
  6. Watch the channel and releases: there is no miner auto-updater, so miner-facing changes are announced there.

Caveats

  • Chain weights, emissions and registration costs were not read; the 70% burn is what the validator code on main applies, and a team statement on 2026-09-23 said it was unchanged then.
  • The scoring doc, S3 doc and README were last edited in February 2026 and lag the code (the scoring doc still lists YouTube weights); the contributor guide AGENTS.md (2026-10-01) says the code is right where they disagree.
  • The team site lists YouTube as a data source, but the miner code only has X and Reddit scrapers.
  • Chat shows the Gravity job list shrinking to single digits in August, standing near 1,000 by mid-September, and a miner reporting it flipping between about 1,000 and 1 on 2026-10-07; the team said on 2026-10-08 it was looking at it, and a fix was not confirmed. The dashboard showed 1,229 active jobs on 2026-10-21.
  • Release v1.18.74's local tag points at the 2026-10-01 commit while its release notes list the change merged 2026-10-09; the merge date is used here.
  • The version string inside neurons/__init__.py is stale (1.3.8) and is only used as the weight-setting version key.
