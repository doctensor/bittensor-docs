What it is

Data Universe is Macrocosmos's subnet for collecting public X and Reddit posts. Miners scrape, store and upload the data and answer live requests; validators re-scrape samples to check it. The team sells the data through its Gravity API, a marketplace, an SDK and MCP tools.

How it works

Miners

Miners scrape X and Reddit with Apify actors or their own scraper. They are scored on three paths: P2P (locally stored data), S3 (a Parquet snapshot per active job, about every 2 hours) and on-demand (live customer requests, polled every 5 seconds). No GPU is needed.

Validators

One Macrocosmos-run validator checks S3 uploads (format, duplicates, 95% job match, 20 entities re-scraped with 80% matching) and the others fetch its result. On-demand answers are sampled hourly. Scraper outages count as neutral. Validator dividends are concentrated: the top validator earns 54.9%.

Incentive

Score = P2P (capped at S3 plus on-demand) + S3 + on-demand. S3 is capped at twice on-demand, so bulk data alone earns nothing. The validator code then gives the owner UID exactly 70% of the weight, a burn, and the rest goes to miners; the chain agrees (70.95%). Stored split: 18% owner, 41% validators, 41% miners.

Roles and requirements

Miner Low barrier

Scrape and store X and Reddit data, answer live requests.

  • Pay: about 0.015 TAO a day on average for each of 234 non-owner UIDs (gross, 2026-10-30).
  • Bulk uploads alone earn nothing; a miner must also answer live requests.
  • Reddit blocks unauthenticated JSON (403, 2026) and has refused API approval for AI-training use.

Validator Medium barrier

Re-scrape samples of miner data and set weights; the code puts 70% on the owner UID.

  • 9 UIDs hold permits; 8 set weights within a tempo, the ninth (the owner UID) is idle since 2024.
  • The validator doc is from January 2024; its clone URL is a personal fork.

Burn history

  • 2026-03-10 (v1.17.0): S3 re-enabled, burn cut from 90% to 70%.
  • 2026-07-24: burn removed (v1.18.68); 07-28: 70% restored while the team reviewed emission flow (v1.18.69).
  • Miners asked for a cut on 04-14, 04-22, 06-05, 07-14 and 10-21; on 09-23 the team said it was not changing.

Getting started

  1. Read the data compliance policy at the top of the repo README.
  2. Test your scraper first: Reddit blocks unauthenticated JSON, and the 0.036 TAO fee (2026-10-30) is not refundable.
  3. Clone macrocosm-os/data-universe (the guide's URL is a personal fork); Python 3.10+, certifi 2026.10.19 or newer.
  4. Set up Apify or your own scraper, then create a wallet and register a hotkey on subnet 13.
  5. Run python neurons/miner.py --netuid 13 with your wallet and hotkey (pm2 in the guide); there is no auto-update, so follow the channel for releases.

Caveats

  • The chain shows weights and incentive, not payouts or intent; the team's last burn statement is 2026-09-23.
  • Usage, customers and revenue are team claims; no price or customer count is published.
  • The scoring doc, S3 doc and README date from February 2026 and lag the code.
  • The Gravity job list flipped between about 1,000 and 1 on 2026-10-07 and the team never said it was fixed; it stood at 1,235 on 10-30.
  • The version string in neurons/__init__.py is stale (1.3.8); the key it yields, 1038, still exceeds the chain minimum 1030.
