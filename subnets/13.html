What it is

Data Universe is Macrocosmos's subnet for collecting public X and Reddit posts. Miners scrape, store and upload data and answer live requests; validators re-scrape samples. The team sells the data through its Gravity API, a marketplace, an SDK and MCP tools.

How it works

Miners

Miners scrape X and Reddit with Apify actors or their own scraper. Scoring has three paths: locally stored data (P2P), a Parquet snapshot per job about every 2 hours (S3) and live customer requests (on-demand).

Validators

One Macrocosmos-run validator checks S3 uploads (format, duplicates, 95% job match, 20 entities re-scraped with 80% matching) and the others fetch its result. Since v1.18.76 its own listing or download failures usually give no verdict instead of a fail. The top validator earns 54.3% of dividends.

Incentive

Score = P2P (capped at S3 plus on-demand) + S3 + on-demand. S3 is capped at twice on-demand. The validator code then gives the owner UID exactly 70% of the weight, a burn, and the rest goes to miners; the chain shows 71.2% on that UID. Stored split: 18% owner, 41% validators, 41% miners.

Roles and requirements

Miner Low barrier

Scrape and store X and Reddit data, answer live requests.

  • Pay: about 0.013 TAO a day on average for each of 233 non-owner UIDs with incentive (gross, 2026-11-27).
  • Bulk uploads alone earn nothing; live requests must be answered too.
  • Live X requests from 11-29: stale or far too low counts fail; skipped username jobs cut the multiplier up to 30%.
  • A re-registered UID starts from zero, even with the same hotkey.
  • Reddit blocks unauthenticated JSON (403, 2026).

Validator Medium barrier

Re-scrape samples of miner data and set weights; the code puts 70% on the owner UID.

  • 9 UIDs hold permits; 8 set weights within a tempo, and the owner UID is idle since 2024.

Getting started

  1. Read the data compliance policy at the top of the repo README.
  2. Test your scraper first; the 0.014 TAO fee (2026-11-27) is not refundable.
  3. Clone macrocosm-os/data-universe (the guide's URL is a personal fork); Python 3.10+, certifi 2026.10.19 or newer.
  4. Set up Apify or your own scraper, then create a wallet and register a hotkey on subnet 13.
  5. Run python neurons/miner.py --netuid 13 with your wallet and hotkey (pm2 in the guide); there is no auto-update, so follow the channel for releases.

Caveats

  • The chain shows weights and incentive, not payouts or intent; the last team burn statement read is from 09-23.
  • Sales are inferred from pool flow and stake reads; who controls those keys is unknown.
  • Usage and revenue are unchecked team claims.
  • The new on-demand rules were read in code, before their start.
  • The scoring doc, S3 doc and README date from February 2026 and lag the code.
  • Chat after 2026-10-31 could not be read (archive unreachable).
