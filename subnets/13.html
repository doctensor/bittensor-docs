What it is

Data Universe is Macrocosmos's subnet for collecting public X and Reddit posts. Miners scrape, store and upload the data and answer live requests; validators re-scrape samples to check it. The team sells the data through its Gravity API, a marketplace, an SDK and MCP tools.

How it works

Miners

Miners scrape X and Reddit with Apify actors or their own scraper. They are scored on three paths: P2P (locally stored data), S3 (a Parquet snapshot per active job, about every 2 hours) and on-demand (live customer requests, polled every 5 seconds).

Validators

One Macrocosmos-run validator checks S3 uploads (format, duplicates, 95% job match, 20 entities re-scraped with 80% matching) and the others fetch its result. On-demand answers are sampled hourly. Scraper outages count as neutral. Validator dividends are concentrated: the top validator earns 53.7%.

Incentive

Score = P2P (capped at S3 plus on-demand) + S3 + on-demand. S3 is capped at twice on-demand. The validator code then gives the owner UID exactly 70% of the weight, a burn, and the rest goes to miners; the chain agrees (70.8%). Stored split: 18% owner, 41% validators, 41% miners.

Roles and requirements

Miner Low barrier

Scrape and store X and Reddit data, answer live requests.

  • Pay: about 0.014 TAO a day on average for each of 240 non-owner UIDs with incentive (gross, 2026-11-07).
  • Bulk uploads alone earn nothing; a miner must also answer live requests.
  • Reddit blocks unauthenticated JSON (403, 2026) and has refused API approval for AI-training use.

Validator Medium barrier

Re-scrape samples of miner data and set weights; the code puts 70% on the owner UID.

  • 9 UIDs hold permits; 8 set weights within a tempo, and the owner UID is idle since 2024.

Getting started

  1. Read the data compliance policy at the top of the repo README.
  2. Test your scraper first (Reddit blocks unauthenticated JSON); the 0.046 TAO fee (2026-11-07) is not refundable.
  3. Clone macrocosm-os/data-universe (the guide's URL is a personal fork); Python 3.10+, certifi 2026.10.19 or newer.
  4. Set up Apify or your own scraper, then create a wallet and register a hotkey on subnet 13.
  5. Run python neurons/miner.py --netuid 13 with your wallet and hotkey (pm2 in the guide); there is no auto-update, so follow the channel for releases.

Caveats

  • The chain shows weights and incentive, not payouts or intent; the team's last burn statement is 2026-09-23.
  • Usage, customers and revenue are team claims; no price or customer count is published.
  • The scoring doc, S3 doc and README date from February 2026 and lag the code.
  • The Gravity job list flipped between about 1,000 and 1 on 2026-10-07 with no team word on a fix; it stood at 1,443 on 11-07.
  • The version string in neurons/__init__.py is stale (1.3.8), but its key 1038 still exceeds the chain minimum 1030.
