What it is

TuneForge is a Bittensor subnet where miners generate music from text prompts and validators score the audio. A single maintainer runs it as a side project and would go to mainnet only if the registration price and customer demand made sense. Testnet only.

How it works

Miners

A miner runs a music-generation model on its own GPU and returns audio for a text prompt (genre, mood, tempo, key, instruments, up to 180 seconds). The default model is ACE-Step 1.5; MusicGen, DiffRhythm, HeartMuLa or your own model also work. Scoring judges the audio, not the model.

Validators

Each round the validator sends a prompt to a batch of miners and scores the audio on 16 weighted signals fixed in the code. The largest are text-audio similarity (19 percent), attribute checks for tempo, key and instruments (11), musicality (9) and lyric quality (8). Penalties apply for silence, timeouts, wrong length and matches to known songs. A learned preference model (7) stays off unless a trained file is supplied.

Incentive

Scores are smoothed with a moving average. Miners with a positive score are ranked: the top 10 share 80 percent of the weight, the rest share 20, and within a tier weight grows with the square of the score. Weights go to chain every 115 blocks (about 23 minutes). This matches the team's description of 2026-03-22. It is a design only: no mainnet emission exists and no testnet uid holds incentive.

Roles and requirements

Miner Medium barrier

Runs a text-to-music model on its own GPU and returns audio for each prompt.

  • Default model ACE-Step 1.5 (MIT licence): about 10 GB VRAM in the guide and README, about 4 GB in the example miner config.
  • Other models: MusicGen Large (16 GB, non-commercial licence), DiffRhythm and HeartMuLa 3B (8 to 10 GB).
  • The dashboard and API docs are for registered neurons only (team, 2026-03-16) and could not be reached.

Validator Medium barrier

Builds prompts, scores miner audio and submits weights; can push rounds to the team's platform.

  • Testnet: 61 of 71 uids hold a permit (64 slots) but none has set weights in over 5 tempos; the last update dates to about 2026-06-10.
  • Rounds run every 240 seconds. Scoring weights are hard-coded for consensus; settings cannot change them.
  • The example config points at the team's platform API (round data out, preference model in hourly); not reachable.

Getting started

  1. Testnet only, no rewards. You need an NVIDIA GPU: about 10 GB VRAM for the default model per the miner guide (16 GB per min_compute.yml).
  2. Clone the repo linked below; the README's own clone address (another GitHub account) returned 404 on 2026-10-31.
  3. Install with pip install -e . (Python 3.10 to 3.12) or Docker; the default model also needs a clone of the ACE-Step 1.5 repo.
  4. Copy .env.miner.example to .env.miner (it already sets netuid 234 and the test network) and add your wallet and hotkey names.
  5. Register with btcli subnet register --netuid 234 --subtensor.network test (burn 0.0005 test TAO, 2026-10-31), then start the miner. With no validator setting weights, expect no score.
