What it is

Witness is a contest for video-understanding models. Miners submit fixed model weights; validators run each on the same private clips and score its timestamped claims. The best model becomes the 'king' and takes all miner pay.

How it works

Miners

One package of full weights per hotkey (24 GB for SALMONN 2 Pro or Qwen2.5-Omni, 44 GB for Qwen3-Omni), served from a CPU server and committed by hash on chain. The first commitment binds the hotkey to that model for good.

Validators

Each window (about 2.4 hours) an evaluator draws 10 of 1,000 public videos, cuts 2 clips from each and scores king and challengers against two reference passes. Results go on chain; CPU followers replay them.

Incentive

Reward = quality x (0.9 + 0.1 x speed). A challenger needs stake-weighted quality above 0.05 and a lead over the king above 0.02. The king gets 100% of validator weight, nothing burned since 2026-09-30; with no king, all is burned.

Roles and requirements

Miner Medium barrier

Submits one video-model package and serves it to evaluators; the top model takes all miner pay.

  • Evaluators allow 15 minutes of download per model; slow servers are dropped from the queue unscored.
  • 2026-10-23: 41 model commitments, none scored after 2026-10-06.

Validator Medium barrier

Follower: replays chain records to find the king and sets weights; no GPU.

  • Docs: a follower needs no GPU, ffmpeg, API keys or model downloads, but a chain endpoint with historical state.

Evaluator High barrier

Runs contenders on private clips and publishes results; needs a GPU and an API key.

  • Evaluator mode can spend GPU and API money; the API daily limit is unset by default. Disk: five maximum-size packages plus 20 GB (docs).

Who is paid and who gets what

  • Uid 94 held 100% of incentive in every sample since 2026-10-03, after five other uids. It never set weights; no owner link on chain.
  • The owner's wallet holds about half of all alpha; its validator earns 58% of dividends. The 33% owner cut is about 3.7 TAO a day against 6.6 for the paid miner (configured, gross).

Getting started

  1. First check that contests are scored: the dashboard was down on 2026-10-30 and the newest result record seen dates from 2026-10-06.
  2. Read docs/miner.md and docs/launch.md, then prepare a full-weights package with the miner tool.
  3. Register a hotkey (0.2 TAO burn on 2026-10-30), serve the package from a public IP and publish the commitment.
  4. A follower also needs the release's activation block and epoch; an evaluator needs a GPU, an OpenAI key and 100,000 alpha.

Caveats

  • Chain figures date from 2026-10-30; result-record and commitment counts from 2026-10-23.
  • Who runs uid 94 is unknown; 'not owner-linked' does not rule out shared control.
  • The crown follows published results; on 2026-10-23 only the owner's validator, which holds half of all alpha, had published one. A design property, not proof of misbehaviour.
  • Reference labels and sampling secrets are private, so scores cannot be recomputed.
