What it is

Netuid 26 was re-registered on 2026-11-15 after the Perturb project was removed. On 2026-11-21 its owner set the name Pocket, a site and an open-source miner kit. Miners enter a Harness for personal AI agents in two-week rounds; the winner takes all miner emission. One uid, 216, has 100% of incentive; the owner's uid 0 and two outside validators put all their weight on it.

How it works

Miners

Write a Harness (agent engine) in Node, test it with the local practice runner, keep it private on Hugging Face, commit its hash on chain, then publish it in the hour after the round cutoff.

Validators

The operator scores each round and publishes results; a validator copies the champion's uid with full weight (65,535) and keeps old weights if a check fails.

Incentive

Incentive is 100% on uid 216 and miner emission is no longer burned. Last epoch: uid 216 50%, owner uid 0 36%, uid 176 11%, uid 116 2.3%.
