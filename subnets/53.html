What it is

engy sells LLM inference on subnet 53. Buyers call one OpenAI- and Anthropic-compatible API with prepaid billing; GPU miners serve open models such as Kimi K3, GLM and DeepSeek. The team's master validator scores the work and signs the weights other validators copy.

How it works

Miners

Miners boot the team's Docker image on a GPU host with a gateway key and declare a model and SSH port; the team verifies and activates the box. The gateway sends buyer requests round-robin to workers with room.

Validators

The master validator is the owner hotkey: it scores miners from the gateway log, samples requests for verification (per the team) and signs one result per 7-day epoch. Outside validators on a CPU check the signature and resubmit it about every 24 minutes.

Incentive

A miner's score is the dollar value of its billed work in a 7-day epoch (docs: tokens times a team rate), applied on chain the next epoch. Split: 18% owner, 41% validators, 41% miners, none burned.

Roles and requirements

Miner High barrier

Runs a GPU box on the team's image; the gateway sends it paid requests.

  • The image accepts only the team's SSH key; touching the box counts as cheating (team, 2026-09-27).
  • A miner said on 2026-10-22 SSH access blocks container hosts without nested Docker.
  • Team, 2026-10-27: start with one node; a large DeepSeek V4.1 Flash cluster may not pay.

Validator Medium barrier

The master validator is the team's; outside validators copy its signed weights.

  • 2026-10-29: 17 uids hold permits, 12 updated weights in the last 72 minutes.
  • The master hotkey takes 40% of validator dividends, the top five 92%.

Getting started

  1. Plan hardware: one H200 for DeepSeek V4.1 Flash, 8 x H100 for GLM-5.3-flash (team).
  2. Register a miner hotkey on SN53, log in at provider.engy.ai and claim a gateway key.
  3. Boot ghcr.io/hanlinai/engy-golden-serve:prod with only that key as ENGY_MINER_KEY.
  4. Declare the model and an SSH port the team can reach; wait for activation.
  5. Leave the box untouched. To validate instead, run the repo's CPU-only light validator with a permit hotkey.

Caveats

  • The master scorer is not public, and its published formula does not reproduce the signed scores.
  • Verification is unseen (no audit verdicts in epochs 17 to 19), and which hotkeys are the team's own is unpublished.
  • Usage and revenue are team data; dashboard and signed counts differ (37 vs 36 miners). No licence file.
