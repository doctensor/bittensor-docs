What it is

engy sells LLM inference on subnet 53. Buyers call one OpenAI- and Anthropic-compatible API with prepaid billing; GPU miners serve open models such as Kimi K3, GLM and DeepSeek. The team's master validator scores the work and signs the weights others copy.

How it works

Miners

Miners boot the team's Docker image on a GPU host with a gateway key, declare a model and SSH port, and the team verifies and activates the box; a TEE box is attested instead and gets more traffic. The gateway sends buyer requests round-robin.

Validators

The master validator is the owner hotkey: it scores miners from the gateway log, samples requests to verify (per the team) and signs one result per 7-day epoch. Outside validators check the signature and resubmit it.

Incentive

A miner's score is the dollar value of its billed work in a 7-day epoch; a model row serving under 95% of requests scores zero. Split: 18% owner, 41% validators, 41% miners, none burned.

Getting started

  1. Register a miner hotkey on SN53, log in at provider.engy.ai and claim a gateway key.
  2. Boot ghcr.io/hanlinai/engy-golden-serve:prod with only that key as ENGY_MINER_KEY.
  3. Declare the model and an SSH port the team can reach; wait for activation.
  4. Leave the box untouched. To validate instead, run the repo's CPU-only light validator with a permit hotkey.

Caveats

  • The master scorer is not public, and its published formula does not reproduce the signed scores.
  • Verification is unseen (no audit verdicts in epochs 17 to 21); which hotkeys are the team's is unpublished.
  • Usage and revenue are team data; dashboard and signed counts differ. No licence file.
