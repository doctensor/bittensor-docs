What it is

engy sells LLM inference on subnet 53. Buyers call one OpenAI- and Anthropic-compatible API with prepaid billing; GPU miners serve open models. The team's master validator scores the work and signs the weights others copy.

How it works

Miners

Miners boot the team's Docker image on a GPU host with a gateway key, declare a model and SSH port, and the team verifies and activates the box. The gateway sends buyer requests round-robin.

Validators

The master validator, the owner hotkey, scores miners from the gateway log, samples requests to verify (per the team) and signs one result per 7-day epoch; outside validators resubmit it.

Incentive

A miner's score is the dollar value of its billed work in a 7-day epoch; a model row serving under 95% of requests scores zero. Split: 18% owner, 41% validators, 41% miners, none burned.

Getting started

  1. Register a miner hotkey on SN53, log in at provider.engy.ai and claim a gateway key.
  2. On 8 x B200 or B300, run engy-onboard.sh from provider.engy.ai with ENGY_MINER_KEY and --model.
  3. The team verifies and activates the worker; other hardware needs a TEE host.
  4. To validate instead, run the repo's CPU-only light validator with a permit hotkey.

Caveats

  • The master scorer is not public, and its published formula does not reproduce the signed scores.
  • Verification is unseen (no audit verdicts in epochs 17 to 22); which hotkeys are the team's is unpublished.
  • Usage and revenue are team data; dashboard and signed counts differ. No licence file.
