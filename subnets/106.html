What it is

Nodexo is a GPU rental marketplace. Miners register GPU hosts and keep proving the hardware is real; validators check the proofs, test idle machines by renting them and weight each machine by a fixed hourly price.

How it works

Miners

Run the miner on an Ubuntu host with a supported NVIDIA GPU, Docker and sysbox. Each GPU endpoint is one executor in an on-chain registry that answers a timed proof about every 3 minutes and starts rental containers on request.

Validators

Validators check proofs and heartbeats on a CPU, score every executor and set weights about every 72 minutes. Only the primary validator rents idle machines to itself (canaries) to test them; follower mode copies its scores.

Incentive

Score = the GPU model's fixed hourly price x GPU count x (1.0 if rented, 0.8 if idle) x pass rate squared. It is zero if any gate fails: valid recent proof, canary, heartbeat, sybil check, minimum version, alpha stake or reliability of 0.67. The live config burns nothing.

Roles and requirements

Miner Medium barrier

Host a verified GPU, answer proofs and run rental containers.

  • Ports 8091 (API) and 20000-20100 (rentals) must be reachable; Cloudflare's HTTP proxy does not carry the rental ports.
  • Accepted GPUs (site docs): B200, H200, H100, RTX PRO 6000, A100, RTX 5090, 4090, A6000.

Validator Medium barrier

Verify proofs, score machines, set weights; rentals and canaries run only on the primary validator.

  • The primary validator's key is the owner's hotkey (uid 0), which earns dividends but no incentive.

Renter Low barrier

Rent verified GPUs by the hour through the team's web app, CLI or API.

Getting started

  1. Ask in the channel first: the team plans to hand 106 to a new team. Check your GPU is on the supported list.
  2. Prepare an Ubuntu host that meets the miner requirements above and a hotkey registered on netuid 106.
  3. Run install.sh or scripts/setup_miner.sh, fund the miner's EVM address with TAO for gas, hold the alpha stake your GPUs need, start under PM2.
  4. Serve the API on a real HTTPS domain, keep ports 20000-20100 reachable; expect no score until proofs are valid and a canary passes.

Caveats
