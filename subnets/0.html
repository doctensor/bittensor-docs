What it is

Netuid 0 is the root network. The chain docs say it has no miners, no alpha token and no validation work: it is the pool where TAO is staked directly, and a chain read on 2026-10-23 put nearly half of all issued TAO there. Root stake counts toward validator stake weight on every subnet and earns a share of each subnet's dividends. Since Root Reborn (runtime v441, mid-2026) that share is no longer sold for TAO every block; it builds up as a per-validator basket of subnet alpha that stakers claim. The Discord channel for netuid 0 (#rao) is also where chain-wide changes, such as registration rules, emission splits and consensus modes, are announced and argued over.

How it works

Miners

None. The docs describe root as having no miners and no mining task. People take part by staking TAO to a root validator, or by running a validator seat.

Validators

Root validators hold one of 64 seats. A hotkey registers by burning a demand-set price (at default settings it rises about 26 percent per registration and decays with a half-life of about 72 minutes; on 2026-10-23 the price sat at its 1 TAO floor), and when the seats are full the lowest-staked validator outside its immunity period is pruned. A registered validator is a delegate (default take 18 percent) and runs one fund: each epoch its root dividends from every subnet are credited to its basket as that subnet's alpha. Since runtime v461 the only way to change a basket's makeup is a swap_basket trade, bounded by price, daily turnover, pool-liquidity and concentration limits (no holding above 1/16 of fund value at launch); the root weight vector validators used to set was removed. On 2026-10-23 the chain showed basket trading switched on with no fund frozen, and no root validator had set weights for at least 35 days. All 64 seats were filled and held stake, and 48 held validator permits. The largest seat held about 19 percent of the roughly 5.45 million TAO staked across seats, the top five about 63 percent and the top ten about 80 percent. Of the 64 seats, 23 charged the 18 percent default take, 17 charged 9 percent and 12 charged nothing.

Incentive

Root stakers are paid in subnet alpha in proportion to their root stake, through their validator's basket. They realize it with a claim that restakes the proceeds as TAO on root. There are no partial claims, and payouts below a small threshold (0.0005 TAO by default, confirmed on chain) wait until they clear. Since Etao (v481) the chain pays root its baseline share off the top of each subnet's validator slot every block, so a subnet owner who changes the emission split cannot lower it. About three days after Etao went live, 11 of 128 subnets had moved off the default owner/validator/miner split of 18/41/41 percent, and none of them burned or recycled any share. How TAO emission is divided between subnets comes from each subnet's moving-average price, adjusted for owner-directed miner incentive and an emission gate, according to the emissions docs. The chain's TAO weight, which scales root stake against alpha stake in validator stake weight, read 0.18 on 2026-10-23, as the docs say.

The pull request was still open on 2026-10-23, so none of it is on the chain.

The website still listed it as upcoming on 2026-10-23 although two subnets already used it.

Getting started

  1. Install the bittensor Python package and use the btcli that ships with it; the team said on 2026-10-02 that the separate bittensor-cli package is deprecated.
  2. To stake, compare root validators with btcli root list (holdings, fund value, return), then stake TAO on netuid 0 with btcli stake add --netuid 0 and the validator's hotkey. The root guide's other way in is btcli root allocate.
  3. Check accrued yield with btcli stake list or btcli root list --mine, run btcli root claim --dry-run to see the fee against the yield, then btcli root claim. Unstaking returns principal only; unclaimed yield stays owed.
  4. To run a root validator, read the price with btcli subnets burn-cost 0 (it stood at its 1 TAO floor on 2026-10-23), preview with btcli subnets register --netuid 0 --dry-run, register, and stake TAO on your own hotkey straight away, because an unstaked seat is the first to be evicted.
  5. Basket trading (btcli root swap) was enabled on the chain on 2026-10-23, but the root guide still calls it testnet-only and needs an SDK release from runtime v461 or later. Check the guide and your btcli version before trading, and expect the price, turnover and concentration limits to bind.

Caveats

  • Netuid 0 has no mining task. This page covers the root layer and the chain-wide changes discussed in #rao, and that channel is mostly general chain and market discussion.
  • Chain figures are a snapshot at blocks 9342487 to 9343001 (2026-10-22 to 2026-10-23). Registration settings, the TAO weight, the basket switch and Etao splits can be changed by governance or subnet owners at any time. The current subnet registration price (about 708 TAO) was calculated here from the code formula and the last paid cost, not read from the chain's own quote.
  • Docs and code defaults lag the chain. The repo defaults (14-day lock interval, 1-day gap between registrations, 1,000 TAO lock-cost floor) differ from the live values (8 days, 2 days and a floor of 1 TAO). Trust the dated chain read over the docs for current values.
  • Mainnet runs runtime v483 (since 2026-10-22), but the repo's main branch and GitHub releases stop at v482 and the website's release list stops at v481. What v483 changed was not found.
  • Basket trading is switched on in chain state, yet the Root Reborn guide still calls btcli root swap testnet-only. How much basket trading happens was not measured.
  • Null consensus is live on two subnets even though the website lists it as upcoming. Its UID capacity is 2,500 in the code, the docs and a team statement but 16,000 on the website's release list; this page follows the code. A Null subnet's single top-staked validator is not checked by consensus; a team member said only stakers moving away constrains it.
  • The root network's old incentive and dividend vectors still hold values, but no root validator has set weights for at least 35 days (the freshest weight on 2026-10-23 was about 35.6 days old). Whether those vectors affect any payout was not checked.
  • The gamma-token proposal appears only in chat. The repo reserves later emission slots for a future runtime, but no details were found.
  • Chat claims about particular subnets (emission share, registration tricks, owners deleting messages) were not verified and are left out. Treat chat as what was said, not as a record of what happened.
  • Etao, Null and basket behavior come from the repo docs, code constants and chain storage reads; the code was not audited. The repo was read at its 2026-10-21 state (v482).
  • Chat read: all of #rao from 2026-10-19 to 2026-10-22, the earlier window (latest 200 messages to 2026-10-18, team posts since 2026-09-18) and #announce. The older root channel was not read, and the outcome of the 2026-10-22 Novelty Search was not.
