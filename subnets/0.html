What it is

Netuid 0 is the root network. It has no miners and no alpha token: it is the pool where TAO is staked directly, about 47% of all issued TAO on 2026-10-31. Root stake adds to validator weight on every subnet and earns a share of each subnet's dividends, paid as a basket of subnet alpha that stakers claim. Its channel, #rao, is also where chain-wide rule changes are argued over.

How it works

Miners

None: the docs say root has no miners. You take part by staking TAO behind a root validator or by holding a validator seat.

Validators

Root validators hold one of 64 seats. Registering burns a TAO price that rises about 26% per registration and halves in about 72 minutes; on 2026-10-29 it sat at its 1 TAO floor. When seats are full, the lowest-staked validator outside its immunity period is pruned. Each seat is a delegate (default take 18%) with its own alpha basket. Since v461 a fund changes only through bounded swap_basket trades; the old root weight vector was removed (last set about 2026-09-17), and root runs no epoch, so no code path pays from the old records.

Incentive

Stakers are paid in subnet alpha through their validator's basket and realize it by claiming, which restakes the proceeds as TAO on root. There are no partial claims; amounts under 0.0005 TAO wait. Since Etao (v481) the chain pays root its baseline share off the top of each subnet's validator slot every block, so owners cannot cut it. TAO emission between subnets follows each subnet's moving-average price (docs). The TAO weight, which scales root stake in validator weight, is 0.18.

Roles and requirements

Root validator Medium barrier

Holds one of 64 root seats and runs a basket fund, keeping a cut (default 18%) of what stakers earn.

  • 2026-10-23: the largest seat held 18.8% of staked TAO, the top five 63.4%; take was 18% on 23 seats, 9% on 17, 0% on 12.
  • 48 of 64 seats hold a validator permit; a new seat is immune from eviction for about 1 day.
  • Basket trades are capped: 2% price band, 10% pool liquidity, 1/16 concentration, 10% of fund value per day (website).

Staker Low barrier

Stakes TAO on netuid 0 behind a root validator and claims the subnet alpha that validator's basket earns.

  • Compare validators with btcli root list; the validator, not the staker, trades the basket.
  • No partial claims; unstaking returns principal only and unclaimed yield stays owed.

Getting started

  1. Install the bittensor Python package and use its btcli (the team said on 2026-10-02 that bittensor-cli is deprecated).
  2. Stake: compare validators with btcli root list, then btcli stake add --netuid 0 with a validator's hotkey (or btcli root allocate). Claim with btcli root claim, previewing with --dry-run.
  3. Run a seat: check btcli subnets burn-cost 0, preview btcli subnets register --netuid 0 --dry-run, register, then stake on your own hotkey at once.
  4. Basket trading (btcli root swap) is on in chain state, but the root guide calls it testnet-only and wants an SDK from v461; check your btcli version first.
