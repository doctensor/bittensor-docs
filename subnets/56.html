What it is

Gradients (repo name G.O.D, Gradients on Demand) runs weekly tournaments in which miners submit open-source training repositories. Validators build the code, train models on validator-managed GPUs, evaluate the results and set weights from tournament standings. The text and image tournaments serve the team's gradients.io training customers; the environment tournament was the research arm and is being shut down.

How it works

Miners

Run a miner endpoint that tells validators which GitHub repository and exact 40-character commit to enter for each tournament type. The repo must contain the required Dockerfiles and licence files, readable source and no bundled datasets or pretrained models, and must write its final model to the expected checkpoint path. Miners do not supply GPUs. Winning repos are republished publicly, so only submit code you are willing to open-source.

Validators

Validators clone the repo at the submitted commit, build its Docker image, train on managed GPUs, upload and evaluate the model. Text and image tournaments use group, knockout and boss rounds; the current champion (boss) is replaced only if beaten by a margin (1% in code). Dedup and cheat checks run in round 2, and entries have been disqualified for duplicated code, a game solver hidden in a chat template, and undeclared training data. Image evaluation uses L2 loss in latent space since late September. Tournaments are set to finish by Friday 14:00 UTC.

Incentive

Per the repo docs (as of 2026-10-19) nothing is burned: text, image and environment pools have anchor weights of 0.35, 0.25 and 0.25, adjusted by a participation balancer and rescaled to sum to 1. Within a tournament the top three ranks are paid by exponential decay (roughly 76/19/5); active participants get a token 0.0001 each; a champion's weight does not decay over time. The team removed a previous 75% miner-emission burn on 2026-09-05 and said environment emissions will move to text and image after 2026-10-23.

Getting started

  1. Read docs/miner.md in the repo: it is the team's single guide to entry, the repo contract and scoring.
  2. Build a training repo with the required Dockerfiles and licence files, pin a commit, and expose it from your miner endpoint.
  3. Hold enough TAO on your coldkey for the fee (text 0.7, image 0.4). Fees are burned and only one entry per coldkey is allowed.
  4. Check the chat announcements before each tournament: task formats are changing, including a text revamp expected in about four weeks from 2026-10-08.

Caveats

  • Environment tournaments are being discontinued; the repo still contains their code and weights until the sunset, so treat environment details as ending.
  • The text revamp (new task types and structure) was announced without a date beyond 'about four weeks', so fees, margins and weights may change.
  • Numbers come from code constants as of 2026-10-19; actual chain weights were not read.
  • A question on removing the 1% boss margin for text and image went unanswered in the chat read.
  • No revenue figures found; the team said it plans buybacks from enterprise revenue once it materialises.
