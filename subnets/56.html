What it is

Gradients runs weekly tournaments in which miners submit open-source training code for text and image models. Validators train it on their own GPUs, score the models and set weights from the standings. The team uses it to power gradients.io, a fine-tuning service.

How it works

Miners

Run an endpoint (port 7999, registered with Fiber) that returns a GitHub repo and an exact 40-character commit for each tournament type. The repo needs the required Dockerfiles, a licence and no bundled data or models. The entry fee is burned; one entry counts per coldkey, IP and GitHub account, and duplicates are screened in three tiers.

Validators

Validators build each repo, train it on managed GPUs and evaluate it. Text: a group round, pairwise knockouts, then a six-task boss round against the champion, which the challenger must win on five of six tasks. Image: three text-to-image tasks, a knockout, then six boss tasks (three edit, three text-to-image) at a 1% margin; the four new families are scored on their own training loss, not on generated pixels.

Incentive

Text is guaranteed 0.50 of weight and image 0.30; the other 0.20 follows entrant counts of earlier tournaments (now 0.65 text, 0.35 image). A champion winning by over 0.10 enlarges its type’s pool by twice the excess (none now). Six uids hold all but 0.01% of it: text ranks 1-3 and image ranks 1-3 of the 2026-11-09 tournaments, both won by the sitting champions (uids 105 and 159). Entrants of the open tournaments earn almost nothing; uid 99 draws 0.009%.

Roles and requirements

Miner Medium barrier

Submits a public training repo and commit for each tournament; validators train it on their GPUs.

  • Entry opens Monday; at least four validated miners are needed.
  • The 2026-11-09 tournaments (10 text, 8 image entrants) ended with the champions defending; the 2026-11-16 pair (8 text, 18 image) was running on 2026-11-18.
  • Code: round 2 reviews your pip packages; an unpinned git dependency still holds your entry, a failed download no longer does (2026-11-17).
  • Docs: training images must use CUDA 12.8 or lower (since 2026-11-12).
  • Docs: image tasks add an edit mode and four base models (FLUX.2 Klein, Qwen-Image-Edit, HiDream-O1, MOSS-Image).

Validator High barrier

Creates tasks, trains miners' repos on trainer GPUs, evaluates the models and sets weights.

  • The docs do not say whether outside validators run their own tournaments.
  • Code: since 2026-11-09 multi-GPU jobs run only on SXM or NVLink trainers.
  • Code: the continuous text task trains a fixed 2.5 hours; the optional subnet API listens publicly (2026-11-14).
  • Code: the trainer withdraws a throttling or faulty GPU and reruns the task without counting an attempt.

Getting started

  1. Read docs/miner.md (and docs/image_tasks.md for image) in the repo.
  2. Register a hotkey on netuid 56, register with Fiber and post your miner IP an hour before Monday's start (text 11:00 UTC, image 13:00 UTC).
  3. Build a training repo with the required Dockerfiles and licence and pin a full 40-character commit.
  4. Hold TAO for the entry fee (text 0.7, image 0.4); it is burned.

Caveats

  • Mechanism numbers come from the repo and docs; whether validators run it shows only as chain consensus.
  • Champion history comes from the team's dashboard (sn56.io); the chain shows only current payouts.
  • Usage and revenue are not published; the news page's newest post is from 2025-11-02.
