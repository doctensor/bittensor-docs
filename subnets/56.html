What it is

Gradients runs weekly tournaments where miners submit open-source code for text, image and (new) compression tasks. Validators run it, score it and set weights from the standings. The team uses it to power gradients.io, a fine-tuning service.

How it works

Miners

Run an endpoint (port 7999, registered with Fiber) that returns a GitHub repo and a 40-character commit per tournament (text, image, quant). The repo needs the required Dockerfiles and a licence, no bundled data or models; compression repos also need a decoder/ directory. One entry counts per coldkey, IP and GitHub account; duplicates are screened in three tiers.

Validators

Validators build each repo, train it on managed GPUs and evaluate it. Docs: every tournament has three one-task rounds (top 8, 4, 1 advance), then a four-task boss round. Compression shrinks the boss’s models, scored on loss or bytes. The challenger wins the crown with 5 to 7 wins in seven head-to-heads at a 1% margin (3% on freeform bytes).

Incentive

Each tournament gets a minimum plus a floating share by participation: text 0.15 to 0.40, image 0.25 to 0.50, compression 0.35 to 0.60 (API now 0.211, 0.439, 0.350). Three places split 76.2 / 19.0 / 4.8%. Compression follows the text placements until its first tournament completes, so uid 105 holds both first places for now; the code then pays that tournament’s own top three, not the old boss. Seven uids earn: text 105, 48, 89; image 99, 159, 59; uid 163 at 0.01%.

Roles and requirements

Miner Medium barrier

Submits a public training repo and commit for each tournament; validators train it on their GPUs.

  • Entry opens Monday (text 08:00, compression 10:00, image 12:00 UTC); at least four validated miners are needed.
  • The 2026-11-23 tournaments (6 text, 9 image, 20 compression entrants) were still running on 2026-11-27.
  • Docs: compression needs a decoder/ directory (1 MiB after xz); training images must use CUDA 12.8 or lower.
  • Docs: from 2026-12-07 second and third place pay more and the text boss round needs 5 of 7 tasks (1% margin stays).

Validator High barrier

Creates tasks, trains miners' repos on trainer GPUs, evaluates the models and sets weights.

  • The docs do not say whether outside validators run their own tournaments.
  • Code: since 2026-11-09 multi-GPU jobs run only on SXM or NVLink trainers; the trainer withdraws a throttling GPU.

Getting started

  1. Read docs/miner.md and your tournament’s guide in the repo.
  2. Register a hotkey on netuid 56 and with Fiber; keep your miner answering before Monday’s start.
  3. Build a training repo with the required Dockerfiles and licence and pin a 40-character commit.
  4. Hold TAO for the entry fee (0.4 to 0.7); it is not refunded.

Caveats
