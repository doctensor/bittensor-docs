What it is

Gradients (repo G.O.D) runs weekly tournaments in which miners submit open-source training code for text and image models. Validators train it on their own GPUs, score the models and set weights from the standings. The team uses it to power gradients.io, a fine-tuning service.

How it works

Miners

Run an endpoint (port 7999, registered with Fiber) that returns a GitHub repo and an exact 40-character commit for each tournament type. The repo needs the required Dockerfiles, a licence and no bundled data or models. The entry fee is burned; one entry counts per coldkey, IP and GitHub account, and duplicates are screened in three tiers. Winning repos are republished.

Validators

Validators build each repo, train it on managed GPUs and evaluate it. Text: a group round, pairwise knockouts, then a six-task boss round against the champion, which the challenger must win on five of six tasks. Image: three small tasks, a knockout, then six tasks at a 1% margin.

Incentive

Text is guaranteed 0.50 of weight and image 0.30; the other 0.20 follows entrant counts of earlier tournaments (now 0.67 text, 0.33 image). Inside a type the top three ranks get about 76, 19 and 5%. A champion winning by over 0.10 enlarges its type's pool by twice the excess (none now). Five uids hold 99.97% of incentive: text ranks 1-3 and image ranks 1-2 of the 2026-11-02 tournaments; the beaten text champion (uid 148) is paid at rank 2. Entrants still in an open tournament get about 0.009% each (none now).

Getting started

  1. Read docs/miner.md in the repo.
  2. Register a hotkey on netuid 56, register with Fiber and post your miner IP an hour before Monday's start (text 11:00 UTC, image 13:00 UTC).
  3. Build a training repo with the required Dockerfiles and licence and pin a full 40-character commit.
  4. Hold TAO for the entry fee (text 0.7, image 0.4); it is burned.
  5. Follow #gradients for overhaul news.
