What it is

CookingTAO (SN122) is a marketplace on top of other subnets: developers submit miner code, users run it through the team's platform, and validators pay the developer by how those users do on the original subnet.

How it works

Miners

The 'miners' are developers and run no daemon. A developer submits a GitHub repo with miner code for another subnet; after team review it is listed in the marketplace. Users deploy it on team servers with their own hotkey on that subnet.

Validators

Validators run the public scorer. Each cycle it takes earnings, importance factors and the developer-to-user map from the team's closed backend, reads those users' ranks and incentive on the original subnets, and sets weights.

Incentive

A user's pair score is the subnet's importance factor times 90% rank-weighted incentive plus 10% flat adoption share. Developer scores are capped at 30%; the rest goes to the owner slot, which burns it. The pool is scaled to platform earnings against a fixed 148.01 alpha per epoch; the chain pays 230.4 alpha (the stored 64%).

Getting started

  1. Developers: sign in at prod.cookingtao.com with a browser wallet, switch to Developer and ask the team for Miner Access.
  2. Developers: submit a repo for a supported subnet ; review time is not fixed.
  3. Developers: once approved, register the miner hotkey on SN122 and stake more than 1,000 alpha on it.
  4. Validators: register on netuid 122, set up Python 3.11 with bittensor 11.0.1, run neurons/validator.py with --plan-weights, then --submit-weights.
  5. Users: add credits, pick a listed miner and deploy it with a registered hotkey; read the keys and seed phrase docs first.

Caveats

  • Weights are opinions; payouts were read at four epoch ends. Who holds the three scored developer slots is not public; the team did not answer questions on 2026-10-16 and 10-17.
  • Earnings, importance factors, adopter lists, revenue, buybacks and usage come from the team's closed backend or own figures; neither validators nor the chain can test them.
  • Closed beta, no public-launch date; the Studio has no public docs. Not read: partner booklet, team X posts, metrics dashboard, marketplace, team chat after 11-02.
