What it is

CookingTAO (SN122) is a marketplace on top of other subnets. Developers submit miner code for a supported subnet, users run it through the team's platform, and SN122 validators pay the developer by how those users do on the original subnet. SN122 has no miner software of its own.

How it works

Miners

The 'miners' are developers and run no daemon. A developer submits a GitHub repo with miner code for another subnet; after team review it is listed in the marketplace. Users deploy it on team servers with their own hotkey on that subnet. The developer needs over 1,000 alpha staked on SN122 to get weight.

Validators

Validators run the public scorer. Each cycle it takes platform earnings, importance factors and the developer-to-user map from the team's closed backend, reads those users' ranks and incentive on the original subnets, and sets weights.

Incentive

A user's pair score is the subnet's importance factor times 90% rank-weighted incentive plus 10% flat adoption share. Developer scores are capped at 30%; the rest goes to the owner slot, which burns it. The pool is also scaled to platform earnings against a fixed 148.01 alpha per epoch.

Roles and requirements

Miner (developer) High barrier

Submits miner code for another subnet; scored by how users running it earn.

  • Beta: ask the team for Miner Access; a screener checks the code can beat the marketplace's top-5 earning rate (chat, 2026-10-07).
  • At most five listings per subnet; outside developers can apply to the Developers Partner Program by DM.
  • Supported on 2026-09-23: SN43, SN6, SN54, SN50, SN33, SN22, SN26; the live list is behind sign-in.

Validator Medium barrier

Runs the public scorer; weights come from the team backend's data.

  • A validator registered on 2026-10-22 set weights, so new ones can join; 12 hold permits and 6 set weights (2026-10-30).

User Medium barrier

Deploys a listed miner on team servers with their own hotkey.

  • Team example for SN33 (2026-10-10): about 20 USD to register, 1-2 USD a day compute, 6-8 USD a day earned then.
  • Docs: the seed phrase is sent encrypted and not kept after setup.

Getting started

  1. Developers: sign in at prod.cookingtao.com with a browser wallet, switch to Developer and ask the team for Miner Access.
  2. Developers: submit a repo for a supported subnet and wait for review; there is no fixed time.
  3. Developers: once approved, register the miner hotkey on SN122 and stake more than 1,000 alpha on it.
  4. Validators: register on netuid 122, set up Python 3.11 with bittensor 11.0.1, run neurons/validator.py with --plan-weights, then --submit-weights.
  5. Users: add credits, pick a listed miner and deploy it with a registered hotkey; read the keys and seed phrase docs first.

Caveats

  • Weights are opinions, not payouts. Who holds the one scored developer slot is not public; the team did not answer participants' questions on 2026-10-16 and 2026-10-17.
  • Earnings, importance factors and adopter lists come from the team's closed backend; validators cannot check them.
  • Revenue, buybacks and usage are the team's own figures; the chain cannot test them.
  • Closed beta, no public-launch date. Not read: the partner-program booklet, team X posts, metrics dashboard, marketplace.
