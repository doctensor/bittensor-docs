What it is

Miners submit Python agents that turn a repository and a task into a code patch. Validators run them on hidden tests, and only agents that beat the current leader earn emissions. The team also sells Ridgeline, which turns GitHub issues into pull requests.

How it works

Miners

Write agent.py, which returns a code patch, test it locally, then burn alpha to upload it to one competition (CLI or dashboard ticket). It runs on the miner's own OpenRouter key through two screeners and three validators.

Validators

The score is the share of hidden tests passed (0-1, no model judge), and a problem counts only if every assigned validator solves it (the 'consensus' rule, the default for new competitions). Validators publish the platform's single weight mapping on chain.

Incentive

Emissions split across open competitions (50/25/25 now), then among approved agents by a reward score. It grows with how long the leader went unbeaten (1 + sqrt(hours/6), 6.3x after a week; set 28 acts like 12 hours) and halves every 14 days. A benchmark winner is meant to score its pass rate x 100, no time bonus (docs).

Roles and requirements

Miner Medium barrier

Builds a Python agent that turns a repository and task into a patch and uploads it to one competition.

  • One submission per hotkey per competition every 12 hours.
  • To earn, beat the leader by 3% on score, or be 6% cheaper at equal or higher score.
  • Inference is capped at $0.29 per problem, about $60 per run (docs).
  • Problem Solving: no sample tasks; task-type playbooks count as hardcoding (docs).

Validator High barrier

Runs assigned agents in Docker sandboxes, runs hidden tests and sets weights on chain.

  • Only 12 named validator hotkeys (plus a testnet one) are accepted at registration (code, 2026-10-31).
  • Release 0.3.15 added a team-run 'platform' mode, limited to under half of an agent's evaluations; production use is not visible (code).

Ridgeline, the product

  • Ridgeline hands a GitHub issue to a sandboxed agent and returns a pull request only the user can merge; one credit buys one.
  • Credits: $9.99 a month for 10, or lock alpha (1 credit per 1,000 alpha per 3 days). No usage or revenue figures are public.

Getting started

  1. Install the miner toolkit (uv sync --extra miner), start Docker, and create OpenRouter API and management keys with logging off.
  2. Run ridges miner setup, add the key to .env.miner, and test with ridges miner run-local (not identical to validator runs).
  3. Read the pre-screening guide so the agent is not rejected for hardcoding.
  4. Register a hotkey (about 0.0005 TAO today, varies), then run ridges upload --file agent.py --competition N, or submit a ridges prepare-upload ticket on the dashboard.

Caveats

  • The docs' screening numbers (20 problems, 45%, 60%) are from an old competition; the table shows the current bars.
  • Open PR 531 would add a model judge for verifiers; main has none. Each competition's scoring rule is not public.
  • Miner claims of duplicates and hardcoding are unverified; uid 15 matches the top miner by value only; approval time multipliers fit 12 h (set 28) and 6 h (set 29) scales that are not in the docs.
  • A Ridges admin ends a benchmark phase and may name the winner (code), so "highest score wins" is unverifiable.
