What it is

Entangle Protocol describes itself as a decentralized cross-chain message relay network built on Bittensor. Scanner miners watch source chains for message events, relay miners compete to deliver those messages on the destination chain, and validators verify, run auctions and score both. The team pitches it as the messaging layer for apps such as buying subnet alpha from other chains and paying for subnet services cross-chain. Everything described here is team documentation; the code could not be read.

How it works

Miners

Two roles on one subnet. Scanner miners monitor chains and report cross-chain events as fast as possible; they need private, low-latency RPC endpoints. Relay miners bid in sealed auctions and, if they win, execute the delivery on the destination chain from their own funded wallets on each supported chain. Both declare their role in a health check that validators send about every 10 minutes; a miner that does not answer within 60 seconds is left out of scoring until the next successful check. The team's docs name EVM chains, Solana, Sui, Cosmos and Stellar as supported ecosystems; chat said 7 chains on 2026-05-14 and 9 on testnet on 2026-06-05.

Validators

Validators ask scanner miners for events and record the arrival time themselves, spot-check about 20 percent of reported events, maintain a shared gas-price estimate, sign verified messages, run the relay auctions and independently confirm that each relay landed on the destination chain. Scores are smoothed with a moving average and set as weights every epoch. The docs say the epoch is 100 blocks; the testnet's tempo on chain is 360, so the docs and the chain differ on this point. The docs list separate signing keys per destination ecosystem, while a 2026-05-16 team update said validators were moving to hotkey-based signing.

Incentive

Scanner score per event comes from the validator's own receipt-time ranking (values 0, 0.2, 0.5, 0.7 or 1) averaged over the window. Relay score blends five parts: delivery success 50 percent, speed 25, proof correctness 15, fee efficiency 5, reliability 5. A winning relay miner gets 0.8 times its execution score plus 0.2 times a bid-quality score; a bidder that loses gets only bid quality; no bid gets zero. The emission split is 30 percent scanners and 70 percent relays: the docs say it is an owner-set parameter, and on the testnet the chain holds two mechanisms split 30/70 (which one is which was not checked). Chain weights are validator opinions and were not traced to payouts.

Getting started

  1. Read the team's miner guide at docs.entangleprotocol.com (Running a Miner) for the role, environment and flag settings; it says scanners need private RPC endpoints and relay miners need funded wallets on every destination chain.
  2. Create a testnet wallet and register on testnet netuid 395 (btcli with --network test); netuid 395 is not registered on mainnet.
  3. The miner and validator code (neurons/miner.py in the docs) is in a GitHub repository that returned 404 on 2026-10-21, so there is no public source to run today. Ask the team in the channel where the code is before investing time.
  4. Check the validator weight age on the testnet first: if validators are not setting weights, a new miner cannot earn incentive.

Caveats

  • Testnet only. Nothing on this page describes mainnet emissions or economics; the testnet's token and pool numbers are not real value and are left out.
  • No code was read. The repository the team links (in the chain identity and the channel's first post) returned 404 and its organization shows no public repositories on 2026-10-21; whether it is private or removed was not determined. Every mechanism detail above comes from the team's docs and litepaper, not from code.
  • The demo and stats site (test.entangleprotocol.com) resolves but did not respond from our network on 2026-10-21, so the live dashboard could not be checked. The whitepaper PDF was not read.
  • The testnet looks idle: no neuron had incentive or dividends and every validator's last weight update was at least about 88 days old at block 8273002. The testnet also showed a large emission share going to one uid (about 54 percent) and to uid 0 (about 35 percent); who holds those was not traced.
  • Mainnet timing has slipped: the docs roadmap says Q1 2026, the litepaper says Q2 2026, the team said May and then mid-July in chat, and the subnet is still not on mainnet on 2026-10-21.
  • Fee flow is described three ways. The docs say 70 percent of a per-message fee goes to the winning relay miner and 30 percent to a treasury, of which 20 percent funds weekly alpha buybacks. The litepaper and a 2026-05-10 team answer say 100 percent of fees fund buybacks, with relay miners reimbursed in alpha. Revenue, message-volume and burn figures in the docs and roadmap are targets, not observed numbers.
  • Docs and chain differ on the epoch length (100 blocks in docs, tempo 360 on the testnet) and the docs still list separate per-ecosystem signing keys after a May update about hotkey-based signing.
