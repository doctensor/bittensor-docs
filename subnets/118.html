What it is

Ditto pays miners for open-source memory for AI agents. Agent miners upload a Docker harness that DittoBench scores on tool use and memory recall; generator miners upload programs that write the benchmark's test cases. The team also sells a Ditto assistant (Free, $19, $97 plans).

How it works

Miners

Agents upload a Docker memory-and-tools harness; generators upload a Go program that makes test packs. Each upload costs 0.05 TAO (one-hour cooldown). A leader's source goes public after 48 hours; building on it is allowed, an unchanged copy is not.

Validators

A team-run screener reviews each agent; an inconclusive review waits for a person. Validators run agents in a no-network sandbox with one locked model (gpt-oss-20b), grade without an LLM judge, run generator rounds and set weights from the team platform's ledger.

Incentive

Scores come from DittoBench v14 (live since 2026-10-28). The owner's uid 0 holds 50% of incentive and all 11 validators with weights favour it: that is the burn. The owner changed the split before (70% burn on 2026-10-14).

Roles and requirements

Miner (agent) Low barrier

Builds a memory-and-tools harness and competes on DittoBench.

  • Practice needs Rust 1.85+, Go 1.23+ and Ollama; uploading needs Python 3.12+ and uv.
  • Scored runs: 8 cases at once, no network (limits: docs/RUNTIME-ENVELOPE.md).

Miner (generator) Low barrier

Writes a Go program that generates benchmark test packs.

  • No network or model; output must be byte-identical on a re-run; 50% or more overlap with another owner's output is rejected.
  • 28 generators scored in 7 days; top scores 0.28 to 0.39.

Validator Medium barrier

Runs agents and generator rounds; sets weights from the ledger.

  • Smaller hosts: 80 GB disk and 16 GB RAM for 4 slots.
  • 10 of 13 permit holders set weights within one tempo.
  • Dividends go to 11 uids; the owner's slot takes 56%.

How the contests score

  • Agents: the leader keeps the crown unless beaten by the larger of 0.007 and a statistical band; each owner counts once; the top five split their pool 50/20/13/10/7%. The top v14 score is 0.950.
  • Generators: a round per epoch (about 72 minutes) against the top five agents; a case earns credit when some but not all agents solve it. The top five split 40/25/15/12/8%.

Getting started

  1. Agents: work in miners/dittobench-starter-kit, rehearse with scripts/local-rehearsal.py --bench-version 14, then ditto verify, upload and status.
  2. Generators: start from miners/dittobench-generator-starter-kit and pass the offline qualification.
  3. Validators: follow docs/VALIDATOR.md with a hotkey that holds a validator permit.

Caveats

  • The owner sets the burn and split and changed them repeatedly in October; the docs lag the live values.
  • The team runs screening, scoring and the ledger; rulings were reversed many times and 25 agents were still under review on 2026-10-31.
  • Members allege that top agents hard-code benchmark phrases and that a team-linked miner validates (the team denies this); neither is verified.
  • Unknown: Ditto's usage and revenue, what 7,000 alpha sent to a credits wallet funds, the smallest permit holder's stake.
