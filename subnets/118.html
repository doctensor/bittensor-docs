What it is

Ditto pays miners for open-source memory for AI agents. Agent miners upload a Docker harness that DittoBench scores; generator miners upload programs that write its test cases. The team sells a Ditto assistant.

How it works

Miners

Agents upload a Docker memory-and-tools harness; generators upload a Go program that makes test packs. Each upload costs 0.1 TAO. A leader's source goes public after 48 hours; building on it is allowed, an unchanged copy is not.

Validators

Screening is build and safety checks only (source review ended 2026-11-07). Validators run agents offline with one locked model (gpt-oss-20b), grade without an LLM judge and set weights from the platform's ledger.

Incentive

Pay follows DittoBench v18 (v19 is staged; the docs still say v15). Nothing is burned; all 12 validators with weights put uid 149 first.

Roles and requirements

Miner (agent) Low barrier

Builds a memory-and-tools harness and competes on DittoBench.

  • Practice needs Rust 1.85+, Go 1.23+ and Ollama; uploading needs Python 3.12+ and uv.
  • Scored runs: 8 cases at once, no network; v18 stops a run at $1.00 per 350 cases.
  • Uids 222, 236 and 241 registered since 2026-10-30 and are paid.

Miner (generator) Low barrier

Writes a Go program that generates benchmark test packs.

  • Output must be deterministic; 50% or more overlap with another owner's output is rejected.
  • 29 generators scored in 7 days; the five paid (0.18 to 0.23) share one coldkey with agent uid 222.

Validator Medium barrier

Runs agents and generator rounds; sets weights from the ledger.

  • Smaller hosts: 80 GB disk and 16 GB RAM for 4 slots.

How the contests score

  • Agents: the crown holder keeps the 50% slot unless a challenger wins a duel on shared seeds by the required lead; the top five split 50/20/13/10/7% of 70%. Uid 149 holds it; uid 250 trails by 0.020 against 0.055 required.
  • Bench v18 is live and v19 is staged. The top official score is 0.843 (0.926 on 2026-11-12).
  • Generators: a round every four epochs (about 4.8 hours); rounds 26113 to 26121 all scored. A generator's score is its latest scored round; the chain still pays the order from before round 26121.

Getting started

  1. Agents: work in miners/dittobench-starter-kit, rehearse with scripts/local-rehearsal.py, then ditto verify, upload and status.
  2. Generators: start from miners/dittobench-generator-starter-kit and pass the offline qualification.
  3. Validators: follow docs/VALIDATOR.md with a hotkey that holds a validator permit.

Caveats

  • Burn, split and rules change often (fifteen releases in two days; the service slice was dropped); the docs lag.
  • Open: whether the chain's generator order catches up with the board, and why the agent tail orders differ.
  • Members allege hard-coded benchmark phrases in top agents and a team-linked validating miner (the team denies it; unverified).
  • Unknown: usage, revenue, and what 7,000 alpha of manual transfers fund.
