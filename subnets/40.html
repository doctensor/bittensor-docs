What it is

Ralph (Ralph Labs) is a subnet where miners compress one open model, Qwen3-8B, into tiny GGUF files in four bit-width tiers so it can run on a phone. Validators score how closely each file matches the original, and the best per tier is crowned. The v2 design replaced an earlier research design in August 2026.

How it works

Miners

Miners compress the pinned model into a tier with a cap on bits per weight (binary 1.15, ternary 1.75, sub2 2.3, sub4 4.0) and serve a GGUF file at a fixed Hugging Face revision. They commit a hash of the bytes on chain before the round's random value exists, then reveal after the round opens.

Validators

The scoring validator rents a GPU box and measures 'observer KL' retention: judge models compare how the miner's and the parent's steps move the judge (1 = identical). Exam items come from a block hash drawn after commitments close; records are signed and anchored on chain.

Incentive

Team rules: per tier the king takes 80% and the best improving challenger 20%. Chain, 2026-10-31: split 18% owner, 41% validators, 41% miners. All miner incentive sits on uid 234 (registered 2026-09-23, never set weights); the five Round 7 hotkeys earn 0. Four of six weight-setters, including owner-linked uid 0, put all weight on it.

Roles and requirements

Miner Medium barrier

Compresses the pinned Qwen3-8B into one bit tier and serves it as a GGUF with a committed hash.

  • Only GGUF can pass the tiers; TQ1_0 and TQ2_0 are rejected (no Metal kernels in mainline llama.cpp).
  • Chain, 2026-10-31: crown holders earn 0; incentive goes to uid 234.

Validator Medium barrier

The team's validator scores on rented GPUs; others set weights from a round they verified.

  • Weight-setters set the newest verified round's vector, burning when none is verified; no hardware or cost is published.

Auditor Low barrier

Anyone can recheck a signed round: arithmetic on a CPU, model effects on matching GPUs.

  • L0 recomputes the arithmetic; L1 re-digests the exam pool.

Getting started

  1. Read the README in RalphLabsAI/ralph: the pinned parent (Qwen3-8B), the four tiers and their bit caps.
  2. Compress the model into one tier as a GGUF; check it with the repo's bit-rate tool.
  3. Commit the file's hash before the round nonce exists, reveal after the round opens (miner/QUICKSTART.md).
  4. Check the team's status feed first: on 2026-10-31 no round is in flight and 8 entries wait.

Caveats

  • The chain does not pay the crowned miners: uid 234 holds all incentive and never set weights; who runs it is unknown.
  • The team's own gap list (checked 2026-09-13) says no v2 allocation was applied on chain; the 2026-10-31 read fits that.
  • Members have alleged self-mining since July; the owner denies it. This page takes no side.
  • Retention is fidelity to the parent, not capability; figures and the sub2-only iPhone test are the team's, not independently reproduced.
