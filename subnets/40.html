What it is

Ralph (Ralph Labs) is a subnet where miners compress one open model, Qwen3-8B, into tiny GGUF files in four bit-width tiers so it can run on a phone. Validators score how closely each file matches the original, and the best per tier is crowned. Since 2026-11-03 it is paused and its emission burned.

How it works

Miners

Miners compress the pinned model into a tier with a cap on bits per weight (binary 1.15, ternary 1.75, sub2 2.3, sub4 4.0) and serve a GGUF file at a fixed Hugging Face revision. They commit a hash of the bytes on chain before the round's random value exists, then reveal after the round opens.

Validators

The scoring validator rents a GPU box and measures 'observer KL' retention: judge models compare how the miner's and the parent's steps move the judge (1 = identical). Exam items come from a block hash drawn after commitments close; records are signed and anchored on chain.

Incentive

Team rules: each tier has a fixed share (see table); the king takes 80%, the best improving challenger 20%. Chain, 2026-11-11: split 18% owner, 41% validators, 41% miners. After the team's burn record (2026-11-03, 00:20 UTC) all seven weight-setters, including owner uid 0, put all weight on the owner uid, so the miner share is withheld.

Roles and requirements

Miner Medium barrier

Compresses the pinned Qwen3-8B into one bit tier and serves it as a GGUF with a committed hash.

  • Only GGUF passes the tiers; TQ1_0 and TQ2_0 are rejected (no mainline llama.cpp Metal kernels).
  • Chain, 2026-11-11: no miner earns; the miner share is withheld until the next scored round.

Validator Medium barrier

The team's validator scores on rented GPUs; others set weights from a round they verified.

  • Weight-setters follow the team's newest signed record, now a burn: all seven follow it. No hardware or cost is published.

Auditor Low barrier

Anyone can recheck a signed round: arithmetic on a CPU, model effects on matching GPUs.

  • L0 recomputes the arithmetic; L1 re-digests the exam pool.
  • A burn record is audited as a signed one-uid payout with no scores.

Getting started

  1. Read the README in RalphLabsAI/ralph: the pinned parent (Qwen3-8B), the four tiers and their bit caps.
  2. Compress the model into one tier as a GGUF; check it with the repo's bit-rate tool.
  3. Commit the file's hash before the round nonce exists, reveal after the round opens (miner/QUICKSTART.md).
  4. Check the team's status feed first: on 2026-11-11 the subnet is still paused and 28 submissions wait.

Caveats

  • Until the burn, one unidentified uid (234) earned all incentive without setting weights; its 2,509-alpha stake was unstaked in one event on 2026-11-03 (4.3 TAO).
  • The team's gap list (checked 2026-09-13) says no v2 allocation was applied on chain.
  • Members have alleged self-mining since July; the owner denies it. This page takes no side.
  • Retention measures fidelity to the parent, not capability; the figures and the iPhone test are the team's own.
