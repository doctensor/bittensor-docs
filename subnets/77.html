What it is

Subnet 77 pays miners for providing Uniswap V3 liquidity on Ethereum, mainly in wTAO pools, so that TAO is easier to buy and sell outside Bittensor. Alpha holders vote on which pools earn, and a server run by the team turns those votes and the miners' live positions into a weight vector. Validators download that vector and set it on chain, so scoring is centralised on the team's server, though the formula is published and can be rerun by anyone.

How it works

Miners

Miners bridge TAO to wTAO on Ethereum, open Uniswap V3 positions in pools that holders have voted for (on 2026-10-21 the wTAO/WETH and wTAO/USDC pools, both at the 1% fee tier), register a hotkey on subnet 77 and link it to the Ethereum address holding the position with a signed claim. The server docs say the hotkey must be registered and hold alpha. Miners carry their own capital, swap fees, impermanent loss and any hedging costs. No minimum amount is documented.

Validators

Validators do not measure liquidity. The reference validator downloads the team server's weight vector every 5 minutes, maps hotkeys to UIDs, smooths it with an exponential average (factor 0.2) and sets weights on chain every 101 blocks. It needs a registered hotkey and, by the team's account on 2026-08-05, a cheap virtual server. A separate script in the client repo recomputes the weights from the server's vote data and Uniswap positions read through The Graph (free API key) and prints a comparison table.

Incentive

Each voting alpha holder splits 10,000 points across pools, and a vote counts in proportion to that holder's share of the alpha held by voters. Within a pool only positions that are in range at the current price score. The score is a Gaussian of the distance from the current tick to the lower bound, the midpoint (weighted 4 times) and the upper bound, using a width that depends on the fee tier (500 ticks at 1%), multiplied by the position's liquidity, so narrow positions near the price earn more. Scores are normalised inside each pool and multiplied by the pool's vote share. On chain the emission split between burn, recycle, owner, validators and miners was 0 / 0 / 18% / 41% / 41% on 2026-10-21.

Getting started

  1. Read the client repo README, then check you can fund Uniswap V3 positions on Ethereum: you need wTAO (bridged from TAO), a pool partner such as WETH or USDC, and ETH for gas.
  2. Register a hotkey on subnet 77 (the registration burn was 0.0005 TAO on 2026-10-21) and hold some alpha, since the address claim needs both.
  3. Open a position in a pool that currently has vote weight, which you can see at /pools (wTAO/WETH and wTAO/USDC, 1% fee tier, on 2026-10-21), in a narrow range around the current price. Positions outside their range score zero.
  4. Link the hotkey to the Ethereum address with the repo's register script. It asks for the hotkey's secret seed (32 bytes in hex) and an Ethereum private key; the team said the Ethereum key only signs the claim message, so you can sign it elsewhere and post the message yourself. Never paste keys into chat.
  5. Check your share at /weights and with `just verify-weights`, and rebalance when the price moves out of your range.
  6. Holders can vote with `just vote`; to run a validator use `just validate` with a registered hotkey.

Caveats

  • Scoring runs on the team's own server. The weight pipeline was interrupted on 2026-04-24 (API down), 2026-07-28 (server down), 2026-09-20 (owner validator stopped setting weights) and 2026-10-15 (API down), and validators simply copy the server, so an outage there stops weight updates.
  • The public server repo's last commit is 2025-09-02 and the team said on 2026-04-24 that its data pulling changed, so the live server may differ from the code. The client repo's verify-weights script is described as mirroring production; I did not run it, so the match is from code and from the live API matching the owner validator's chain weights.
  • The update announced for 2026-07-07 (no-impermanent-loss liquidity and a lending-based buyback) is not in the repos and no release was announced as of 2026-10-21.
  • Chat claims about how much miners earn or lose conflict and are unverified. Several miners reported that range, hedging and swap costs dominated results.
  • The API lists 110 miner hotkeys but only 15 carry more than a trace of weight on 2026-10-21; the owner's key (UID 0) received the largest single share of the last epoch's alpha (37%), without a split between owner share and validator dividends. The top incentive UID (4) is not the owner's key; who runs the others is not shown.
  • That emissions were switched off in late June and on again by late August is supported by chat and a bot post, not by an official announcement I could find; the chain read is a snapshot.
  • A moderator warned on 2026-09-02 that direct messages and friend requests offering help in this channel are scams. Chat shows miners with failed bridge transfers and unclear registration errors; use only the repo's documented steps.
  • The channel rules block investor and price questions, so token price and buyback discussion is not answered there.
