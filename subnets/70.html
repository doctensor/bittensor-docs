What it is

Fugal pays miners to build routers that send each question to the cheapest model likely to answer it correctly. Miners run a benchmark slice with a small trained router inside an Intel TDX VM, pay their own model calls and submit a signed proof.

How it works

Miners

Train a small router head on a frozen Qwen3-0.6B, with its own price weight. Each epoch it runs in an Intel TDX VM on GCP, calls models through OpenRouter at the miner's cost and returns a signed proof.

Validators

Validators call no model: they check the signature, approved image, head hash and answers, score miners, bar copies of older heads and set weights.

Incentive

Split: 18% owner, 41% validators, 41% miners. The seat holder takes the miner share, 85/10/5 across the last three holders. v5 (11-25) pays on RouterArena's accuracy-and-cost score, burns half the miner share, and burns all of it until a router beats the best single model; the seat started empty.

Getting started

  1. Read the miner guide, train a head (scripts/train_head.py) and rehearse on testnet with --mock (no spend).
  2. Deploy the published miner image on a GCP TDX VM with dstack, push the head and a funded OpenRouter key over the attested channel, then register a hotkey (0.0005 TAO on 2026-11-26).
  3. Validators: stake 50+, set the 4,320 s epoch, load approved entries, run neurons/validator.py --live.
