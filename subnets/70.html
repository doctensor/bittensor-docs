What it is

Fugal pays miners to build routers that send each question to the cheapest model likely to answer it correctly. Miners run a benchmark slice with a small trained router inside an Intel TDX VM, pay their own model calls and submit a signed proof.

How it works

Miners

Train a small router head on a frozen Qwen3-0.6B. Each epoch (about 300 questions) it runs in an Intel TDX VM on GCP, calls models through OpenRouter at the miner's cost and returns a signed proof.

Validators

Validators call no model: they check the signature, approved image, head hash and answers, score miners, bar copies of older heads and set weights.

Incentive

Split: 18% owner, 41% validators, 41% miners. Since the v2 switch one champion takes 85% of the miner share and the last two 10% and 5% (docs); a head wins the seat by beating the champion by 0.2 points at 99% confidence over five or more epochs; with no eligible head the share burns.

Getting started

  1. Read the miner guide, train a head (scripts/train_head.py) and rehearse on testnet with --mock (no spend).
  2. Deploy the published miner image on a GCP TDX VM with dstack, push the head and a funded OpenRouter key over the attested channel, then register a hotkey (0.0005 TAO on 2026-11-14).
  3. Validators: stake 50+, set the 4,320 s epoch, load approved entries, run neurons/validator.py --live.
