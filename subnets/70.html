What it is

Fugal pays miners to build routers that send each question to the cheapest model likely to answer it correctly. A router is a small trained layer on a frozen 0.6B model; miners run a benchmark slice with it inside an Intel TDX VM, pay for their own model calls and submit a hardware-signed proof.

How it works

Miners

Train a small router head on a frozen Qwen3-0.6B. Each epoch (about 300 questions) it runs in an Intel TDX VM on GCP, calls models through OpenRouter at the miner's cost and returns a signed proof.

Validators

Validators call no model: they check the signature, approved image, head hash and answers, score miners, drop near-copies of older heads and set weights.

Incentive

Score is the accuracy a router adds above what any single model or random mix buys at the same cost; constant policies score zero; new heads ramp in over 10 epochs. Split: 18% owner, 41% validators, 41% miners.

Getting started

  1. Read the miner guide, train a head (scripts/train_head.py) and rehearse on the test network with --mock (no spend).
  2. Deploy the published miner image on a GCP TDX VM with dstack, push the head and a funded OpenRouter key over the attested channel, then register a hotkey (about 0.06 TAO).
  3. Validators: stake 50+, set the 4,320 s epoch, load approved entries, run neurons/validator.py --live.
