What it is

Project Nobi set out to build Nori, a free personal AI companion with long-term memory on Telegram, Discord and a web app, with the subnet paying miners for companion quality. It ran as netuid 272 on the Bittensor test network from 2026-03-17 and never had a mainnet slot. The team's website, which said Nori was closed, no longer resolves, and the public repository it used to link is no longer reachable.

How it works

Miners

According to the project's FAQ, miners served companion chat replies, held encrypted user memories spread across the network, and paid for their own servers (small cloud servers using API-based inference). Their software could not be checked: the repository is no longer public.

Validators

The FAQ says validators score miners on memory recall, personality consistency, emotional intelligence and multi-turn conversation, not raw speed. On the test network there is one validator permit, and it has set no weights since registration.

Incentive

The team described quality-scored emissions for miners and said the owner would burn 100% of its owner take. Neither could be verified: there is no mainnet subnet, the scoring code is unreadable, and the test network shows no incentive or emission.

Getting started

  1. There is nothing active to join: the project's website is offline (it said the service is closed), and the testnet subnet pays nothing.
  2. To inspect it anyway, point a Bittensor client at the test network (not mainnet) and read netuid 272.

Caveats

  • Testnet only: no mainnet netuid 272 exists, so nothing here describes mainnet emissions or economics. Test-network emission has no market value.
  • The mechanism comes from the team's FAQ and chat posts. The repository with the incentive design, mining guide and code was not found on any check, 2026-10-21 to 2026-11-06; no scoring or validator code was read.
  • Why the repository and the website disappeared, and whether the subnet is abandoned, is not stated anywhere found. The closure date is only bounded by page dates (2026-09-22 to 2026-11-01).
  • Team figures on neuron counts, external miners, test counts and the 100% owner burn were not verified on chain.
  • Whether the Telegram bot still answers was not tested; its profile page still resolves. Miner cost figures come from the FAQ as read on 2026-10-31.
