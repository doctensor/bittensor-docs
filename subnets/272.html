What it is

Project Nobi set out to build Nori, a free personal AI companion with long-term memory reachable from Telegram, Discord and a web app, with the subnet intended to pay miners for companion quality. It ran as netuid 272 on the Bittensor test network from 2026-03-17 and never had a mainnet slot. The team's website now carries a notice that Nori is closed, and the public source repository it used to link is no longer reachable.

How it works

Miners

According to the project's FAQ, miners served companion chat responses, held encrypted user memories distributed across the network, and paid for their own servers (the team quoted small cloud servers using API-based inference). Which software they ran could not be checked, because the code repository is no longer public.

Validators

The FAQ says validators score miners on memory recall, personality consistency, emotional intelligence and multi-turn conversation rather than raw speed. On the test network today there is one validator permit and it has set no weights since the subnet was registered.

Incentive

The team described quality-scored emissions for miners and said the subnet owner would burn 100% of its owner take with the burn_alpha call. These are team statements and could not be verified: there is no mainnet subnet, the scoring code was not readable, and the test network currently shows no incentive, no dividends and zero emission in the last epoch.

  • 2026-03-17 (Bittensor test-network chain read, 2026-10-21; project blog) The subnet was registered on the Bittensor test network as netuid 272. The team's own blog gives the same date as the project's start.

Getting started

  1. There is nothing active to join: the project's own site says the service is closed, and the testnet subnet currently pays nothing.
  2. If you want to inspect the subnet anyway, point a Bittensor client at the test network (not mainnet) and read netuid 272.

Caveats

  • Testnet only. No mainnet netuid 272 exists, so nothing here describes mainnet participation, emissions or token economics. Test-network emission has no market value.
  • The mechanism description comes from the team's FAQ and chat posts. The repository with the incentive design, mining guide and code (ProjectNobi/project-nobi) returned not found on 2026-10-21, so scoring and validator code were not read.
  • Why the repository disappeared, and whether the notice on the home page also means the subnet is abandoned, is not stated by the team anywhere found. The date of the closure is only bounded by page modification dates.
  • Team figures on neuron counts, external miners, test counts and the 100% owner burn were not verified on chain. The 84 neuron slots seen now include slots that earn nothing.
  • Whether the Telegram bot still answers was not tested; its profile page still resolves.
