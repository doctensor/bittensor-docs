What it is

ReadyAI (SN33; repo name: Conversation Genome Project) turns raw content into tagged, structured data. Miners tag text; validators score them against tags built from the whole content. The team sells the output through a paid Jobs API and is shifting the subnet to agent-skill tasks.

How it works

Miners

Miners answer tasks with their own LLM. In conversation tagging a miner gets one masked window of up to 10 lines and returns topical tags. The team's server picks which task types go out (the code has six).

Validators

A validator fetches task bundles from the team's server, copies one random window of a conversation into 5 identical tasks, sends each to 6 random miners and scores replies against tags built from the whole conversation.

Incentive

Tag tasks (conversation, skill tagging) score by embedding similarity to the reference, with penalties. Skill-test tasks score 60% on how well the tests cover up to 3 random hidden sections and 40% on how well they match the skill. An LLM judge must accept a test; none is run. Under 3 tests is skipped; under 5, or near-duplicates, halve the score; under half accepted costs 30%, over 6 per section 40%. Weights are rank-based.

Getting started

  1. Clone the repo, copy env.example to .env and add an OpenAI key.
  2. Open your miner port to the internet; a closed port is the usual reason for no requests.
  3. Test on testnet (netuid 138) with the README miner command; it checks setup only.
  4. Register on netuid 33 (burn 0.0823 TAO on 2026-11-26) and start the miner; low scorers are replaced.
