What it is

ReadyAI (SN33; the repo is still called Conversation Genome Project) turns raw content into structured data. Miners tag or enrich text; validators score them against a reference built from the whole content. The team sells the output through a paid Jobs API and is moving the subnet to agent-skill tasks for its planned Skill Store 33.

How it works

Miners

Miners answer tasks with their own LLM. In conversation tagging, a miner gets one masked window of up to 10 lines of a longer conversation and returns topical tags. The code also has webpage, survey, entity, skill generation and skill coverage tasks; the team's server picks which go out.

Validators

A validator fetches task bundles from the team's server, splits each into up to 5 tasks, sends each to 6 random miners and scores replies against tags built from the whole conversation (OpenAI embeddings). Since release 2.39.77 tasks go out in random order.

Incentive

Tags score by embedding similarity to the reference; a set mixes top-3 mean, mean, median and max, with penalties. Weights are rank-based; since 2026-10-27, 25% of weight goes to the owner uid and is burned.

Roles and requirements

Miner Low barrier

Answers tagging and skill tasks with its own LLM; paid by rank.

  • env.example: the OpenAI key is always required; the README lists Anthropic, OpenRouter and Chutes overrides for miners.
  • A closed port is the usual reason a miner gets no requests (team and moderator).

Validator High barrier

Scores miners from whole conversations and sets weights; needs team-issued keys.

  • The server key goes to a coldkey that owns a validator hotkey with the minimum stake; the team issues the commitment key.
  • The owner's own validator holds a permit but last set weights over 720 days ago.

Task mix and fairness dispute

  • Team, 2026-10-29: conversation tasks shrink over the coming weeks toward almost all skill tasks; it calls this certain. No date or split given.
  • Participants say an operator with many slots can stitch a conversation's windows together by their shared enrichment cards; the team calls that harder than it sounds. Not tested here.
  • Skill Store 33 is still a sign-up page; the team had promised an October launch.

Revenue and buybacks (team data)

Getting started

  1. Clone the repo, copy env.example to .env and add an OpenAI key; the W&B key is only for validators.
  2. Open your miner port to the internet; a closed port is the usual reason for no requests.
  3. Test on testnet (netuid 138) with the README miner command; it checks setup only.
  4. Register on netuid 33 (burn 0.0420 TAO on 2026-10-30) and start the miner; low scorers are replaced after immunity.
  5. Validators also need the team's server key and commitment key.

Caveats
