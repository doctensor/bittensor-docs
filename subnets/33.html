What it is

ReadyAI (SN33; the repo is still called Conversation Genome Project) turns raw content into tagged, structured data. Miners tag text; validators score them against tags built from the whole content. The team sells the output through a paid Jobs API and is shifting the subnet to agent-skill tasks.

How it works

Miners

Miners answer tasks with their own LLM. In conversation tagging a miner gets one masked window of up to 10 lines and returns topical tags. The team's server picks which task types go out (the code has six).

Validators

A validator fetches task bundles from the team's server, splits each into up to 5 tasks, sends each to 6 random miners and scores replies against tags built from the whole conversation. Since release 2.39.77 tasks go out in random order.

Incentive

Tags score by embedding similarity to the reference, with penalties. Skill tasks score 60% on how well the tests cover up to 3 sampled sections and 40% on how well they match the skill; an LLM judge must accept a test (none is run), and the score halves for under 5 tests or near-duplicates. Weights are rank-based; since 2026-10-27, 25% of weight goes to the owner uid and is burned.

Getting started

  1. Clone the repo, copy env.example to .env and add an OpenAI key (the W&B key is for validators).
  2. Open your miner port to the internet; a closed port is the usual reason for no requests.
  3. Test on testnet (netuid 138) with the README miner command; it checks setup only.
  4. Register on netuid 33 (burn 0.0336 TAO on 2026-11-07) and start the miner; low scorers are replaced.
