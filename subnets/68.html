What it is

NOVA, built by Metanova Labs, rewards miners for finding molecules and nanobody (antibody fragment) sequences that a structure-prediction model scores as strong binders to chosen protein targets. A second contest, Blueprint, asks miners to submit search code that generates good molecules inside a sandbox, with the best code kept as champion until a challenger beats it. The team describes this as open competition feeding its own drug-discovery pipeline and partnerships.

How it works

Miners

Compound track: every epoch of 361 blocks, miners commit a set of small molecules and/or nanobody sequences, encrypted with timelock encryption and posted to a public GitHub repository, with only a pointer committed on chain. Molecules come from a large reaction-based library; the team announces new protein targets about a day ahead in Discord. Blueprint track: miners upload code (a miner.py) through a signed submission API. It runs once a day in a no-network Docker sandbox with a one-hour budget, queries a Boltz-2 scoring service, and must output a fixed-size set of reaction-formatted molecules. Everything the code runs must be readable source and the molecules must be generated inside the sandbox; internet access during a Blueprint run is not allowed.

Validators

Compound validators decrypt submissions, apply chemistry and sequence validity filters (a check that a molecule can be built into a 3D conformer was added on 2026-10-20), then score small molecules with Boltz-2 and nanobodies with a modified BoltzGen pipeline; the repository documents 2 GPUs with over 48 GB of memory and a team-issued API key. Blueprint validators run each miner's code in the sandbox against the oracle, keep a frozen champion that is re-run every epoch, and track challengers. The team also reviews and disqualifies Blueprint submissions that break the rules. On chain, 7 of the 64 uids hold validator permits (2026-10-21).

Incentive

Compound: one winner per category per epoch, with 60 percent of the compound share for molecules and 40 percent for nanobodies, ties broken by earliest submission. The validator code sends all of that mechanism's weight to one payout UID (42), and winners are then paid alpha off chain to their coldkey by a team service, sometimes with delays and a manual approval for a new coldkey. Blueprint: a challenger must beat the champion by a set margin on 4 consecutive daily epochs; all Blueprint weight goes to a second payout UID (56), and on a change of champion the accumulated bounty, which grows while the champion stands, is paid in alpha to the new champion's coldkey through a team payout service. A chain read on 2026-10-21 matches this: emissions are split 71.43 percent to Compound and 28.57 percent to Blueprint, each mechanism's incentive sits entirely on its one payout UID, and 6 of the 7 permitted validators give UID 42 all their Compound weight. The subnet-level emission split is 18 percent owner, 41 percent validators and 41 percent miners, with nothing burned or recycled.

Getting started

  1. Read docs/MINER.md in the nova repository for the Compound track and the README of the nova-blueprint repository for Blueprint; both tracks need a registered hotkey on subnet 68.
  2. Compound: set up the .env file with a public GitHub repository for payloads, write your own molecule or nanobody selection (the baseline miner alone earns nothing), and commit before the last 10 blocks of each 361-block epoch. The README lists Ubuntu 24.04, CUDA 12.6 and GPUs with more than 48 GB of memory.
  3. Blueprint: write miner.py at the repository root to read /workspace/input.json and write /output/result.json with exactly the required number of reaction-formatted molecules, scoring through the oracle socket.
  4. Blueprint: associate your hotkey with your coldkey first (the API reports owner_unset and shows the btcli associate-hotkey command until you do), then check GET /quote?hotkey=<your hotkey> on the submission API for the live mode, price and credit balance, and upload with the submission SDK in the repository. One slot per hotkey per daily epoch.

Caveats

  • Both tracks pay through a team-run service off chain rather than plain emission to the winning miner. A chain read on 2026-10-21 shows each mechanism's whole incentive on one UID (42 for Compound, 56 for Blueprint), as the repository config says. Neither UID is the subnet owner's own hotkey or coldkey, and they sit on two different coldkeys, but who controls them and what winners are actually paid cannot be checked from the chain data read here. Payments can be delayed and new coldkeys need approval, so rewards depend on the team running that service.
  • Chain reads are a single snapshot (blocks 9334714 to 9334722 on 2026-10-21). Compound weights were read for all 7 permitted validators; Blueprint weights for three of them (two put everything on UID 56, one had set none). Two of the 7 permitted validators, including the owner's own slot UID 0, share the subnet owner's coldkey; validator stake was not compared.
  • Documentation lags the code: the main README does not mention Blueprint, the oracle or credit-based submission, and the Compound guide gives 20 to 50 heavy atoms while the Compound config says 10 to 50 (unchanged since 2026-10-13).
  • On 2026-10-14 a miner said the deployed validator enforced a limit on aromatic rings that the public repository lacked and asked whether older Br and BRENK checks still applied. The repository's molecule-filter overhaul, which includes the ring limit and no longer contains those older checks, was published on 2026-10-13, and the team told the miner to pull the latest code. Which version was deployed at the time cannot be confirmed from outside.
  • Blueprint rules are enforced partly by team judgement: disqualifications on 2026-10-15 and 2026-10-16 interpreted the rule on precomputed data broadly, with changes announced about 24 hours ahead, and those clarifications are in chat only. Contest parameters, targets and filters change by announcement, and the repository can lag the live settings (the Blueprint repository has had no commit since 2026-09-25).
  • Blueprint bounty sizes quoted in chat were not verified. The submission API shows a price of 10 with asset alpha:68 but no separate unit; no document read states it.
  • The lab-result claim of 2026-10-21 (more favourable ADME profiles than controls) is a team statement; the recording it points to, and any data behind it, were not read. Members have repeatedly asked for a roadmap, revenue plan and partnerships, and the team announced a quarterly founder incentive distribution on 2026-10-07 whose details (an X post) were not read.
  • Miner questions about skipped or delayed epochs (25781, 25819) and about a missing score from the second validator at epoch 25822 had no team answer in the messages read.
  • Only named team members give support; direct messages offering help are scams.
