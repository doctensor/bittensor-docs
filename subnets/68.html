What it is

NOVA, built by Metanova Labs, runs open drug-discovery contests. Compound pays miners for molecules and nanobody (antibody fragment) sequences an AI model scores as strong binders to a chosen protein. Blueprint pays for the best molecule-search code.

How it works

Miners

Compound: each 361-block epoch (about 72 minutes) miners commit 20 molecules and/or one nanobody sequence, encrypted in a public GitHub repository. Blueprint: miners upload code that runs daily in a no-network sandbox and returns molecules scored by a Boltz-2 service.

Validators

Compound validators decrypt entries, filter them, score molecules with Boltz-2 and nanobodies with BoltzGen, then use scores averaged through a team-run service. Blueprint validators run each entry in a sandbox and re-run a frozen champion every epoch.

Incentive

Compound: one winner per category per epoch (60% molecules, 40% nanobodies). Blueprint: a challenger must beat the champion by a margin on 4 daily epochs in a row. All weight goes to one payout uid per contest (42 and 56); a team service pays winners in alpha.

Roles and requirements

Miner (Compound) Medium barrier

Choose molecules or design nanobodies that score best on the epoch's target.

  • Since 2026-10-24 the targets are MCT4 (molecules) and PD-L1 (nanobodies); nanobodies must pass germline, VHH, developability and similarity checks.
  • Entries are timelock encrypted and committed before the last 10 blocks; a first win from a new coldkey needs team approval.

Miner (Blueprint) Medium barrier

Submit search code that finds high-scoring molecules; the best code stays champion.

  • One slot per hotkey per day (64 slots; 0 used early on 2026-11-07); resubmitting in the same epoch is free.
  • No internet, 48 GB memory, exactly 100 molecules out; since 2026-10-29 priors on which molecules score well are barred.

Validator High barrier

Decrypt and score Compound entries; run the Blueprint sandbox.

  • Payout calls need a team-issued transfer key. Blueprint side: Docker, oracle token, MinIO and submission keys; no GPU.
  • On 2026-11-07, 6 of 7 permit holders put all weight on uid 42; the owner's own uid 0 last set weights about March 2025. Owner-coldkey uid 5 earns 65% of dividends and holds 36% of the alpha read.

Getting started

  1. Read docs/MINER.md (Compound) or the nova-blueprint README; both need a subnet 68 hotkey (burn about 0.019 TAO on 2026-11-07).
  2. Compound: set a public GitHub repository and token in .env, write your own selection method and commit before each epoch's last 10 blocks.
  3. Blueprint: link your hotkey to your coldkey, check the quote endpoint, upload miner.py with the SDK; no priors.
  4. Validators: ask the team for an API key; you need 2 GPUs over 48 GB and 1,000+ stake.

Caveats

  • Winners are paid off chain by a team service: the two payout uids earn about 1,570 alpha a day but hold none; where it goes cannot be checked.
  • The extra 8 points of emission go to an owner-held R&D fund (team post); holdings and spending are not visible on chain.
  • Prize sizes come from chat only (10,000 alpha quoted; an earlier 23,000 cap).
  • Lab results, partners and the 2025 DiaGen AI letter of intent are team statements, not data.
