What it is

Cacheon runs speed contests for AI inference. Miners submit code that speeds up one part of a serving engine (SGLang); the team's evaluator checks that it is faster with no loss of quality. One arena is open (GLM-5.3-Flash on eight B300 GPUs); two passes so far.

How it works

Miners

Build a bundle that replaces one part of the SGLang baseline, host it, pay the fee and commit it on chain; model weights may not change.

Validators

The team's evaluator replays a sealed workload against baseline and candidate and audits speed and quality. One signed weight offer goes out about every two hours; followers republish it.

Incentive

Credit needs one audited pass that beats the arena's best earlier pass by 1.5% (stock for the first) and grows with the log of the speedup. Older winners' shares decay and dilute as new winners arrive. Chain split: 18% owner, 41% validators, 41% miners.

Getting started

  1. Read the miner guide and the GLM arena README (branch feat/glm53f-pd-arena).
  2. Check the dashboard queue; install the package (Python 3.11+) and run scan and verify on an example.
  3. Register a hotkey on subnet 14, build on the arena's SGLang baseline, beat the payment bar (about 1.097x stock), then chain-submit.
  4. The kernel-challenge claim route is closed.
