What it is

Cacheon runs speed contests for AI inference. Miners submit code that speeds up one part of a serving engine (SGLang); the team's evaluator checks that it is faster with no loss of quality. One arena is open (DeepSeek V4.1 Flash); five passes so far, three by one miner.

How it works

Miners

Build a bundle that replaces one part of the SGLang baseline, host it, pay the fee and commit it on chain; model weights may not change.

Validators

The team's evaluator replays a sealed workload against baseline and candidate and audits speed and quality. One signed weight offer goes out about every two hours; followers republish it.

Incentive

Credit needs one audited pass that beats the arena's best earlier pass by 1.5% (stock for the first) and grows with the log of the speedup. Older winners' shares decay and dilute as new winners arrive. Chain split: 18% owner, 41% validators, 41% miners.

Getting started

  1. Read the miner guide, arena_inputs/dsv41pd and the DeepSeek results page.
  2. Check the dashboard queue; install the package (Python 3.11+) and run scan and verify on an example.
  3. Register a hotkey on subnet 14, build on the arena's SGLang baseline, beat the payment bar (about 1.125x stock), then chain-submit (0.5 TAO).
  4. The kernel-challenge claim route is closed.

Caveats

  • Scoring and weights run on team servers; the chain shows what is paid, not that scoring is fair (one crown was revoked).

  • The evaluator was quiet 44 hours, then stale again from 12:11 UTC on 11-05; neither cause is stated (chat after 11-01 unread).
