What it is

ComputeHorde aims to give validators of other Bittensor subnets cheap, trusted GPU capacity, so they do not need their own hardware or centralized clouds. Miners register executors, validators send them synthetic and organic jobs and check the results with the help of a trusted GPU. The project has a public SDK and a gateway for outside requests, but the chat shows little visible progress or named customers in 2026.

How it works

Miners

Run executors (several GPUs behind one miner hotkey) that accept jobs from validators. Only the A6000 hardware class is documented as supported, with A100 listed as next. Miners can post collateral with validators to be eligible for organic jobs, can run an optional DDoS shield and can preload common Docker images.

Validators

Run synthetic jobs and relay organic jobs coming from a facilitator, checking results against a separate trusted GPU. Each block mints compute allowance per miner and validator pair, scaled by validator stake, and a job spends allowance equal to its runtime. All validators score all miners for work that fits valid allowance blocks. Chain weights are set with commit-reveal.

Incentive

Paid runtime per miner is summed by coldkey and split across that coldkey’s hotkeys, with a 10% boost when a miner changes its declared main hotkey. Hardware classes have configurable weights. The validator code has a burn setting that sends a share of miner incentive to a burn target list, off by default in code. On 2026-10-21 the chain showed 97% of incentive on a single UID, with 7 of 8 weight-setting validators putting their top weight there. The owner has said in chat that the burn is about 99.5%, but this page did not confirm that UID is the burn target.

Getting started

  1. Read the repository README and the miner and validator READMEs; install scripts (install_miner.sh, install_validator.sh) are in the repo root.
  2. Test a miner on testnet netuid 174 before registering on mainnet 12, using a different port if you later mine from the same IP.
  3. A6000 is the only documented hardware class; check the pinned chat notes that other GPUs do not pass the A6000 class.
  4. Miners wanting organic jobs deposit collateral following the collateral-contracts guide linked from the README.

Caveats

  • Burn rate and burn target were not verified. The repo default is no burn, the live value is a dynamic setting, and the chain pattern (97% of incentive on one UID) is only consistent with a heavy burn.
  • No traffic, revenue or customer subnet could be confirmed; the owner mentions a paying client and work on other subnets without names.
  • Chat includes strong accusations about the owner’s holdings and token sales. None were checked against the chain, and the page does not repeat them as fact.
  • Alpha transfers being disabled comes from chat and was not checked on chain; try a plain unstake if swaps fail.
  • Pinned messages and most guides date from 2024 and 2025 and may be out of date.
  • Chain weights were read as aggregate shares only; hotkeys and addresses were not published.
