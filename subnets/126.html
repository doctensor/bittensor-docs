What it is

Attelier is a generative-video company with apps and a paid API (its statements); the subnet is meant to be the compute behind them. Since 11-23 the GPU lane is paused for a new API lane: a worker in a confidential Intel TDX VM resells a private video API. Outside pay ended that day.

How it works

Miners

Both lanes need the team's review. Active: a CPU worker in a Phala Intel TDX VM, with the miner's own video-API key, posts signed price offers; the gateway sends each paid request to the best one. Paused: GPU workers.

Validators

A light CPU process copies the primary validator's finalized weights; only the primary publishes a lane's vector, and today it runs burn-only (100% to uid 0) while dry-running the API allocation.

Incentive

API lane: only completed customer requests with a signed receipt earn; an empty hour burns the miner share on uid 0; team tests earn nothing. GPU lane (paused): up to 5% of the miner pool.

Getting started

  1. API miner: register a hotkey on SN126, verify it at console.attelier.ai/manage and ask for operator review.
  2. Deploy the reviewed worker image in a Phala Intel TDX VM with your sealed provider key and USD offers (workers/api_miner README).
  3. Validator: install the repo (Python 3.12, OpenSSL 3), run attelier-validator --role light --dry-run --once, then with wallet and hotkey; a permit is required.

Caveats
