What it is

Cascade trains time-series forecasting models by making the training data the competition. Miners write synthetic-data generators; the owner's trainer trains each one, validators score the result on private real-world data, and the best generator holds the throne.

How it works

Miners

A miner writes a generator: Python code, fully set by its seed, that streams synthetic series (v2: exactly 32 channels). The operator's CPU machines generate the data; the miner pays for one rented GPU training run.

Validators

The owner's trainer trains each entry and signs the record; validators check it and score private windows. A challenger must beat the king by a bar that falls with the king's tenure; v2 adds a public-benchmark gate.

Incentive

King of the hill. A king crowned in the random-init week starts at 50% of the miner-side weight (later kings 25-80% by margin), gains 10 points per passed check up to 95%, drops to 10% on a failed check; the last former king keeps 5% for about 5 days; unclaimed weight burns.

Roles and requirements

Miner High barrier

Writes a 32-channel synthetic-data generator and pays for one rented multi-GPU run per entry.

  • Default pods stay under the caps of $40 an hour and about $110 a leg; plan for up to $105 (8xH100) or $210 (8xH200).
  • One entry per hotkey per round (about 3 hours).

Validator High barrier

Checks the owner's signed training record, scores private windows and sets weights.

  • Satellite validators replay the owner's signed receipts and never re-score; a full evaluator and the owner's main validator need a GPU.
  • On 2026-11-14 all 8 permit holders had set weights within a tempo; the king (uid 220) never has and has no permit.
  • Docs: a chain.toml without the three shared_ladder keys stops a validator starting; private scoring runs about 6x longer.

Getting started

  1. Read the v2 miner intro and FAQ; v2 is open.
  2. Clone the repo, pip install -e '.[hippius,chain,generation]', and commit only through the cascade CLI.
  3. Write a 32-channel generator, run cascade verify, then cascade iterate (scores you and the king on one pool).
  4. Register a hotkey on netuid 91 (0.1 TAO), set a Lium key budgeted for the plan-for cost, then cascade submit --yes and cascade status --watch.
