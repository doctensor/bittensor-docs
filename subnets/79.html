What it is

MVTRX (formerly tau-os) simulates limit-order-book markets where miners trade as agents against background traders, paid for liquidity and risk-adjusted profit. It went live on mainnet on 2025-05-07 and rebranded in early 2026. The team's alpha-token exchange is not live on mainnet.

How it works

Miners

A miner's Python trading agent answers each validator update with orders (up to 5 per book, within 3 s); slower replies add simulated delay. Optional: train the shared GenTRX model (1 miner active on 2026-11-07).

Validators

A validator pairs a C++ market simulator with a Python validator that sends state to miners, applies their orders, scores them every 5 simulated seconds and sets weights. A run lasts about 4.9 real days. Only the owner's UID holds a validator permit, so it alone sets all incentive.

Incentive

About 95% of miner pay goes to trading; GenTRX training gets up to 5% (about 0.02% with one trainer, an estimate from the code). Trading splits into two equal halves paid by share, not rank: making (spread captured on two-sided maker fills, held 20 simulated seconds) and skill (profit after removing market drift). Chain split: 18% owner, 41% validators, 41% miners, none burned.

Getting started

  1. Read the FAQ, the README incentive sections and agents/README.md; scoring changes by release.
  2. Install with install_miner.sh on Ubuntu and write your own strategy; the example agents are templates.
  3. Test locally with the proxy tools or on testnet netuid 366; mainnet miners can ask the team for testnet TAO.
  4. Register on mainnet netuid 79 (about 0.09 TAO) and run the miner within the 3-second and 5-instruction limits.
  5. After each release post, pull the repo and restart; the team says 0.6.5 agents run unchanged on 0.6.6.

Caveats

  • One owner-run validator holds the only permit; its coldkey holds 70% of staked alpha. Nothing independent checks the scoring.
  • Rules change often: six scoring releases in six weeks, from 0.6.2 (09-24) to 0.6.7 (test branch, 11-06).
  • The team confirmed a scoring bug on 10-29 (GitHub issues 5 and 6 closed that day). The top miner's share rose from 0.9% (10-31) to 1.6% (11-07); cause not established.
  • Wash trading: the team's own figure put the largest coordinated set at 7.9% of incentive (09-29). On 10-23, 256 slots sat under 37 coldkeys, 18 holding 88% (not proof of one operator).
  • Whether a new miner profits is unknown: 61 UIDs re-registered in the day before 10-23. GenTRX had 1 active miner on 11-07, down from 21 on 10-21.
