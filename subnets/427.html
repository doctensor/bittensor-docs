What it is

Dinobets presents itself as a decentralized casino platform built on Bittensor, where every game round is meant to be provably fair and auditable by anyone. According to the team's launch post, subnet miners produce cryptographic hashes for each round and validators check them in real time, while operators set up ready-made games with their own pool and parameters. The post lists three game categories: in-house original games, player-versus-player games and operator games. None of this could be checked against code, because the project's repository is not public.

How it works

Miners

Per the launch post, miners generate a cryptographic hash for each game round of the operator games. The format of the task, the hash scheme and the hardware needed are not documented anywhere that could be read.

Validators

Per the launch post, validators verify the miners' hashes in real time, and the history can be audited by anyone. How verification is done and how it turns into a score is not documented in readable sources.
