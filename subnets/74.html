What it is

Gittensor set out to pay open-source work: miners link a GitHub account to a hotkey, validators score merged pull requests against an owner-set repository registry. In 2026 it narrowed to team-run projects (sparkinfer, Spark-Hermes) plus a GPU compute pool. Since 2026-10-12 the registry is empty, so no miner is paid.

How it works

Miners

No miner neuron runs. A miner registers on netuid 74, makes a free fine-grained GitHub token, installs the CLI and posts the token to validators. Pay comes from merged pull requests to registered repositories (sparkinfer GPU speed-ups, Spark-Hermes agent strategies) or, on the compute track, from verified GPU servers.

Validators

Every two hours a validator scores recent merged pull requests against per-repository rules (default: 3 merged, 80% merge rate). Repository weights come from a local registry; an empty registry allocates nothing. Compute pay needs a signed scorecard and a nonzero compute share.

Incentive

Miner emission splits across registered repositories by share; leftovers and any unused compute share recycle to uid 0. Before 2026-10-12 the registry held three repositories (25%, 20%, 5%); that day's change emptied it and zeroed the compute share. The chain's split is 50% validators, 50% miners, the miner half withheld from owner hotkeys.

Getting started

  1. Ask in the channel whether miner emission has resumed; as of 2026-10-30 nothing pays.
  2. Open-source track: register a hotkey on netuid 74, make a read-only GitHub token (no expiry), install the CLI, post it; no repository is registered today.
  3. sparkinfer: read CONTRIBUTING.md; a paid change needs a verified speed-up on an RTX 5090; docs-only changes earn nothing.
  4. Spark-Hermes: read the README (two-hour rounds, practice and hidden bugs); its feed has been stuck since 2026-10-12.
  5. Validator: run the Docker setup with one public TCP port and stake above the permit threshold.

Caveats

  • The team says burn; the chain setting is Recycle, which is not proof of what the owner does with other alpha.
  • The docs CLI reference shows default netuid 2 for the post command (mainnet is 74); not checked in code.
  • Fleet size and demand for compute were not found. A critic alleged on 2026-09-26 that the sparkinfer owner self-mines (the team says it has answered); no first-hand evidence.
