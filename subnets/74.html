What it is

Gittensor set out to pay open-source work: miners link a GitHub account to a hotkey and validators score merged pull requests against an owner-set repository registry. In 2026 it narrowed to team-run projects plus a GPU compute pool. Since 2026-10-12 the registry is empty and no miner is paid.

How it works

Miners

No miner neuron runs. A miner registers on netuid 74, makes a free GitHub token, installs the CLI and posts the token to validators. Pay comes from merged pull requests to registered repositories (sparkinfer, Spark-Hermes) or, on the compute track, from verified GPU servers.

Validators

Every two hours a validator scores merged pull requests against per-repository rules (default: 3 merged, 80% merge rate) and splits weight by an owner-set registry of repositories; an empty registry allocates nothing. Compute pay needs a signed scorecard and a nonzero compute share.

Incentive

Miner emission splits across registered repositories by share; leftovers recycle to uid 0. Until 2026-10-12 the registry held three repositories (25%, 20%, 5%); that day's change emptied it and zeroed the compute share, so validators put all weight on uid 0. The chain splits 50% to validators and 50% to miners, the miner half withheld from owner hotkeys.

Getting started

  1. Ask in the channel whether miner emission has resumed; as of 2026-11-07 nothing pays.
  2. Open-source track: register a hotkey on netuid 74, make a read-only GitHub token (no expiry), install the CLI, post it; no repository is registered today.
  3. sparkinfer: read CONTRIBUTING.md; a paid change needs a verified speed-up on an RTX 5090; docs-only changes earn nothing.
  4. Spark-Hermes: read the README (two-hour rounds, practice and hidden bugs); its feed has been stuck since 2026-10-12.
  5. Validator: run the Docker setup with one public TCP port and stake above the permit threshold.

Caveats

  • PRs 1801 and 1840 (optimisation challenges, no pay until a share is set) are unmerged; whether they replace the registry is not stated.
  • Fleet size and demand for compute were not found; a 2026-09-26 self-mining allegation against the sparkinfer owner has no first-hand evidence.
  • Validators score from a team-run mirror of GitHub data (public, rate-limited), not from GitHub; if a call fails they reuse a miner's last good score.
