What it is

Connito trains one shared language model: each round miners train a small add-on expert on a frozen Qwen3.6 base and validators keep the best. Since 2026-10-30 a second validator grades answers to customer task prompts; since 11-04 its grades set miner pay. Its scoring code is public; since 11-10 the task is writing three-lesson courses.

How it works

Miners

Each round a miner downloads the latest winning add-on, trains a new residual expert (about 250 MB), uploads it to Hugging Face and posts two on-chain commits.

Validators

The training validator loads each submission onto the frozen base and measures gain on the task data, any loss rise on general C4 text (above 0.02 scores zero) and how often the new gate fires (target about 20%).

Incentive

A loss ranking set most pay until the guide's 2026-11-04 ramp. Pay then moves to the prompt validator: the three best mean judge grades per 22.7-hour cycle share 75% of weights; UID 0 keeps 25%. Since 2026-11-10 the prompts ask for a three-lesson course; an answer that is not valid lesson JSON scores 0.

Getting started

  1. Read the miner guides at doc.connito.ai (prerequisites, prompt evaluation).
  2. Register a hotkey on SN102 (about 0.0054 TAO on 2026-11-20; the cost moves with demand).
  3. Download the pinned Qwen3.6-35B-A3B revision (about 72 GB) and run release v0.7.2.
  4. Post both on-chain commits inside the windows the phase API shows.

Caveats

  • Per-miner grades are not public: we could not read /v1/miner/results, and Jev (a third-party grader) and the prompts are private.
  • UID 0's four-uid set changed on 11-17, 11-18 (once 98.5% on itself), 11-19 and twice on 11-20; our reading: winners rotate each cycle; chat after 2026-11-01 is unread.
  • Paid uids come from coldkey groups of 10 to 33 uids; the copy rule catches only an identical model hash (our reading: operators submitting several models).
  • Phase lengths and the whitelist come from owner-run services; README docs links return 404.
  • Fairness of top miners is disputed in chat; the team's re-run has no posted result.
