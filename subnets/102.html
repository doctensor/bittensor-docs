What it is

Connito trains one shared language model in the open. A frozen Qwen3.6 base stays fixed; each round miners train a small add-on expert and validators keep the best. Since 2026-10-30 a second validator grades answers to customer task prompts, worth 15% of rewards.

How it works

Miners

Each round a miner downloads the latest winning add-on, trains a new residual expert (about 250 MB), uploads it to Hugging Face and posts two on-chain commits.

Validators

The training validator loads each submission onto the frozen base and measures gain on the task data, any loss rise on general C4 text (above 0.02 scores zero) and how often the new gate fires (target about 20%). A team-run prompt validator has an automated judge grade answers to private prompts.

Incentive

Each round the top three miners with a positive score earn rank points (2.25, 1.5, 1.0); a rolling average sets the loss weights: 98% to the top three, 2% to the next five. The table below shows the full split.

Roles and requirements

Miner Medium barrier

Trains a small residual expert each round and posts two on-chain commits.

  • Team figure (2026-10-14): the reference miner peaks near 39.5 GB GPU memory.
  • Several UIDs per operator are allowed (team, 2026-10-23).
  • For the prompt share, keep the model on Hugging Face until results are out; only the first committer of a model is ranked.

Validator High barrier

Scores submissions against the frozen base and sets weights.

  • 6 permit holders, 5 with weights set; two show online on the dashboard (UID 0 and UID 176).
  • Scoring one miner takes about 98 s on an A6000; the whitelist comes from the owner's phase API.
  • The prompt mix is off by default and not in the repo docs; an operator needs the prompt validator's hotkey and a rules hash.

Getting started

  1. Read the miner guides at doc.connito.ai (prerequisites, prompt evaluation).
  2. Check for a 48 GB GPU, Python 3.10+, CUDA 12.x and a Hugging Face read token.
  3. Register a hotkey on SN102 (about 0.06 TAO on 2026-10-31; the cost moves with demand).
  4. Download the pinned Qwen3.6-35B-A3B revision (about 72 GB) and run release v0.7.2.
  5. Post both on-chain commits inside the windows the phase API shows.
  6. For the prompt share, keep your model on Hugging Face until the cycle's results are published.

Caveats

  • The prompt validator, judge and prompts are not public, so 15% of rewards rests on grading outsiders cannot check.
  • The three prompt winners hold exactly 5% each although the guide says shares follow grade; the next cycle will show.
  • Phase lengths and the whitelist come from services the owner runs.
  • Fairness of top miners is disputed in chat; the team's second-machine re-run had no posted result by 2026-10-31.
  • README links to connito.ai/docs return 404; repo docs do not explain the prompt mix switch.
