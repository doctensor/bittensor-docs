What it is

Connito trains one shared language model in the open: each round miners train a small add-on expert on a frozen Qwen3.6 base and validators keep the best. Since 2026-10-30 a second validator grades answers to customer task prompts; per the guide its grades set miner pay from 2026-11-04, and since 11-10 the task is writing three-lesson courses.

How it works

Miners

Each round a miner downloads the latest winning add-on, trains a new residual expert (about 250 MB), uploads it to Hugging Face and posts two on-chain commits.

Validators

The training validator loads each submission onto the frozen base and measures gain on the task data, any loss rise on general C4 text (above 0.02 scores zero) and how often the new gate fires (target about 20%).

Incentive

A loss ranking set most pay until the guide's 2026-11-04 ramp. Pay then moves to the prompt validator: the three best mean judge grades per 22.7-hour cycle share 75% of weights; UID 0 keeps 25%. Since 2026-11-10 the prompts ask for a three-lesson course.

Getting started

  1. Read the miner guides at doc.connito.ai (prerequisites, prompt evaluation).
  2. Register a hotkey on SN102 (about 0.0086 TAO on 2026-11-12; the cost moves with demand).
  3. Download the pinned Qwen3.6-35B-A3B revision (about 72 GB) and run release v0.7.2.
  4. Post both on-chain commits inside the windows the phase API shows.
