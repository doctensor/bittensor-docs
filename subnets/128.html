What it is

ByteLeap says it is a decentralized GPU cloud: miners earn alpha only while their GPUs are rented. Validators do not test the GPUs; they relay lease scores from the team's closed MeshHub service. By 2026-10-30 one miner uid earned all miner incentive, and no public data shows rented compute.

How it works

Miners

A miner is a Python node that gathers Go worker agents running on bare-metal GPU hosts. Only leased GPUs earn; answering validator challenges earns nothing. Access is limited: an allowlist of partner compute centers (2026-08-18), then 'connect your own GPU' (2026-09-20).

Validators

A validator links to the team's MeshHub service (it will not start without a team-issued token), stores the per-worker lease scores MeshHub sends, sums them per miner every 420 seconds and submits the shares as weights. No heartbeat for 30 minutes scores 0.

Incentive

A miner's weight is its share of all lease scores; nobody outside the team can recompute them. Configured split: 41% validators, 41% miners, 18% owner; RecycleOrBurn is Burn. Owner uid 0 earned 14.8% of last-epoch emission as validator dividends and no incentive.

Roles and requirements

Miner High barrier

Connects bare-metal GPU hosts through a Python miner and Go worker; paid in alpha only while its GPUs are rented.

  • Worker needs Ubuntu 22.04+ on bare metal (no Docker or VMs); installed from a team-hosted script or zip.
  • Only leased GPUs earn; the team recommends 4 to 8 GPUs per miner (2026-10-08).
  • A miner on default settings reported no tasks and no rewards on 2026-10-18.

Validator High barrier

Relays the team's MeshHub lease scores into on-chain weights; measures no GPU itself.

  • The example config ships a pre-filled MeshHub endpoint and token in a public repo; it may be revoked.
  • 27 hold a permit (2026-10-30); 11 had set weights, all on one uid; 19 had not set weights for over five tempos.

Getting started

  1. Check fit: bare-metal Ubuntu 22.04+, 8+ cores, 32 GB RAM, 500 GB disk and a GPU on the team's list (2026-10-26).
  2. Ask in the subnet channel whether your machine can join: the team described an allowlist (2026-08-18) and a self-connect option (2026-09-20).
  3. Install the worker (team script or zip), bind the GPUs to VFIO, reboot, then run miner and worker with a registered hotkey.
  4. Alpha arrives only while a GPU is rented; the lease-status API the team mentioned (2026-10-20) was not identified.
  5. Validators need a team-issued MeshHub token; the repos do not say how to get one.

Caveats

  • Lease scores come from a closed, team-run MeshHub, so nobody outside the team can check that rented compute exists.
  • Chat is what the team said; its claims on revenue, full rental, partner compute centers and buybacks were not checked.
  • The earning uid's operator is unknown; no owner link on chain does not show it is independent or that its GPUs are rented.
  • Not read: locks held by other accounts, the lease-status API named on 2026-10-20 and the 2026-08-12 economic report attachment.
