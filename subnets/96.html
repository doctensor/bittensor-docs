What it is

Since 2026-10-15 SN96 sells Verathos Decide: open-weight models that read a state (ticket, document, code change or image) and answer typed yes/no, choice or scale questions with a probability per option, via a System One compatible API. Miners sign a receipt for each answer. The owner runs the gateway, auditor and model catalog.

How it works

Miners

Miners run one of four models (kev-4b, clef-flash, d3-flash, d3-mini) per NVIDIA GPU. The auditor tests the declared capacity; the score stays zero until it is proven.

Validators

Light validators copy the weights the owner's auditor publishes each epoch. Full validators send canary prompts and compare answers with float32 references; a probability over 0.10 off zeroes the hotkey for 6 epochs.

Incentive

Each model has an emission share (kev-4b 0.17, clef-flash 0.22, d3-flash 0.33, d3-mini 0.28), split among its endpoints by proven capacity, availability and latency. Miners get 15%; the rest goes to the owner UID, which the chain burns.

Roles and requirements

Miner Medium barrier

Serves a decision model on an NVIDIA GPU; earns by the request capacity the auditor proves.

  • GPU memory: kev-4b about 15 GiB, clef-flash 21 (reads images), d3-flash 21, d3-mini 12.
  • The installer picks the best-paying model per GPU.
  • Pay is small: about 429 alpha a day (about 1.3 TAO on 2026-10-30) shared by all independent miners.

Validator Medium barrier

Sets weights each epoch: light mode copies the owner's auditor, full mode checks miners' answers.

  • 17 permits; 7 validators set weights, all mostly on the owner UID, the auditor; the other 10 have not set weights for about 90 days.
  • Only the owner's validator runs throughput tests; others apply its verdicts.

Referrer Low barrier

Any registered hotkey except the owner's can register referral codes and earn from referred users' payments.

  • Pool up to 10% of emission; no referrers or referred spend yet.

Getting started

  1. Miner: Ubuntu machine with an NVIDIA GPU (12-21 GiB), public IP, open TCP port; register a hotkey on netuid 96 (0.1 TAO burn).
  2. Run the one-command installer from the miner guide; it picks the model and installs pinned engines. Use unquantized weights.
  3. Expect a zero score until the auditor's throughput test credits your capacity; check your declared address answers.
  4. Validator: light mode needs a permit and no GPU; full mode needs 10,000 stake and 41 GiB or more of RAM.
  5. Customer: create a key at verathos.ai/account/keys and call POST /v1/systemone on api.verathos.ai.
