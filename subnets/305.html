What it is

Blockchain Insights ran subnet 15 on mainnet from October 2023 until it was deregistered on 2024-08-25; miners indexed Bitcoin data for validators to query. Since then the team has used testnet slots for a rebuild and published no documentation. Slot 305 has been on testnet since 2025-12-18 as 'chainswarm' with 8 neurons, but its validators have not set weights since about January 2026.

How it works

Miners

Nothing is documented for netuid 305. For the old mainnet subnet 15, miners ran a Bitcoin indexer on heavy hardware, served graph queries and ran an LLM engine that needed a third-party API key. In September 2025 the owner told a testnet miner that the older testnet and miner code were obsolete and a new version was coming.

Validators

Nothing is documented for 305. The old repo describes validators that benchmarked miners on queries, freshness of indexed blocks and uptime, with extra score for organic prompts. The team has called that code obsolete.

Incentive

Not documented for 305, and with no mainnet subnet there are no emissions to describe. On the testnet slot no neuron has incentive or dividends (2026-10-31), and one uid (uid 0) gets 98.1% of the roughly 295 alpha emitted in the last epoch. These are testnet tokens: no value claim.

Caveats

  • Testnet only and dormant: 8 of 256 slots filled, 2 validator permits, no incentive or dividends. Weight ages grew by exactly the blocks elapsed since the reads of 2026-10-26 and 10-27, so nothing was set in between.
  • The new design for 305 is not documented anywhere found: no repo, docs or announcement beyond the owner's one-line post of 2025-12-18. The mechanism text above describes the old subnet 15.
  • The ops repo named in the 2024 chat for miner and validator setup is private or gone (HTTP 404 on 2026-10-31). GitHub's API was rate limited, so other repos were not checked.
  • chain-insights.ai is a separate fund-tracing tool whose repo mentions no netuid, miners or validators. Its GitHub organisation matches the slot's on-chain name, chainswarm: a link is suggested but unverified.
  • Who runs the 8 neurons, and why one uid takes 98.1% of the testnet emission, was not read. Emission and hardware figures for subnet 15 are from 2024 owner posts and were not checked.
