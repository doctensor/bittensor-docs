What it is

This channel is the home of Blockchain Insights, a team that ran subnet 15 on mainnet from October 2023 until it was deregistered on 2024-08-25. That subnet had miners index Bitcoin transaction data so that validators could query them, including with natural-language prompts. Since then the team has used testnet slots (97, 146 and now 305) for a rebuilt version, but it has published no documentation for it. The domain chain-insights.ai now hosts a separate blockchain forensics tool that does not mention a subnet.

How it works

Miners

Nothing is documented for netuid 305. For the old mainnet subnet 15, miners ran a Bitcoin indexer on heavy hardware (the owner mentioned up to about 1.6 TB of use in August 2024), served graph queries, and ran an LLM engine that needed a third-party API key. The owner told a testnet miner in September 2025 that the older testnet and miner code were obsolete and that a new version was coming.

Validators

Nothing is documented for 305. The old repo describes validators that benchmarked miners on queries, checked how recent the indexed blocks were and tracked uptime, and the team said organic prompts gave extra score. These details are historical and the team has called the old code obsolete.

Incentive

Not documented for 305, and with no mainnet subnet there are no emissions to describe. For the old subnet 15 the owner said in August 2024 that its emission share had risen slightly while miners complained it had fallen; this was not checked.

Getting started

  1. There is no current guide for netuid 305. The team told testnet miners in 2025 that the old code is obsolete.
  2. Ask in the channel and wait for the owner; moderators there only point people to the general testnet FAQ and do not answer subnet-specific questions.
  3. Do not rely on the old repo's testnet instructions or on mainnet registration: netuid 305 does not exist on mainnet.

Caveats

  • Testnet only and dormant. A testnet read on 2026-10-21 (block 8273091) shows netuid 305 registered on 2025-12-18 under the on-chain name chainswarm, with 8 neurons; the date matches the owner's last channel message. Weights, who runs the miners and whether anything is running were not read.
  • The new design for 305 is not documented anywhere found: no repo, docs or announcement beyond the owner's one-line post on 2025-12-18. The mechanism sections above describe the old mainnet subnet only.
  • The ops repo that the 2024 chat pointed to for miner and validator setup could not be cloned on 2026-10-21 (not found or private), and GitHub's API was rate limited, so repo activity beyond the old subnet repo was not checked.
  • The chain-insights.ai product (a command-line tool and hosted graph for tracing funds, with its own GitHub organisation) lists Bittensor only as a data source. No page or repo read says it is connected to subnet 305. The testnet slot's on-chain name, chainswarm, matches the GitHub organisation that hosts the chain-insights repo, which makes a link likely but it is still unverified.
  • Emission and hardware figures come from owner posts in August 2024 and were not checked against the chain or code.
