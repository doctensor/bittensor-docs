What it is

NIOME is Genomes.io's subnet for privacy-safe synthetic genomic data for pharma research. Miners now submit synthetic CRISPR designs for the HBB (sickle-cell) gene, which validators simulate and score. V4 would predict drug response and runs only on testnet. Netuid 55 was Precog before.

How it works

Miners

V3 (mainnet): each miner gets the same task and a 300-second upload link, and returns CRISPR experiments for the HBB gene (guide RNA, target, strand, mutation, Cas9 or Cas12a, cell type). Validators simulate the outcomes. V4 (testnet): miners call gene variants and drug-prescribing actions for synthetic patients and state a confidence.

Validators

A validator fetches the task from the team's backend, sends it to miners one at a time, and 1.5 hours into each 2.4-hour round scores the files: format checks, a simulated cut-and-repair outcome, a consistency score and a fidelity score, averaged over three random seeds. Consistency is how well a random forest predicts the simulated outcomes from the designs.

Incentive

Only the top ten scores get weight, split from 30% for first to 1% for tenth. A 'burn' share goes as weight to the owner's own validator uid: 99% until 2026-10-18, 1% since. The chain withholds it, but that uid also earns validator dividends.

Roles and requirements

Miner Medium barrier

Writes its own generator and uploads CRISPR designs (about 250 rows reported) within 300 seconds.

  • Guide: Ubuntu 22.04, Python 3.12, standard port forwarding; no Windows.
  • Miners say some operators run 10 to 90 instances each (unmeasured).
  • If tasks return 401, set require_receiver=False (team advice, 10-19 and 10-20).
  • The guide's requirements.txt is not in the repo (it uses pyproject.toml).

Validator High barrier

Fetches the task, scores miners' designs and sets weights each round.

  • Backend calls are signed with the validator hotkey; whether any validator is accepted is not documented.
  • Only the owner's validator (uid 119) appears in the public results feed.
  • The guide still asks for Docker for PharmCAT, which the V3 code does not use.

Getting started

  1. Read the pinned posts in the subnet channel first; the site's miner and validator pages say docs are coming soon.
  2. Miner: Ubuntu 22.04, Python 3.12, 16 vCPU, 16 GB RAM, GPU per the guide. Clone genomesio/subnet-niome and install from pyproject.toml.
  3. Write your own generator (process_task is a stub); benchmark_submission in the repo scores a file locally.
  4. Register a hotkey on netuid 55 with btcli (about 0.002 TAO), then run neurons/miner.py with --netuid 55 on finney (open axon port).
  5. Upload each result to the task's link within 300 seconds, then look for your uid in the results feed.

Caveats

  • Scoring is disputed: miners say the top consistency values (up to 0.71) cannot come from the public code, and many rows share one decimal tail. Not tested here.
  • The live validator may differ from the repo: a validator-side change was reverted on 10-19, and no commit explains the 10-21 coverage fix or the end of negative rows.
  • Tasks and scores run through the team's closed backend; only the owner's validator posts to the feed, and other validators' top weights match it.
  • Submissions and weights are keyed by uid, so a uid taken over mid-round inherits the old result (reported 10-02, no fix seen).
  • The V4 date and token migration are unanswered; the site and the team disagree on whether the HBB challenge is done.
