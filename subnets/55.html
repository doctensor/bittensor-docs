What it is

NIOME is Genomes.io's subnet for privacy-safe synthetic genomic data for pharma research. Miners submit synthetic CRISPR designs for the HBB (sickle-cell) gene; validators simulate and score them. V4, a drug-response task, runs only on testnet. Netuid 55 was Precog until January 2026.

How it works

Miners

V3 (mainnet): every miner gets the same task and a 300-second upload link, and returns CRISPR experiments for the HBB gene (guide RNA, target, mutation, Cas9 or Cas12a). V4 (testnet): miners call gene variants and drug actions for synthetic patients.

Validators

A validator fetches the task from the team's backend, sends it to miners one at a time, then scores the files: format checks, a simulated cut-and-repair outcome, a consistency score and a fidelity score, averaged over three random seeds. Rounds are 3.6 hours apart (2.4 before 11-04); the feed shows pauses of 18 to 147 hours from 11-03 to 11-11. Scored files go up best first and, since 11-05, the seeds are reported after scoring.

Incentive

Only the top ten scores get weight, from 30% for first to 1% for tenth; a 'burn' share goes to the owner's validator uid (99% until 10-18, 1% since). The chain withholds it, but that uid also earns validator dividends.

Getting started

  1. Read the pinned posts in the subnet channel; the site's miner and validator docs say 'coming soon'.
  2. Miner: Ubuntu 22.04, Python 3.12, 16 vCPU, GPU. Clone genomesio/subnet-niome and install from pyproject.toml.
  3. Write your own generator (the repo's process_task is a stub); benchmark_submission scores a file locally.
  4. Register a hotkey on netuid 55 with btcli (about 0.002 TAO now; it moves with registrations), then run neurons/miner.py --netuid 55 on finney.
  5. Upload each result to the task's link within 300 seconds, then find your uid in the results feed.

Caveats

  • Scoring is disputed and the team has shared no data; whether the live validator runs the latest code is not shown.
  • Weights follow the uid: a hotkey registered on a winning uid before weights are set is paid for the old hotkey's score (seen 11-06, reported 10-02; none among 17 uids read on 11-13).
  • The feed dropped the five rounds of 11-05 to 11-08 that it showed on 11-09; no cause is stated, nor for the 6-day gap.
  • The chat was not re-read after 11-02 (archive down): team replies, the V4 date and migration figures are unchecked.
