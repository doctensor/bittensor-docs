What it is

Eastworld is a simulated open world used to evaluate and train general AI agents. Miners write LLM-driven agents that explore the world, collect items, talk to characters, trade and complete quests; validators relay observations from a team-run Eastworld server to each agent and sync its steps. The project ran on mainnet as SN94 from its launch announcement on 2025-04-20 until the slot was deregistered in late November 2025. Its testnet copy is netuid 333 (it replaced testnet netuid 288 on 2025-11-11), and the team's site says it will keep building there.

How it works

Miners

Write an agent, usually backed by an OpenAI-compatible model or a local vLLM or SGLang server, that answers validator requests with function calls: moving, inspecting, collecting, talking to characters, discarding items, an emergency return, and item-exchange actions. Quests are not assigned; agents find them by exploring or talking to non-player characters. The repo ships four demo miners (a random wanderer, a basic ReAct agent, a reasoning-model agent and a SLAM-plus-LangGraph agent). The guide says the subnet rewards agent development, not compute.

Validators

Fetch each agent's telemetry from the Eastworld server, use an LLM to write a text description of what the agent perceives, send it to the miner as a synapse, take back the miner's function-call decision and sync the step with the server. Weights come from aggregated scores read from the team's Leaderboard API, so scoring depends on a team-run server that the repo does not contain.

Incentive

Per the miner guide, a weighted score of 15% action score, 15% explorer score and 70% quest score. Action and explorer scores lose a fixed amount each hour and quest score decays by a factor of 0.9 per hour. Invalid or repeated actions are penalised. A dynamic emission burn tied to progress on a shared world quest is documented (the target ratio is not given). In chat on 2025-11-19 the team said a 50% static burn was being added and the dynamic part cut from 30% to 20%. These are statements from docs and chat about the mainnet period; no burn logic is visible in the repo code.

Getting started

  1. Treat this as testnet work only: netuid 333 exists on the test network, not on mainnet, and the team has not confirmed since 2025-11-21 that the testnet validator is still running.
  2. Get testnet TAO (the miner guide points to a Discord request post) and create a testnet wallet.
  3. Clone the subnet repo and install it with uv or pip, following docs/guide_for_miner.md.
  4. Register a miner with btcli on the test network, netuid 333.
  5. Set credentials for an OpenAI-compatible model or point the miner at a local vLLM or SGLang server, then run neurons/miner.py with the test network and netuid 333, and check the external endpoint is reachable from another host.
  6. Validators follow docs/guide_for_validator.md; they need an LLM for the perception text and the address of the team's Eastworld testnet server.

Caveats

  • Testnet only. No mainnet netuid 333 exists, and nothing here describes mainnet emissions or token economics. The mainnet SN94 slot now belongs to a different project, so SN94 material in the repo and in the older chat describes this project's former slot.
  • A testnet read on 2026-10-21 (block 8273088) shows netuid 333 registered on 2025-03-30 under the on-chain name Eastworld, with 14 neurons, so the slot still carries the project's name. Which of those are active miners or validators, and whether weights are being set, was not read.
  • The repo is frozen since 2025-11-24 and its guides still describe mainnet SN94 steps. The Hugging Face dataset has had no upload since 2025-11-26. The team's site is live and still lists this subnet page alongside its game projects, but it does not say whether the testnet world is running.
  • Scoring depends on a team-run Eastworld server and Leaderboard API that are not in the repo, so the scoring rules above come from the guide and could not be checked against code. The testnet server address in the validator guide returned a 404 at its root on 2026-10-21; the API path itself was not probed.
  • The burn settings come from the docs and chat only. The repo's code has no burn logic, the target ratio is not stated, and the 50% static burn was a team statement from the mainnet period that cannot be verified now.
  • Chat since December 2025 has almost no team posts, so the project's current plans are known only from the January 2026 statement and from the site. Discussion of price, buybacks and speculators in the November 2025 chat is not included.
