What it is

Eastworld is a simulated open world for evaluating and training general AI agents. Miners write LLM-driven agents that explore, collect items, talk to characters, trade and complete quests; validators relay the world state from a team-run server and sync each agent's steps. It ran on mainnet as SN94 until late November 2025 and now exists only as testnet netuid 333.

How it works

Miners

Write an agent, usually backed by an OpenAI-compatible model or a local vLLM or SGLang server, that answers validator requests with function calls: move, inspect, collect, talk to characters, discard, exchange items. Quests are not assigned; agents find them by exploring or talking to non-player characters.

Validators

Fetch each agent's telemetry from the Eastworld server, have an LLM write what the agent perceives, send it to the miner, take back its function-call decision and sync the step. Weights come from aggregated scores in the team's Leaderboard API, so scoring depends on a team-run server that is not in the repo.

Incentive

Per the miner guide: score = 15% action + 15% explorer + 70% quest; action and explorer scores lose a fixed amount each hour, quest score decays by 0.9 per hour. A dynamic emission burn tied to a shared world quest is documented, and on 2025-11-19 the team said it was adding a 50% static burn. None of this is visible in the repo code.

Roles and requirements

Miner Low barrier

Writes an LLM-driven agent that answers validator requests with function calls in the simulated world.

  • The guide says the subnet rewards developing agents and architectures, not supplying compute.
  • No Dockerfile or .env.example; LLM credentials go in OPENAI_BASE_URL and OPENAI_API_KEY or a .env file.

Validator Low barrier

Relays each agent's world state from the team's server, writes the perception text with an LLM, calls the miner and syncs the step.

  • Server access uses HTTP Basic auth: hotkey plus timestamp as username, a hotkey signature as password (guide).
  • Whether the Eastworld server admits every registered validator is not documented, so openness is unknown.
  • Chain: the global stake floor for setting weights reads 0 TAO; the permit holders' own stakes were not read.

Getting started

  1. Treat this as testnet work only: netuid 333 is on the test network, not mainnet, and no validator has set weights for about 110 days (2026-10-31), so expect no scoring.
  2. Get testnet TAO (the miner guide links a Discord request post) and create a testnet wallet.
  3. Clone Eastworld-AI/eastworld-subnet, install it with uv or pip (Python 3.11+) and register with btcli on the test network, netuid 333.
  4. Set OPENAI_BASE_URL and OPENAI_API_KEY (or a .env file) for a hosted or local vLLM / SGLang model, run neurons/miner.py on the test network, and make the endpoint reachable.
  5. Validators follow docs/guide_for_validator.md: an LLM for the perception text, a stake on the subnet and the address of the team's Eastworld testnet server.

Caveats

  • Testnet only: nothing here describes mainnet emissions or token economics. The guides' mainnet steps (SN94) describe the former slot.
  • Testnet weight dates are estimates from block numbers. Who holds the 12 permits, why weights stopped and whether the testnet server or livestream runs were not read; the testnet endpoint's root returns 404.
  • Scoring depends on a team-run server and Leaderboard API that are not in the repo, so the guide's scoring rules could not be checked against code; the burn settings come from docs and chat only.
  • Current plans are known only from the 2026-01-20 statement and the team's site.
