What it is

Chutes is a hosted inference service with an OpenAI-compatible API for open-source models. Miners supply GPU servers that run it in confidential virtual machines, and the operator, Chutes Global Corp, routes the traffic. Since 2026-10-26 it also sells inference that runs off-network, unpaid by emissions.

How it works

Miners

Miners run one control server plus GPU hosts, each a confidential virtual machine (Intel TDX seals it from its host) proven by hardware attestation. A scheduler, gepetto, picks which chutes (apps) to run and claims bounties for serving new ones first.

Validators

The validator is the operator's API platform: it routes requests to miners and records audit data. All 14 weight-setting validators put their top weight on the same miner on 2026-10-31, which fits relaying one team result. The public API repo, archived about 2026-10-29, trails live scoring; the team plans a new public repo. A public score feed and an auditor let anyone recompute scores.

Incentive

A miner's weight is its share of compute units over the last day; the public score feed matches this exactly. Units are running time times a GPU multiplier with bonuses, which the team retuned on 2026-10-28 and 10-29 (not visible in the repo). Emission splits 18% owner, 41% validators, 41% miners, none burned. 17 of 256 UIDs are paid (top five 61%); the owner's validator UID takes about 10%.

Roles and requirements

Miner High barrier

Supply TDX-confidential GPU servers; pay follows compute time.

  • Register one UID, no axon; add each GPU server with the miner CLI.
  • Bare metal or VMs with unique static IPs (no Runpod or Vast); RAM per GPU at least its VRAM.

Validator High barrier

The operator's platform sets weights; outsiders delegate or run the auditor.

  • The README advises delegating to the team's validator via a child hotkey; miners choose which validator gets their servers.

API user Low barrier

Pay per token for hosted models, or deploy custom chutes.

No further detail found in the sources.

Shift to off-network inference

  • Subscriptions ended; billing is pay-as-you-go. Since 2026-10-26 extra models run off-network, unpaid by emissions (7 of 17 catalog models are not confidential).
  • Team says miner compute stays confidential, standard inference will not be incentivised and off-network revenue will not be linked to the chain; the revenue page is gone.

Getting started

  1. Check the host guide: Ubuntu 26.04, an Intel TDX server, an Intel PCCS API key, a validated 8-GPU layout.
  2. Provision one non-GPU control server (4 cores, 32 GB) with the miner repo's Ansible and Helm.
  3. Register one hotkey with btcli subnet register --netuid 64; announce no axon.
  4. On each GPU host, run the sek8s host setup and launch the confidential VM.
  5. Add each VM with chutes-miner add-node (name, validator hotkey, hourly cost, GPU, API addresses).
  6. Tune gepetto; run chutes-miner tee start-maintenance before reboots.

Caveats

  • Production validator code is unconfirmed: the public API repo is archived and bonuses were retuned off-repo, though live scores match its formula.
  • Chain figures are a snapshot (2026-10-31); weights are opinions, not payouts; miner pay is gross emission.
  • Usage, revenue and stake-lock claims are the team's own and unverified.
  • Whether smaller or non-validated TDX servers are accepted is not documented.
  • Parallax participation is undocumented; its report is AI-generated.
