What it is

Chutes is a hosted inference service with an OpenAI-compatible API for open-source models. Miners supply GPU servers that run it in confidential virtual machines, and the operator, Chutes Global Corp, routes the traffic.

How it works

Miners

Miners run one control server plus GPU hosts, each a confidential virtual machine (Intel TDX seals it from its host) proven by hardware attestation. A scheduler, gepetto, picks which chutes (apps) to run, serving new ones first for a bounty.

Validators

The validator is the operator's API platform: it routes requests to miners and records audit data. All 14 weight-setting validators put their top weight on the same miner (one, silent since 11-02, is active again), which fits relaying one team result. They sit under 13 coldkeys: three hotkeys take 79% of dividends, about 45% of counted stake was delegated in via parent hotkeys, and the chain does not name who runs the two largest non-owner ones; the second also validates on subnets 32, 43 and 48. Six paid miners hold validator permits but have never set weights; three of them gained permits since 11-12.

Incentive

A miner's weight is its share of compute units over the last day; the public score feed matches this within 0.2 points. Units are running time times a GPU multiplier with bonuses, which the team retuned on 2026-10-28 and 10-29 (not visible in the repo). Emission splits 18% owner, 41% validators, 41% miners, none burned. 15 of 256 UIDs are paid (top five 67.6%); the owner's validator UID takes about 11%.

Roles and requirements

Miner High barrier

Supply TDX-confidential GPU servers; pay follows compute time.

  • Register one UID, no axon; add each GPU server with the miner CLI.
  • Bare metal or VMs with unique static IPs (no Runpod or Vast); RAM per GPU at least its VRAM.

Validator High barrier

The operator's platform sets weights; outsiders delegate or run the auditor.

  • The README advises delegating to the team's validator via a child hotkey; miners choose which validator gets their servers.

API user Low barrier

Pay per token for hosted models, or deploy custom chutes.

Getting started

  1. Check the host guide: Ubuntu 26.04, an Intel TDX server, an Intel PCCS API key, a validated 8-GPU layout.
  2. Provision one non-GPU control server (4 cores, 32 GB) with the miner repo's Ansible and Helm.
  3. Register one hotkey with btcli subnet register --netuid 64; announce no axon.
  4. On each GPU host, run the sek8s host setup and launch the confidential VM.
  5. Add each VM with chutes-miner add-node (name, validator hotkey, hourly cost, GPU, API addresses).
  6. Tune gepetto; run chutes-miner tee start-maintenance before reboots.

Caveats

  • Production validator code is unconfirmed: repo archived, bonuses retuned off-repo; live scores match its formula.
  • Chain figures are a snapshot (2026-11-14); weights are opinions, not payouts; miner pay is gross emission.
  • Team chat after 2026-11-01 was not read (archive offline).
  • Usage, revenue and stake-lock claims are the team's own and unverified.
  • Whether smaller or non-validated TDX servers are accepted is not documented.
  • Parallax participation is undocumented; its report is AI-generated.
