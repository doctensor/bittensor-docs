What it is

Allways was built for native cross-chain swaps: miners delivered the destination asset against posted collateral, a Solana program settled. On 2026-11-17 the owner merged a change that moved that code to branch allways-old and makes every validator put all weight on one pinned uid, the 'treasury miner'. The team's site now offers a routed swap app that names no miners.

How it works

Miners

No independent miner can earn: validator code pins all weight on uid 78, the repo's 'treasury miner', registered nine minutes before the change merged on 2026-11-17. The old miner lives only on branch allways-old.

Validators

Each validator runs a small program that sets weight 1.0 on uid 78 every epoch (on the owner's uid, which burns it, if that slot holds another hotkey). No scoring, no open port. 10 of 11 weight rows on chain point at uid 78; the eleventh is the owner's, last updated 2026-04-02.

Incentive

The miner side of emission, half of what the subnet pays to uids, goes to uid 78: 147.6 alpha per epoch, about 2,944 a day. Its hotkey holds 10,332 alpha, the exact sum of every epoch since 2026-11-18, so none was sold. The owner slot (uid 53) earns 0%.

Roles and requirements

Miner High barrier

Nothing to run: the miner code is archived and the weight is pinned to one uid.

  • Until 2026-11-17 a miner posted a rate backed by SOL or a TAO bond; a missed delivery slashed 110% (docs, archived). Uids 32 and 120 read 0%.

Validator Medium barrier

Run the validator image: it sets one weight on uid 78 every epoch (no scoring).

  • 13 permit holders (2026-11-21); 11 have weight rows, 10 on uid 78. Without a permit the program submits nothing.
  • The old validator needed a whitelisted Solana key and a paid Solana RPC; the new image ignores them.

Getting started

  1. Do not plan to mine: while validators pin all weight on uid 78, no other miner can earn.
  2. To validate: register a hotkey, reach the validator permit (1,000 TAO stake threshold) and start docker-compose.vali.yml; no GPU, no open ports.
  3. Preview first: run the validator with --dry-run; it logs the target uid and exits, no wallet needed.
  4. To swap assets, use all-ways.io, its MCP server or HTTP API; no account or key is needed.

Caveats

  • Who controls uid 78 and what the treasury does with its alpha are not stated; the chain shows only that it is not under the owner's keys.
  • Whether the swap app settles through subnet miners is not stated: its docs and API name providers, not miners or the subnet.
  • Usage: the old API is offline (last read 2026-11-15); the new app shows only a referral leaderboard (37 swaps, about USD 282), unchecked.
  • No docs describe the archived code: the docs and Ventura Labs hosts return 502. Chat after 2026-10-30 not read (archive down).
  • Why weight rows fell from 12 to 11, and when uid 78 got its permit (held, never set weights), are not known.
