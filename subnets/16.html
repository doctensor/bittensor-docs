What it is

SN16 was launched in June 2026 by a team that called it Fast Thinker, an efficient-reasoning subnet whose slogan was to think less and achieve more. Its public repo is no longer reachable. The on-chain name is now Zero Hour and its identity links to Kenju, a proposed subnet in which contributors would invent small disruptions to robot household tasks and demonstrate recoveries, to produce training data for vision-language-action models. The Kenju repo contains only a short symbolic demo, with no Bittensor miner or validator code.

How it works

Miners

Not documented for the current identity. Under Fast Thinker the team said in July 2026 that miners submitted private fine-tuned reasoning models to validators of their choosing. Kenju proposes that miners would design short episodes of recoverable trouble for robots, each with a goal, a twist and a recovery, but this is a concept, not a running mechanism.

Validators

Under Fast Thinker the team described scoring in which correctness dominates and token efficiency adds a bounded bonus, over math, long-context question answering and science tasks weighted 50, 30 and 20 percent. The code is no longer readable, so this is unverified. Kenju says validators would judge whether episodes are believable, different, solvable and useful; its demo only prints illustrative weights.

Incentive

On chain at block 9334360, one UID holds a validator permit and 100% of incentive, and all three permitted validators that have set weights point only at it. Its hotkey and coldkey are not the registered owner keys. Who controls it was not determined, and the team said in July that this UID had been used in its own dev test.

Getting started

  1. No way to mine or validate is documented for the current identity.
  2. The Kenju repo's only runnable part is a local demo: with Python 3.11 or newer, run python -m kenju demo. It uses no chain access and is not a miner.

Caveats

  • This page describes an unclear project. The old Fast Thinker repo and dashboard returned 404 on 2026-10-21, so its scoring could not be checked.
  • Chat from July to September contains many allegations about the owner and about the single rewarded UID. This page uses only what chain data or team statements support, and does not include them or any market data.
  • Chain data is one snapshot (blocks 9334356 to 9334361, 2026-10-21). Weights are validator opinions, not payouts, and a chain match with the owner's keys does not by itself prove or disprove affiliation.
  • Chat before 2026-07-03 was not read, and no website for the project was found.
  • The on-chain name changed at least twice (a third-party bot read a different name on 2026-08-28), and the channel name still says fast-thinker.
