What it is

Ormas, run by Heron Cove LLC, sells verified coding outcomes. A client supplies a GitHub repo, a task and an automated test; miners quote a price, deliver a branch and are paid only if the test passes.

How it works

Miners

A miner runs the open ormas-subnet software against the Ormas gateway. For each queued task it offers a firm price, a limit (estimate plus hard ceiling) or declines; the gateway awards the lowest expected total cost. The winner clones the repo, makes the change, runs the tests and publishes the branch.

Validators

A checker re-runs the client's test on the branch and signs accept or reject. The reference checker is public, but the team runs all acceptance today. Six hotkeys hold validator permits; the README says a weight service relays a gateway-computed vector.

Incentive

An accepted delivery freezes an emission target of 2x its settled USD price (since 2026-10-05); unearned emission goes to the owner's uid. On 2026-11-13 that uid held 71.8% of emission; the five other validators shared 28.1% as dividends and independent miners 0.1%. Stored split: 18% owner, 49% validators, 33% miners.

Getting started

  1. Check eligibility: the beta is US-only and the operator approves each miner.
  2. Sign in at ormas.ai and mint a runner key (no expiry).
  3. Install the miner (Python 3.10+) or re-clone the repo, then run ormas-miner login and register a miner name.
  4. Ask the operator for slot approval before paying for registration (0.0005 TAO, all 256 slots taken).
  5. Finish the proof task, bind your hotkey with ormas-miner register-hotkey, then take offers.

Caveats

  • Almost no emission reaches independent miners: the owner's uid held at least 98.5% of incentive in every read since 2026-10-26; who runs the earning uids is not public.
  • The team runs acceptance and its own miner.
  • Usage is the team's word: the network feed says 'insufficient data'; independents show 100% acceptance, yet independent uids earn 0.18% of incentive.
  • Miners report non-selection with no reason shown; no team chat post since 2026-10-18, and chat after 10-30 was unreadable on 11-13.
  • Docs say independent Protected-tier mining is not open, yet a 2026-10-18 team post said a slot was approved.
