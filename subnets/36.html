What it is

Weir is a GPU rental marketplace. Miners list GPU machines, a validator checks each card, and renters pay by the hour on weircompute.com.

How it works

Miners

A miner runs a node on a GPU machine and gives Weir support its control address. Until 11-11 the public validator sent each card a random matrix job; a wrong answer zeroed the miner for 24 hours.

Validators

Until 11-11 the public code had the validator call each node every 5 minutes, recompute random rows and set weights; it is no longer in the repo.

Incentive

Of the miner share, 10% goes to rented GPUs (hours x card weight, capped per miner at the platform fee its rentals paid) and up to 90% to idle verified GPUs after 14 days of passed checks; the rest goes to a reserve hotkey. Rent is paid on top: 95%, weekly.

Getting started

  1. Check the card is on the list (Ubuntu 22.04 or 24.04, NVIDIA driver, Docker). Register a hotkey on SN36 (0.3 TAO burn).
  2. Install the NVIDIA container toolkit and Sysbox, then the node from the repo.
  3. Get a fee quote from Weir (held 7 days), then pay the fee per GPU from the coldkey, or in USDT or USDC through Weir.
  4. Run the self-test with a payout address, start the node and give Weir support your hotkey, machine name and control address.
