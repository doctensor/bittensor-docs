What it is

AdTAO is a prediction contest for Google Ads. Miners submit containerised models that forecast how real advertising changes will move cost, conversions and efficiency over 7, 14 and 28 days. The team runs every model daily, scores it once outcomes settle and pays the 20 most accurate.

How it works

Miners

Miners ship a model, not predictions: a container that turns account-change episodes into P10/P50/P90 ranges for cost, conversions and efficiency at 7, 14 and 28 days.

Validators

The team builds each daily basket, collects settled outcomes and scores each prediction once (interval accuracy 50%, width 10%, direction 15%, goal metric 15%). Validators fetch its weight vector with an API key and set it on chain.

Incentive

Models are ranked by recent score against the field; the top 20 are paid on a fixed curve (50%, 25%, 10%, then 80% of the previous rank).

Roles and requirements

Miner Low barrier

Builds a forecasting container; the team runs and scores it daily.

  • Sandbox: no network, 3,072 MB address space, 15 CPU-minutes; a run stopped by a limit is your failed run.
  • Paid: top 20 with 7 scored days, 50 scored predictions (250 from 2026-11-17) and 1,000 alpha; one seat per coldkey; the earliest of identical models.
  • Gross pay: about 11.8 TAO a day over 20 miners; 0.16 outside the top 5.

Validator High barrier

Sets the team's daily weight vector on chain; scoring stays with the team.

  • 64 UIDs hold permits; 7 set weights, 57 none in over 5 epochs; all 7 top UID 193.

Rules and field since 2026-10-30

  • Since 2026-10-30 results compare the 28 days before a change with the days after; first settled results (due about 2026-11-08) not read.
  • Run changes: from 2026-11-07 scoring can pause and a new campaign's first 7 days give no episodes; from 2026-11-09 Performance Max changes count (at most a fifth of a basket); shared negative keyword list changes count from 2026-11-15.
  • From the 2026-11-16 run a model unchanged for 40 days is not run (counted per model) and released models are copied; from 2026-11-17 eviction after 5 strikes in 14 runs and a 250-prediction placement floor; the 75% participation bar no longer gates pay.
  • One earning seat per coldkey; a 5% admission margin over the naive baseline; a 3,072 MB memory cap; our-side failures are never strikes, and an evicted model returns after 7 days on a clean run.
  • From 2026-12-05 a conversion-count score is half the entry score of small-campaign results; shown, not counted, since 2026-11-07.

Getting started

  1. Register a hotkey on netuid 21; set up Docker and the repo tools.
  2. Create the one-time ed25519 key and bind it on chain (quickstart steps 3 and 4).
  3. Start from the reference model and train on the v5 and v6 slices (drop budget-only moves under 5 from v5).
  4. Return 7, 14 and 28 day blocks per episode, repeatably and offline, inside the sandbox limits.
  5. Push the image by digest to a public registry and commit sn21-model:v1:<repo>@sha256:<digest> on chain.
  6. Hold 1,000 alpha; check admission on the miner-status page. Validators: ask the operator team for an API key.
