What it is

Score pays miners for computer-vision models. The team publishes a list of tasks: seven public object-detection tasks and two private ones (football events, cricket deliveries). Its own validator scores miners against ground truth, and the best miner per task takes that task's share.

How it works

Miners

Public tasks: train an open-source model, publish it on Hugging Face, host it on Chutes and commit it on chain. Private tasks: run a Docker image that answers challenges on port 8000 and commit its registry address.

Validators

The team's validator sends challenges, scores answers against ground truth from Score and its data partners, and sets weights. Public tasks score 0.6 x box accuracy plus 0.4 x a false-positive score, averaged over 3 days. Private images are spot-checked; mismatches are blacklisted. Private scoring: football events must match real ones within 1 to 3 seconds; cricket scores 12 ball-tracking fields.

Incentive

The pool splits 12% owner, 44% validators, 44% miners (owner cut was 18% until 11-04). A public task's share goes to its best miner, re-picked hourly; if scores are within the task's margin (0.05; 0.041 person, vehicle, petrol, room dirtiness; 0.039 fallen person), the earlier on-chain commit wins. Private tasks pay the top three 80/15/5 with no tie-break.

Roles and requirements

Miner (public tasks) Medium barrier

Train an open-source detector, host it on Chutes, commit it on chain.

  • A public winner earns about 5.2 TAO per day while it holds the win (gross, 2026-11-06).

Miner (private tasks) Medium barrier

Serve a Docker image that answers football or cricket challenges within 30 seconds.

  • The commit must carry the exact task id, or the miner is skipped.
  • Varied solutions, OCR of cricket speed or a model left out of the image get hotkeys blacklisted (team).

Validator High barrier

Fetch challenges, score miners, set weights; in practice the team's validator decides payouts.

  • Private miners only answer the team's validator, so others cannot score private tasks.

Who is paid

  • 13 uids earn miner incentive (2026-11-06): seven public winners at 4.3-5.2% each, the football podium (about 37 / 7 / 2%) and the cricket podium (about 16 / 3 / 1%).
  • The football uids share one coldkey (3 paid of 6 held), the cricket uids another (3 of 12): 66% of miner pay, identical published scores in each podium; holders unknown.
  • The seven paid public uids sit on seven coldkeys. The team's winners file changed hands often in 24 hours (Vehicle 13 times, petrol 14); chain pay trails it by about an hour (inference).

Getting started

  1. Install the sv tool, create a wallet and register a hotkey on subnet 44 (burn about 0.05 TAO).
  2. Public: get a developer-enabled Chutes account and Hugging Face token, meet the 100 ms limit on 2 vCPUs, run sv deploy-os-miner.
  3. Private: build the /challenge Docker image, push it to a private registry, give Score read access, set your axon, run sv deploy-pt-miner.
  4. Commit once and keep your hotkey registered: a new commit resets your score.

Caveats

  • Shares come from a team list that can change without a code change.
  • Payouts rest on one team-run validator and team ground truth; chain weights are validator opinions, not payouts.
  • Miners disputed the tie-break and labels almost daily through 2026-11-01 (chat since not read).
  • Docs lag code: the README links a missing root MINER.md; card grading is not live.
