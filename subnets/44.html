What it is

Score pays miners for computer-vision models. The team lists seven public object-detection tasks and two private ones (football events, cricket deliveries); its validator scores miners against ground truth and the best miner per task takes that task's share.

How it works

Miners

Public tasks: train an open-source model, publish it on Hugging Face, host it on Chutes and commit it on chain; a recovered commit expires after seven indexed evaluations (11-14). Private tasks: run a Docker image that answers on port 8000 and commit its registry address.

Validators

The team's validator sends challenges, scores answers against ground truth, and sets weights. Public tasks score 0.6 x box accuracy plus 0.4 x a false-positive score over 3 days; up to 2 zero scores per miner are ignored. A model is ranked only after 30 scored challenges. Private scoring: football events must match real ones within 1 to 3 seconds; cricket scores 12 ball-tracking fields.

Incentive

The pool splits 12% owner, 44% validators, 44% miners. A public task's share goes to its best miner, re-picked hourly; within the task's margin (0.05; 0.041 for person, vehicle, petrol and room dirtiness; 0.039 for fallen person) the earlier on-chain commit wins. Private tasks pay the top three 80/15/5; ties go to the more-tested model, then the lower uid.

Roles and requirements

Miner (public tasks) Medium barrier

Train an open-source detector, host it on Chutes, commit it on chain.

  • A public winner earns about 4.9 to 5.2 TAO per day while it holds the win (gross, 2026-11-14).

Miner (private tasks) Medium barrier

Serve a Docker image that answers football or cricket challenges within 30 seconds.

  • The commit must carry the exact task id, or the miner is skipped.
  • Varied solutions, cricket speed OCR or a model left out of the image get hotkeys blacklisted (team).
  • A hotkey on the team's blacklist (348, 2026-11-14) earns nothing, even as winner (chain, code).

Validator High barrier

Fetch challenges, score miners, set weights; in practice the team's validator decides payouts.

  • Private miners answer only the team's validator.

Getting started

  1. Install the sv tool, create a wallet and register a hotkey on subnet 44 (burn about 0.05 TAO).
  2. Public: get a developer-enabled Chutes account and Hugging Face token, meet the 100 ms limit on 2 vCPUs, run sv deploy-os-miner.
  3. Private: build the /challenge Docker image, push it to a private registry, give Score read access, set your axon, run sv deploy-pt-miner.
  4. Commit once and keep your hotkey registered: a new commit resets your score.

Caveats

  • Shares come from a team list that can change without a code change.
  • Payouts rest on one team-run validator and team ground truth; weights are opinions, not payouts.
  • The blacklist (348 hotkeys) removes miners from pay; the reasons are in team chat, not read.
  • Miners disputed the tie-break and labels almost daily through 2026-11-01 (chat since not read).
  • Docs lag code: the README links a missing root MINER.md; card grading is not live.
