What it is

Engram is a Bittensor subnet design for a decentralized vector database: text, PDFs and images are embedded, stored on miners under an ID derived from the embedding, and checked with storage proofs. One developer builds it, with pull requests from outside accounts, and it has only run on the testnet, as netuid 450.

How it works

Miners

Miners store vectors in a local Qdrant index, answer similarity queries and respond to storage-proof challenges. Each item is meant to be copied to several miners (3 in the README), with optional private namespaces and Arweave for binary files. Writing needs a minimum stake (default 0.001 TAO in the code).

Validators

A validator sends challenges and queries, measures recall, response time and whether storage proofs verify, and sets weights from the combined score. The proofs are HMAC-based; the repo's funding document lists replacing that proof design as planned work, and the roadmap marks a decentralized validator as not done, so one validator is the expected setup.

Incentive

Score is 0.50 recall at 10, plus 0.30 for latency (full marks at 100 ms or less, zero at 500 ms or more), plus 0.20 for the share of storage proofs passed (repo config). Miners below a 50 percent proof rate or flagged for slashing get zero weight. Testnet design only: no mainnet emission split, owner take or token economics exist.

Roles and requirements

Miner Low barrier

Runs a node that stores embeddings, answers similarity queries and passes storage-proof challenges. On testnet nothing is paid now.

  • Docs (miner.md): Python 3.10+, Linux or macOS, systemd unit supplied; the Rust wheel is optional.
  • Optional cloud mining on Akash, paid in USDC on Base: about $0.10 to $0.36 per hour by tier (cloud-mining.md).

Validator Medium barrier

Scores miners with challenges and queries, then sets weights. One validator permit exists on testnet; its holder went silent on day one.

  • Testnet (2026-10-31): 1 validator permit of 64 slots; its last weight update was 1,041 blocks after registration. Commit-reveal is on and no commit is waiting.

Getting started

  1. Only the testnet is documented: install with pip install engram-subnet, pull the Docker image or clone the repo, and follow docs/miner.md or docs/validator.md.
  2. Get testnet TAO yourself (no faucet answer in the archive), register a hotkey with btcli on netuid 450 (test network) and start the node.
  3. Ask in the channel: the API was down on 2026-10-31 and the chain shows no weights since April, so a new miner would not be scored until a validator runs.

Caveats

  • Testnet only. No mainnet netuid 450 exists (2026-10-31); testnet state is not evidence of a working network, and test-network emission has no market value.
  • The testnet read is aggregates only: it does not say who runs the one validator or whether any miner is online. The weight age is an estimate at 12 seconds per block (give or take a day).
  • The Q3 mainnet target has passed. The runbook puts subnet creation at about 1,050 TAO (July 2026) and the team is seeking grants for readiness work.
  • The README's 355 passing tests and its erasure-coding, Arweave and private-namespace claims were not run or checked. Code read at 649f699.
  • The project API returned 502 on 2026-10-21, 2026-10-26 and 2026-10-31; the dashboard was blank on 2026-10-21 and not re-rendered since. A down backend does not show the network is empty.
