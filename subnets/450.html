What it is

Engram is a Bittensor subnet design for a decentralized vector database: text, PDFs and images are embedded, given a content-addressed ID derived from the embedding, replicated across miners, and checked with challenge-response storage proofs. Binary files are meant to be pinned to Arweave, and a mobile mining option runs managed Akash nodes. It is built mainly by one developer and ran only on the Bittensor testnet, where it uses netuid 450.

How it works

Miners

Miners run a node that stores vectors in a local Qdrant index, answers similarity queries and responds to storage-proof challenges. The design replicates each item across several miners (3 copies in the README, erasure coding in the roadmap), with optional private namespaces that use encryption, noise on stored embeddings and key shares split across miners. Requests are signed with a hotkey and writing to the network needs a minimum stake (default 0.001 TAO in the code). Setup on testnet is by pip package or Docker with the testnet netuid in the environment.

Validators

A validator sends challenges and queries to miners, measures recall of the true nearest items, response time and whether storage proofs verify, and sets weights from the combined score every few minutes (README says 120 seconds). The proofs are HMAC-based and bound to the validator's key; the repo's own funding document lists replacing the proof design as planned hardening work. The roadmap lists multi-validator agreement as done and a decentralized validator as not done, so one validator is the expected setup.

Incentive

Score is 0.50 recall at 10, plus 0.30 for latency (full marks at 100 ms or less, zero at 500 ms or more), plus 0.20 for the share of storage proofs passed, as set in the repo's config. Miners below a 50 percent proof rate or flagged for slashing get zero weight. This describes testnet design only; there is no mainnet subnet, so no emission split, owner take or token economics apply, and none were found.

Getting started

  1. Only the testnet is documented. Install the package with pip install engram-subnet, or clone the repo.
  2. Get testnet TAO yourself (a member asked on 2026-10-03 where faucets are and the archive shows no answer), then register a hotkey with btcli on netuid 450 using the test network.
  3. Set the wallet name, hotkey, NETUID=450 and SUBTENSOR_NETWORK=test in the environment file the README describes, then run the miner or validator from the repo's Docker or Python instructions.
  4. Check the live dashboard and ask in the channel before spending time: on 2026-10-21 the API was down and the team had been silent since 2026-07-28.
