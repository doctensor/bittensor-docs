What it is

BrainPlay, built by ShiftLayer, scored AI models by having them play games against each other. Its first game was Codenames, followed by 20 Questions and a 2D platformer for vision models. It ran on mainnet as subnet 117 from late 2025 until the team handed that slot to a new team on 2026-04-29. The channel documented here is the team's testnet one, netuid 335; its testnet design, if any, is not published in the channel.

How it works

Miners

Up to April 2026, per team posts: miners submitted a model (a Hugging Face repo) deployed on Targon compute, started with a deploy script that takes a competition name, a model and serving options. Each Codenames game used two miners and each model played both roles, spymaster and operative. Later posts added 20 Questions (2026-03-17) and a first visual game, a 2D platformer, on 2026-04-18. No post describes miner steps for testnet 335.

Validators

Per the team, validators ran the games and scored them. From version 2.3.2 (2026-03-25) each validator used only the scores it computed itself rather than a shared score table, and from 2026-03-17 validators used Chutes instead of OpenAI in one part of the flow. Validator code was not read because the repository is no longer public.

Incentive

As described by the team in chat before the reset: a winner-takes-all competition per game, with most of the miner emission burned (95 percent in February, lowered to 90 percent on 2026-03-17, and at times 100 percent, which the 2.4.1 hotfix tied to too few games). The alpha stake requirement for miners was removed on 2026-02-20. The mechanism was split into slots for language, vision and vision-language-action benchmarks, with only the first two announced as live or in progress. None of this was checked against the code or chain weights, and no testnet incentive rules are published.

Getting started

  1. No current miner or validator guide was found for testnet 335. The old subnet repository and the project sites were not reachable on 2026-10-21.
  2. Ask in the BrainPlay testnet channel whether testnet 335 is running before spending time or funds.

Caveats

  • This page is about the testnet netuid 335. Mainnet netuid 117 now belongs to a different project (EveryFrame) and is not BrainPlay.
  • The subnet repository the team used (shiftlayer-llc/brainplay-subnet) returned not found without credentials on 2026-10-21 and is absent from the organization's public repository list, so it is private or removed. Mechanism details come only from team posts and may not match the code that ran.
  • The project sites play.shiftlayer.ai and shiftlayer.ai returned gateway errors on 2026-10-21.
  • Miner chat in March and April 2026 raised thin rewards against GPU rental costs and said the subnet was near the top of the deregistration list. These are miner claims and were not checked on chain.
  • A testnet read on 2026-10-21 (block 8273094) shows netuid 335 registered on 2025-04-04 with 60 neurons, under the on-chain name llm-battle rather than BrainPlay. The link between that slot and this team rests on the team's own posts. Whether the subnet is running, and what rules it uses, was not checked.
  • Chain weights were not read.
