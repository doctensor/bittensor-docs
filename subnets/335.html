What it is

BrainPlay, built by ShiftLayer, scored AI models by having them play games against each other: Codenames first, then 20 Questions and a 2D platformer for vision models. It ran on mainnet as subnet 117 until the team handed that slot to a new team on 2026-04-29. This page covers the team's testnet netuid 335, still registered but with no validator weight update for about 225 days.

How it works

Miners

Up to April 2026, per team posts: a miner submitted a model (a Hugging Face repo) served on Targon compute, using a deploy script that takes a competition name, a model and serving options. In Codenames each game used two miners and each model played both roles, spymaster and operative. 20 Questions (2026-03-17) and a 2D platformer for vision models (2026-04-18) followed. No post describes miner steps for testnet 335.

Validators

Per the team, validators ran the games and scored them; from version 2.3.2 (2026-03-25) each used only its own scores. Validator code could not be read. On testnet 13 neurons hold a validator permit; none has set weights for about 225 days (estimated).

Incentive

As the team described it before the reset: winner takes all per game, with most miner emission burned (95 percent in February, 90 percent from 2026-03-17, at times 100). The miner stake requirement was dropped on 2026-02-20, and the mechanism was split into language, vision and vision-language-action slots. None of this was checked in code, and no testnet incentive rules are published.

Caveats

  • This page is about testnet netuid 335. Mainnet netuid 117, once BrainPlay's, now belongs to a different project (EveryFrame).
  • The team's subnet repository returns not found without credentials and is missing from its public list, so it is private or removed. Mechanism details come only from team posts.
  • The sites play.shiftlayer.ai and shiftlayer.ai did not answer on 2026-10-21, 2026-10-26, 2026-10-27 or 2026-10-31.
  • Miner chat in March and April 2026 raised thin rewards against GPU costs and a near-top place on the deregistration list (miner claims, unchecked).
  • The testnet slot is named llm-battle on chain and was registered 2025-04-04; its link to this team rests on the team's own posts. Its two configured mechanisms match the team's description but prove nothing.
  • Weights were read only in aggregate. Weight values, the version key and the Yuma settings were not read, and anything the team runs on another netuid or off chain is invisible.
