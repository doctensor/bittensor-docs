What it is

Safe Scan (repo name cancer-ai) ran model competitions in which miners submit medical-imaging classifiers, such as skin-lesion models, that validators score on data batches supplied by medical institutions. Until early 2026 it held mainnet subnet 76; after being deregistered, the team said it would keep developing and testing on testnet, where the project is discussed under netuid 163. The team's last channel post (2026-04-10) says it is delaying its comeback, and the testnet shows no recent validator activity. The repo and docs still describe the mainnet SN76 setup.

How it works

Miners

Per the docs written for mainnet SN76: miners train a model for the current competition (the documented one is Tricorder-3, 11 skin-lesion classes aligned with ISIC-2025, with an image and demographic data as inputs). Models are ONNX files under an MIT licence, with training code expected, hosted on Hugging Face, with the repo link committed on chain at least 120 minutes before the competition starts. The miner command line has four actions: evaluate, self-check, upload and submit.

Validators

A competition starts when medical institutions add a new data batch to a central Hugging Face dataset repo. Validators detect it, download it and evaluate every eligible model themselves. For Tricorder-3 the docs give the final score as 0.9 times a prediction score plus 0.1 times an efficiency score. Prediction is half accuracy and half weighted F1, with malignant classes weighted 3, medium 2 and benign 1. Efficiency is 1.0 for models up to 50 MB and falls linearly to 0 at 150 MB. The scoring code was not audited beyond finding the efficiency function.

Incentive

The competition doc splits rewards among the top 10 models as 50, 17, 10, 7, 5, 4, 3, 2, 1 and 0.5 percent, with a minimal share for the rest. These figures come from the docs for mainnet; how they apply on testnet, where tokens have no market value (moderator, 2026-03-19), was not verified. Chain weights were not read.

Getting started

  1. Before investing time, ask in the channel whether anyone still runs a validator: the testnet chain shows no validator weights for roughly 171 days or more, and the team's last post says it is delaying its comeback.
  2. Read DOCS/miner.md and DOCS/COMPETITIONS.md in the repo. Both are written for mainnet SN76 (miner.md uses netuid 76 on finney), and netuid 163 and testnet appear only in chat.
  3. Build an ONNX model for the documented competition (Tricorder-3), publish it with its training code under an MIT licence on Hugging Face, and commit the repo link on chain at least 120 minutes before the competition starts.
  4. Use the miner command line (evaluate, self-check, upload, submit). The network flag accepts finney or test; pairing it with netuid 163 is what chat suggests, not what the docs say.
  5. Validator setup was not read in detail and is not summarized here.

Caveats

  • Testnet only. Netuid 163 does not exist on mainnet at the latest block read (2026-10-21) or at five earlier points back about 300 days; mainnet holds only netuids 0 to 128. Chat from before 2026-02 is mostly about the old mainnet SN76, and mainnet SN76 is now a different project.
  • Nothing on chain names Safe Scan for testnet 163: the slot was registered on 2024-05-24 (before the repo was created) and has no subnet identity set. The link to Safe Scan rests on chat (a member on 2026-03-12, a moderator on 2026-03-19) and on the channel's placement. No team post read names the testnet netuid.
  • All repo documentation targets mainnet SN76. A testnet competition config exists (one competition, tricorder-3, evaluation at 14:38 daily with no time zone stated, and a testnet dataset repo on Hugging Face), but whether any competition or dataset is live on testnet was not verified.
  • The project's sites could not be checked: safe-scan.ai returned 403 and dashboard.safe-scan.ai did not respond from the research machine on 2026-10-21, and the melanoma test page linked from the repo returned 404. The skin-scan.ai site loads and describes a patient and clinic skin-health platform with no mention of Bittensor, subnet or TAO.
  • The 'no weights for 171 days' figure comes from chain reads of validator permits and last-update ages only; it does not show that nobody mines or runs software. Scoring formulas above come from the docs, not from an audit of the code.
  • Whether the team will return is unknown; the only statement is the 2026-04-10 delay. Testnet tokens carry no market value, and no price, emission or market figure is given on this page.
