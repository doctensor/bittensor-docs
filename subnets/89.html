What it is

SN89 pays miners who show statistically real skill at calling market direction. Miners submit directional calls (pair plus long or short) with fixed take-profit and stop-loss bands, and validators grade them against public price ticks. Since 2026-10-09 the subnet also runs on-chain Up/Down prediction markets. The operating team (IQ / Delta Compute) says it uses the signals in its own trading and sells them through an API.

How it works

Miners

Low-frequency (LF) miners pick a pair and direction, encrypt the call under a 15-minute drand timelock and put its hash on chain; at most 3 calls per UTC day and 1 hour apart. High-frequency (HF) miners send signed calls over a WebSocket to the team ingest and keep the countersigned receipts, up to 30 a day. Both use the same hotkey. Anyone can also join the Markets competition with sub-accounts that bet Up or Down on 15-minute and 1-hour windows. Referrers (recruiting new miners) are a fourth pool.

Validators

Validators read the on-chain commitments, wait for the timelock to open, check the plaintext against the hash and grade each call on a public, Merkle-anchored tick series: take-profit touched first is a win, stop-loss first is a loss, neither by the horizon is a wash. Grading is meant to be deterministic so anyone can recompute the weights. The repo's single-validator document describes one authoritative validator with others delegating to it, so how many independent validators actually set weights is not established here.

Incentive

Per the code, a miner is qualified once it has at least 8 decisive results and a hit rate that beats a coin flip with about 90% confidence. Weight follows qualified wins times a tier multiplier (1.0x from 55%, 1.2x from 60%, 2.0x from 70%), with each win fading linearly over 30 days and a cap of 20 counted wins on LF (200 on HF). New hotkeys spend 8 days at a dust weight, and a lifetime hit rate confidently below 45% (at least 40 decisive calls) removes a hotkey for good. Copying another hotkey's trades is penalised. Since 2026-10-14 the miner emission is split LF 30%, HF 30%, Markets 20% and referrers 20%. Markets pays entities that post positive net profit on real-stake bets backed by alpha collateral in a vault.

Getting started

  1. Use Python 3.10 (the timelock dependency has no wheels for newer versions), clone the repo and install requirements.txt.
  2. Register a hotkey on netuid 89 with btcli (the README quotes about 0.05 TAO burn).
  3. Get a feed token by sending /token to the team's Telegram signals bot and export it as SN89_FEED_TOKEN.
  4. Run neurons/miner.py in follow, serve or submit mode for LF calls, or submit-hf for HF calls.
  5. Expect an 8-day warmup before wins pay; HF also needs 50 accepted submissions on 8 distinct days.
  6. To practise first, use testnet netuid 496 with the faucet as described in the README.

Caveats

  • Chain weights, miner counts and actual emission amounts were not read for this page.
  • The README's emission table still mentions trailing 7-day wins; the code and the Scoring section use 30 days, which this page follows.
  • Chat on 2026-10-19 asked whether the program page's 55% floor and cap of 20 apply to HF; the code uses a tier ramp and an HF cap of 200.
  • The README links a live board at partner.infinitequant.app/sn89/mechanisms, which returned 404 when checked on 2026-10-21.
  • The Markets money flows (deposits, fees, withdrawals, credits) are taken from the README and were not checked in code or on the live site.
  • Some miners in chat criticise the scoring as paper trading and note the subnet's team trading book had losses in September; these are opinions and team claims, not verified.
  • Rules changed frequently in the last month, so check the README and commit log before relying on any number.
