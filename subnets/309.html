What it is

EchoIC is a voice-cloning subnet. A miner receives a short voice sample and a transcript, produces speech in that voice with a cloning model, and returns an audio file. Validators score the audio for text accuracy, voice similarity, intonation and sound quality. Everything found describes testnet use only, and the channel has been nearly silent since February 2026.

How it works

Miners

Miners run one of four cloning methods in the repository (XTTS by default, Bark, Tortoise or RVC), upload each result to their own storage bucket (Backblaze, Amazon S3 or Cloudflare R2) and return the file's address. The README requires Python 3.10 or older for miners and suggests a GPU with 4 GB or more of memory. In a 2026-02-12 post the team said it was adding ElevenLabs and Chatterbox as methods; neither appears in the public code.

Validators

Validators fetch voice-cloning tasks (a voice sample, a transcript and a time limit) from the team's own server, which requires an API key from the team's website, so the task source is closed. They query up to 50 responsive miners per task by default, download each result and compute an overall score: 30 percent text accuracy (speech recognition compared with the transcript), 30 percent voice similarity (speaker embedding, with spectral and pitch checks), 30 percent intonation and 10 percent audio quality.

Incentive

In the code, a miner whose overall score is below 0.7 is treated as having failed. Among sampled miners, the one with the shortest response time wins the round and gets a score of 1; everyone else gets 0. Round results feed a moving average (weight 0.1 on the newest round) and the averages become the validator's weights. The README lists stricter thresholds per metric (0.8 overall, for example) than the code enforces; the code is the source used here. Chain weights were not read.

Getting started

  1. Clone the repository (the README names a different GitHub organization than the one the team links in chat), create a Python 3.10 or older environment for miners, and install requirements.txt plus miner_additional_requirements.txt.
  2. Copy .env.example to .env and set a storage provider, endpoint, bucket and credentials for the result uploads.
  3. Register a hotkey on the testnet netuid the team uses for EchoIC, which was not stated in the channel, then run neurons/miner.py with your wallet and --voice_cloning.method xtts.
  4. Validators install ffmpeg and need an API key from the team's website; that site was unreachable on 2026-10-21, so check with the team before planning a validator.
