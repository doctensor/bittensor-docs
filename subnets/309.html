What it is

EchoIC is a voice-cloning subnet. A miner gets a short voice sample and a transcript, produces speech in that voice with a cloning model and returns an audio file; validators score text accuracy, voice similarity, intonation and sound quality. Everything found describes testnet use; the channel has been silent since February 2026 and the project looks dormant.

How it works

Miners

Miners run one of four cloning methods (XTTS by default, Bark, Tortoise or RVC), upload each result to their own storage bucket (Backblaze, Amazon S3 or Cloudflare R2) and return the file's address.

Validators

Validators fetch tasks (a voice sample, a transcript and a time limit) from the team's own server, so the task source is closed. Each task goes to up to 50 responsive miners. Results are scored 30 percent text accuracy (speech recognition against the transcript), 30 percent voice similarity, 30 percent intonation and 10 percent audio quality.

Incentive

In the code a miner scoring below 0.7 overall fails the round. Among passing miners the fastest response wins and scores 1; everyone else scores 0. A moving average (weight 0.1 on the newest round) turns the results into the validator's weights. On testnet no uid has incentive, so no round results reach the chain.

Roles and requirements

Miner Medium barrier

Runs a voice-cloning model on a GPU and returns each result as a file link in its own storage bucket.

  • Speed counts: the fastest passing miner wins the round (code).
  • The README calls a GPU 'recommended'; the repository's min_compute.yml marks it required for miners.
  • Nothing can be earned today: no uid has incentive on testnet 309 (chain, 2026-10-31).

Validator High barrier

Fetches voice tasks from the team's server, scores miners' audio and sets weights. Needs a team-issued API key.

  • Scoring uses a Whisper base speech model (GPU if found, else CPU) and a speaker-recognition model (code).
  • Tasks come only from the team's server; with no task the validator waits 60 seconds (code).

Getting started

  1. There is nothing to join today: no testnet uid earns and the one validator has set no weights for about 312 days. Ask in the project's channel whether anything runs first.
  2. Miners: use a GPU machine with Python 3.10 or older, clone echo-ic/echo-bittensor-subnet (the README's organization link is dead) and install requirements.txt plus miner_additional_requirements.txt.
  3. Copy .env.example to .env and set a storage provider, endpoint, bucket and keys. Run neurons/miner.py with your wallet, the netuid and --voice_cloning.method xtts.
  4. Validators: install ffmpeg and sign up on the team's site for an API key. The site did not answer on 2026-10-31, so a validator cannot start without the team.

Caveats

  • Testnet only: nothing here describes mainnet emissions or economics. Test-network pool and price figures are test tokens and are not given.
  • The team's site did not respond on 2026-10-21, 2026-10-26, 2026-10-27 or 2026-10-31. Validators depend on its task server, so the subnet may not be running.
  • The no-weights finding is an inference: the validator's last update age equals the slot's age. Individual weights were not read; block-to-date conversions are estimates.
  • Who runs the permit holder, and whether any miner runs, were not read. No incentive on any uid means only that nobody earned in the last epoch.
