What it is

Netuid 39 was Basilica, a GPU-rental project run by Covenant AI, which said in April 2026 it was leaving Bittensor. Cathedral, a community team, kept the slot running for four months and moved to SN94 in late September.

How it works

Miners

The former team's miner docs (undated) say to register on SN39, run a CPU server plus A100-class or better GPU nodes, and earn compute units plus rental revenue. On chain the miner share burns and one owner UID holds all incentive, so nothing shows anyone paid this way.

Validators

Thirteen hotkeys hold validator permits. Twelve set weights within the last tempo and put top weight on UID 136. UID 30 has not set weights since 2026-10-17 (24 days); it alone weights UID 68, an unstaked, unpermitted registration. Who runs them is not documented.

Incentive

One UID, 136, has all incentive. It uses the owner's keys, is an active validator, and got 59.9% of last-epoch emission (about 3,527 of 5,890 alpha, the subnet's token, per day; a floor). Split: 18% owner, 41% validators, 41% miners (chain default).
