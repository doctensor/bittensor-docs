What it is

Netuid 39 was Basilica, a GPU-rental project run by Covenant AI, which said in April 2026 it was leaving Bittensor. Cathedral, a community team, kept the slot running for four months and moved to SN94 in late September. The chain name now reads 'deprecated'.

How it works

Miners

The former team's miner docs (undated, still online) say to register on SN39, run a CPU miner server plus A100-class or better GPU nodes, and earn compute units (1 unit = 1 GPU-hour validated) plus rental revenue. On chain the miner share burns and one owner UID holds all incentive, so nothing shows anyone paid this way.

Validators

Twelve hotkeys hold validator permits (64 slots exist). Eleven set weights within the last tempo and put top weight on UID 136. UID 30 has not set weights since 2026-10-17 (20 days); it alone weights UID 68, an unstaked, unpermitted registration. Who runs them is not documented.

Incentive

One UID, 136, has all incentive. It uses the owner's keys, is an active validator, and got 58.5% of last-epoch emission (about 3,440 of 5,890 alpha, the subnet's token, per day; a floor). Split: 18% owner, 41% validators, 41% miners (chain default).

Caveats

  • The on-chain name reads 'deprecated' (set 2026-04-10 under the previous owner key); the owner's plans are unknown.
  • Basilica's miner docs are undated. Whether anyone runs its code on SN39 is not shown; the team's payout API was not read.
  • Chain weights are validator opinions, not payouts. The miner-side burn amount and the owner UID's take rate could not be read.
  • The chain dates the owner-key changes, not a price; the conviction mechanism and cost come from chat.
  • Stake shares cover about 76% of staked alpha; one holder can use many coldkeys.
  • Chat after 2026-11-01 was not readable (archive down).
