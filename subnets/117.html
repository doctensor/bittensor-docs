What it is

EveryFrame (SN117) serves EveryFrame Studio, an AI video and image studio that resells models such as Seedance, Veo and Kling. Miners run no models: they use their own provider keys in a team-approved worker inside an Intel TDX confidential VM on Phala Cloud. The team runs the coordinator and accounting. New team since 2026-09-21.

How it works

Miners

Register a hotkey, open Phala Cloud and provider accounts (fal, OpenRouter, Replicate, Google and others), then deploy the approved worker with everycli. Miners post a discount per model and the coordinator assigns jobs from those offers. The worker calls the provider, hashes the output and signs a receipt; an operator approves each job.

Validators

The owner side publishes a signed accounting report per 361-block window (about 72 minutes) and a signed assignment naming the report to score. Validators run the public Docker image, verify signatures and submit the weights; they do not check customer payment. A missing report makes them wait.

Incentive

Pool in dollars = alpha emitted x miner share (33%) x alpha price. A miner's weight is its approved work divided by the larger of the pool and total work; the rest goes to the owner uid and is recycled. Work has been 4% to 9% of the pool since 2026-10-24, so the owner uid holds 97% of incentive.

Roles and requirements

Miner Low barrier

Serves video, image and audio jobs with your own provider keys in an attested cloud worker.

  • Jobs need operator approval; the reward runner rejects recipients tied to the owner's coldkey.
  • The hosting ceiling is a rate cap, not a budget; earnings are not guaranteed (README).
  • Pay on 2026-10-30: the 3 uids outside the owner share about 0.18 TAO a day, before costs (chain).

Validator High barrier

Verifies the owner's signed accounting and submits the weights; needs a validator permit.

  • 10 of 64 slots are held; 8 have set weights (chain, 2026-10-30).
  • Weights come from the owner's signed report, so validators do not choose the input.

Getting started

  1. Check demand first: the dashboard and signed epoch feed show jobs and work (about $113 across 8 miners on 2026-10-30).
  2. Register a hotkey (0.05 TAO burn), open a Phala Cloud account and fund a provider account.
  3. Install everycli, run setup with an hourly ceiling, deploy, run doctor, then post a discount per model with offer.
  4. Validators: use the Docker image with a permit-holding hotkey and an archive RPC; never clear the state journals.

Caveats

  • Weights are validator opinions, not payouts. No public data shows the 2026-10-20 backlog (about $107) was ever paid.
  • The operator runs accounting and job approval; the coordinator is private, and the TEE shows which image ran, not that the provider did the work.
  • Studio home still says prelaunch; the subnet site says routing is live and shows 0 miners online, yet its dashboard lists 8 workers.
  • The cause of the 2026-10-30 price jump is unknown; 3 of 10 permit holders have not set weights for over 5 tempos.
