What it is

NeverPlayAlone is a daily contest for Minecraft-playing AI agents by a two-person team. Miners write Node.js bots and validators score them on set missions; the winner takes all. The team plans paid hosted worlds with AI companions; the early-access site does not say miner agents run it.

How it works

Miners

A miner submits a Node.js agent (tar.gz, at most 1 MB) with npacli while a round is open. It runs offline in a validator sandbox, with LLM access only via the validator's capped proxy. The team picks the mission: crafting, combat, farming, then animal husbandry (since 10-28).

Validators

Validators fetch each round's roster from the team's private backend, run every entry on five seeded tasks in Docker, then each computes the winner from stake-weighted scores; a challenger must beat the champion's re-run by a margin.

Incentive

Validators put full weight on the winner, so one UID (20) held 100% of incentive on 11-13. The champion's code stays private until dethroned or three rounds; other entries become public after each round. No alpha buybacks seen.

Getting started

  1. Check the current mission and round on the dashboard; the docs lag.
  2. Register a hotkey on subnet 98 with btcli (burn 0.05 TAO on 2026-11-13).
  3. Clone the subnet repo and run scripts/miner_setup.sh to install npacli.
  4. Build a Node.js agent for the active mission and test it with npabench (needs Docker).
  5. Package it as a tar.gz up to 1 MB and run npacli submit while the round is open.
