What it is

UMI pays miners for models that turn American Sign Language (ASL) video into English text. Team-run evaluators score each model on held-out clips; models near or above a public baseline share the miner pool by score band.

How it works

Miners

Miners submit an offline Python model bundle that turns video into English text, on CPU, with a permitted license. Only models are paid. A model qualifies within 1% of the reference model's score.

Validators

A team coordinator issues the test clips and two team-run evaluators score them. Permit holders re-derive the published rows and set weights: five hold permits and four set weights in the last epoch.

Incentive

Emission splits 30.75% owner, 15.5% validators, 53.75% miners. Scores fall into 2.5-point bands; each lower band or rank earns 0.85 times the one above. A model within 0.01 points of a better one counts once; unallocated share is burned.

Getting started

  1. Register a hotkey on subnet 78 (0.375 TAO burn on 2026-11-07).
  2. Read 'What miners should run now' in the repo; only models are paid.
  3. Install the model client (Python 3.10 to 3.14, FFmpeg, uv); rerun it for each cohort and client release.
  4. Download the reference model from the results API (the cohort 7 winner is the baseline); build an offline bundle: one entry point, declared training data, matching license.
  5. Sign and upload to the open cohort (9) before its cutoff; the first receipt says pending, so query admission.

Caveats

  • Evaluation is team-run (two evaluators, one coordinator); cohort 6 was re-scored once after a complaint.
  • Near-copies of a better model earn once they are over 0.01 points apart; miners say this pays copies of the baseline.
  • Unverified: buyback funding, paid translators, customers, revenue. Training hardware is not documented.
  • Team chat after 2026-11-01 was not read (archive down); cohort dates may have moved.
