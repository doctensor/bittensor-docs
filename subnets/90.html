What it is

KubeTEE calls itself a decentralized AI factory: miners run Kubernetes GPU clusters with hardware confidential computing (Intel TDX, NVIDIA).

How it works

Miners

Run a Rancher-managed RKE2 cluster of 8-GPU Blackwell-class nodes on Intel TDX CPUs. Early Access registration is by hand: the team labels the cluster with the miner's hotkey and deploys the stack. The validator has had no node-count gate since 2026-10-29; a 10 TAO per node deposit is announced, not enforced.

Validators

The validator reads the Rancher inventory and gives each cluster a ready or not-ready verdict, then sets weights once per epoch; since v1.3.4 a node counts only with a heartbeat under 15 minutes old. TEE attestation and job metrics are not in the weights yet.

Incentive

A ready cluster earns a USD price per GPU-hour times GPU count times a tenure factor, scaled down pro rata when claims exceed the epoch pool; unused weight goes to the owner UID and is recycled. Since 2026-10-29 the owner publishes per-GPU floors and two switches on a card validators read (2026-11-07: Targon clamp on, Lium off).

Getting started

  1. Read the README roadmap and docs/GPU-NODE-REQUIREMENTS.md; they separate what ships today from what is planned.
  2. Miner: Early Access is hand-reviewed. Contact the team in the subnet channel; self-service onboarding waits for Phase 1.
  3. Validator: get a validator permit, then run the ghcr.io/kubetee-ai/kubetee-validator image with a Taostats key and follow validator/README.md.
