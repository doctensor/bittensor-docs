What it is

KubeTEE calls itself a decentralized AI factory: miners run Kubernetes GPU clusters with hardware confidential computing (Intel TDX, NVIDIA).

How it works

Miners

Operate 8-GPU Blackwell-class nodes on Intel TDX CPUs. Onboarding is by hand: the miner installs plain Ubuntu, sets BIOS and GPU firmware, and gives KubeTEE SSH and power access; the team builds the Rancher-managed RKE2 cluster, labelled with the miner's hotkey.

Validators

The validator reads the Rancher inventory and gives each cluster a ready or not-ready verdict, then sets weights once per epoch; since v1.3.4 a node counts only with a heartbeat under 15 minutes old. TEE attestation and job metrics are not in the weights yet.

Incentive

A ready cluster earns a USD price per GPU-hour times GPU count times a tenure factor, scaled down pro rata when claims exceed the epoch pool; unused weight goes to the owner UID and is recycled. Since v1.4.0 each GPU class is priced once per epoch, 5% above the highest of three feeds (Targon, Lium, Chutes), never below the owner's floor.

Roles and requirements

Miner High barrier

Runs a confidential-computing GPU cluster; KubeTEE prepares the hosts over SSH and binds the cluster to the miner's hotkey.

  • New nodes: B200, B300, RTX PRO 6000 Blackwell or Vera Rubin; H100 and H200 are deprecated (removal targeted November 2026).
  • KubeTEE sets the kernel, CC mode, drivers and storage itself (draft docs). One cluster per hotkey.

Validator Medium barrier

Reads cluster inventory, checks readiness, prices the hardware and sets weights once per epoch.

  • Release v1.4.2 (2026-11-08); no Rancher account needed, inventory comes through the owner's proxy.
  • Nine permit holders set weights: five rank uid 56 first, four the owner uid 0 (63-64%). Only uids 0 and 1 hold much SN90 alpha.

Getting started

  1. Read the README roadmap and docs/GPU-NODE-REQUIREMENTS.md; they separate what ships today from what is planned.
  2. Miner: Early Access is hand-reviewed; ask the team in the subnet channel. docs/MINER-ONBOARDING.md (draft) lists the SSH handoff.
  3. Validator: get a validator permit, then run the ghcr.io/kubetee-ai/kubetee-validator image with a Taostats key and follow validator/README.md.
