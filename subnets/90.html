What it is

KubeTEE calls itself a decentralized AI factory: miners run Kubernetes clusters of GPUs with hardware confidential computing (Intel TDX, NVIDIA confidential-computing GPUs). Today the validator checks that a cluster is ready and pays by hardware, not by work served.

How it works

Miners

Run a Rancher-managed RKE2 cluster of 8-GPU nodes on Intel TDX CPUs. Early Access registration is by hand: the team labels the cluster with the miner's hotkey and deploys the stack. New nodes must be Blackwell-class. Since 2026-10-29 the validator has no node-count gate. A 10 TAO per node deposit is announced and not enforced.

Validators

The validator reads the Rancher inventory and gives each cluster a ready or not-ready verdict (hotkey label, node roles, 72 cores and 1 TiB memory per node, an 8-GPU worker), then sets weights once per epoch. TEE attestation and job metrics are not in the weights yet.

Incentive

A ready cluster earns a USD price per GPU-hour times GPU count times a tenure factor, scaled down pro rata when claims exceed the epoch pool; unused weight goes to the owner UID and is recycled. Since 2026-10-29 the owner publishes per-GPU price floors and two on/off switches on a price card that validators read.

Roles and requirements

Miner High barrier

Runs a confidential-computing GPU Kubernetes cluster that the team binds to the miner's hotkey.

  • Per node (docs): 8 GPUs of one type, all nodes in one data centre on one fast network.
  • New nodes: B200, B300, RTX PRO 6000 Blackwell or Vera Rubin; H100 and H200 are deprecated (removal targeted November 2026).
  • Docs ask for 3 nodes of one GPU type; the validator enforces no node count since 2026-10-29. One cluster per hotkey.

Validator Medium barrier

Reads cluster inventory, checks readiness, prices the hardware and sets weights once per epoch.

  • Image ghcr.io/kubetee-ai/kubetee-validator (latest v1.3.3, 2026-10-29); no Rancher account needed, inventory comes through the owner's proxy.
  • All 9 permit holders set weights and all rank UID 56 first (2026-10-30).
  • A v1.3.2 or older reader ignores the price card's switches, so mixed versions could diverge.

Getting started

  1. Read the README roadmap, docs/GPU-NODE-REQUIREMENTS.md and docs/NODE-REGISTRATION.md; they separate what ships today from what is planned.
  2. Miner: Early Access is hand-reviewed. Contact the team in the subnet channel; self-service onboarding waits for Phase 1.
  3. Plan 8-GPU Blackwell nodes (Intel TDX Xeon, 72+ cores, 1 TiB+ memory) in one data centre.
  4. Validator: get a validator permit, then run the ghcr.io/kubetee-ai/kubetee-validator image with a Taostats key and follow validator/README.md.

Caveats

  • Throughput, revenue and dollar rates on the dashboards are the team's own and are not repeated here.
  • Only 3 of 45 recycler fills were checked on chain.
  • Chain figures are one read on 2026-10-30. Weights are validator opinions, not payouts.
  • The README describes a split company structure in which the owner-side operator of the staging cluster (UID 56) competes under the same rules.
