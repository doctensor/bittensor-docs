What it is

Minos pays miners for tuning the settings of open DNA variant-calling tools (GATK, DeepVariant, bcftools) to find the most real mutations with the fewest false ones. Every 72 minutes the platform issues a fresh synthetic genome; validators score submitted configs on it against the hidden answers.

How it works

Miners

Each round a miner downloads the new alignment file, runs one of the three tools and submits its config, after committing a hash of it on chain. Every value must stay inside the published ranges.

Validators

Validators get tasks and truth data from the team's platform, re-run configs in Docker and score them with hap.py. Each scores a primary range of miners by stake rank, pulls peers' scores for the rest and sets weights. The team sets scoring version and reward shares through a public config and releases truth files after each round.

Incentive

The round's top miner gets 80% of weight; ranks 2 to 20 share the other 20%, each 0.9 times the one above; nothing is burned. Only one hotkey per coldkey is paid and a miner needs scores in 5 of the last 20 rounds. Scoring is 70% core accuracy, 30% germline.

Roles and requirements

Miner Low barrier

Runs a variant caller with tuned settings on each round's genome and submits the config.

  • Repo minimum: 4 cores at 2.5 GHz, 8 GB RAM (16 GB for DeepVariant), x86_64, Docker 24+; about 7 GB of images. A GPU only speeds up DeepVariant.
  • Miners say winning configs need heavy per-round search; no cost is documented.

Validator High barrier

Re-runs miner configs, scores them with hap.py and sets weights; the platform assigns who scores whom.

  • Repo minimum: 8 cores at 2.5 GHz, 32 GB RAM, 100 GB SSD; no whitelist documented.
  • PR 41 (merged 2026-11-06) adds an opt-in ComputeHorde SDK runner; containers still run locally for now, and 1 CPU, 4 GB is the stated goal.

Getting started

  1. Clone minos_subnet, run bash install.sh and read the README (newer than the docs site).
  2. Run bash start-miner.sh --demo (no wallet) for the exact validator score on a sample, then --practice.
  3. Read the live config and parameter-ranges endpoints before tuning; keep every value in range.
  4. Register a hotkey on subnet 107 and run bash start-miner.sh; expect several rounds before pay.
  5. Validators: bash start-validator.sh, with a validator permit and the server specs above.

Caveats

  • The team's platform sets rewards, tasks, truth data and validator assignments. Hashes, a public task selector and post-round truth files let miners check parts; validator logs stay private.
  • Copying, multi-UID and self-mining accusations (2026-10-16 to 10-30) stay unresolved. Winner uid 3 shares a coldkey with uid 69 (last week 73 and 42 each shared one); alone this proves nothing.
  • IM2, custom algorithms, the app's release and commercial pilots are chat statements only; no public IM2 code, date or revenue was found.
