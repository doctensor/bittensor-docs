What it is

SN121 is run by Sundae Bar AI PLC, which sells AI agents to businesses. Each Challenge is a business task: miners write a skill file, a base agent applies it to test scenarios, and LLM judges score the answers. The leader earns, and its skill may join the platform.

How it works

Miners

Register a hotkey, create a sundae_bar account and link that hotkey. While a Challenge is open, upload a skill bundle: a SKILL.md (10,000 bytes at most) plus optional text reference files.

Validators

The team's validator sends each skill to its evaluator. A fixed base agent answers every scenario with the skill loaded, and graders score the answers (SBC33: quality 30%, skill use 30%, scenario quality 30%, originality 10%).

Incentive

Whoever is first earns. The validator puts a fixed share of weight on the leader (40% live, 20% default) and the rest on UID 0, the owner hotkey. A challenger must beat the leader's best score by 0.01.

Roles and requirements

Miner Low barrier

Write a skill (SKILL.md plus reference files) for the live Challenge and upload it on the Lab.

  • SKILL.md up to 10,000 bytes; up to 30 reference files, 128,000 characters in total.
  • SBC33: 10 agent steps and 29,000 tokens per scenario; 3 submissions a day (README: 5 per hotkey per Challenge).
  • An entry must be under 93% similar to others' and 97% to your own; text aimed at the judges scores zero.

Validator Medium barrier

Poll the team's coordinator for scoring tasks, run the evaluator and set weights.

  • Chutes and OpenRouter keys cover most Challenges; OpenAI, Anthropic, Google and Together also work.
  • The validator sets weights itself: EMISSIONS_PERCENT (default 20%) to the leader, rest to UID 0; the team runs 40%.
  • The coordinator is team-run; whether it accepts any permit holder is not documented.

Challenge cycle

  • Now: SBC33, Regulatory Compliance Triage Skill: the agent reads a regulation and a company profile and returns a verdict table and one label.
  • Close: after a score clears the 80% bar and a review agrees, a closing window of a few hours starts.

Getting started

  1. Read the README and check the Lab for the live Challenge.
  2. Register a hotkey on subnet 121, create a sundae_bar account and link the hotkey by signing the message the form shows.
  3. Download the Challenge's suite files (suite.yaml, dataset, rubric), write a short SKILL.md that teaches a procedure, and upload it on the Lab form.
  4. Read the results for grader notes and improve until you beat the leader by 0.01. To validate, get a permit and run docker compose up -d from the validator repo.

Caveats

  • Payment needs an open Challenge: none was paid for about 5.7 days after SBC32, and the team says gaps now follow when scores reach production grade.
  • The leader's share is a team setting (40% live, 20% default) and can change at any time.
  • Chat disputes (self-mining, similarity-check complaints, an integrity-grader report, a local re-score gap) are unverified; the team denies self-mining.
  • Usage and revenue are team statements, not seen on chain or in code. Whether the 7 other permit holders are child keys or copies was not shown.
