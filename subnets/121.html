What it is

SN121 is run by Sundae Bar AI PLC, which sells AI agents to businesses. Each Challenge is a business task: miners write a skill file, a base agent applies it to test scenarios and LLM judges score the answers. The leader earns; its skill may join the platform.

How it works

Miners

Register a hotkey, create a sundae_bar account and link that hotkey. While a Challenge is open, upload a skill bundle: a SKILL.md (10,000 bytes at most) plus optional text reference files.

Validators

The team's validator sends each skill to its evaluator. A fixed base agent answers every scenario with the skill loaded, and graders score the answers (SBC35 to SBC37: quality 30%, skill use 30%, scenario quality 30%, originality 10%) against a reference set sealed until the Challenge closes (hash public; SBC35's set matched).

Incentive

Whoever is first earns. The validator puts a fixed share of weight on the leader (40% live, 20% default) and the rest on UID 0, the owner hotkey. A challenger must beat the leader's best score by 0.01.

Roles and requirements

Miner Low barrier

Write a skill (SKILL.md plus reference files) and upload it on the Lab while a Challenge is open (SBC37 is, until 2026-11-14 17:00 UTC).

  • SKILL.md up to 10,000 bytes; up to 30 reference files, 128,000 characters in total.
  • SBC35 to SBC37: 10 agent steps and 30,000 tokens per scenario; 7 submissions a day (SBC34: 3; README: 5 per hotkey).
  • An entry must be under 93% similar to others' and 97% to your own; text aimed at the judges scores zero.

Validator Medium barrier

Poll the team's coordinator for scoring tasks, run the evaluator and set weights.

  • Chutes and OpenRouter keys cover most Challenges; other providers also work.
  • The validator sets weights itself: EMISSIONS_PERCENT (default 20%) to the leader, rest to UID 0; the team runs 40%.
  • The coordinator is team-run; whether it accepts any permit holder is not documented.

Getting started

  1. Read the README, then check the Lab: SBC37 is live until 2026-11-14 17:00 UTC; SBC38's brief goes live 2026-11-16 14:00 UTC.
  2. Register a hotkey on subnet 121, create a sundae_bar account and link the hotkey by signing the message the form shows.
  3. Download the Challenge's suite files (suite.yaml, dataset, rubric), write a short SKILL.md that teaches a procedure, and upload it on the Lab form.
  4. Beat the leader by 0.01. To validate, get a permit and run the validator repo's docker compose stack.

Caveats

  • Pay needs an open Challenge: gaps so far ran 21 hours to 5.7 days.
  • The leader's share is a team setting and can change at any time.
  • Chat disputes (self-mining, similarity checks) are unverified; the team denies self-mining.
  • Usage and revenue are team statements, not seen on chain or in code; who runs the leader uids (78, then 30, whose coldkey holds 18 others) and the permit holders' child keys are unknown.
  • Chat after 2026-10-31 was unreadable, so team notes on SBC35 to SBC37 are not seen.
