What it is

Teutonic is a competition to train one shared language model, Teutonic-II-110B-A7B. Miners submit full checkpoints; a challenger that cuts the king's loss gap to a pinned reference model (Horizon) by a set margin is crowned and earns emission.

How it works

Miners

Miners submit a full checkpoint with the repo's miner tool. Each hotkey gets one irreversible submission, shared across all competitions; the miner picks MAIN, MIX01, MIX06 or MIX07.

Validators

The team's validator verifies each checkpoint against its on-chain commitment; a remote GPU evaluator then scores whole documents (35M tokens) for the challenger, the king and a pinned reference model, Horizon. A challenger wins if the lower bound of its cut in the king's deficit against Horizon exceeds the margin (0.00075 bits per byte).

Incentive

Rewards are paid in alpha: 40% of miner rewards to the MAIN king, 20% to each of the MIX01, MIX06 and MIX07 kings. The chain paid exactly this split on 2026-11-13.

Roles and requirements

Miner High barrier

Trains and submits a full checkpoint of the shared model.

  • The model is about 220 GB in bf16; a checkpoint must support 16,384 positions.
  • Training data and the kings' models are public; upload credentials are free.
  • A new attempt needs a new hotkey (1 TAO).

Validator High barrier

Checks submissions and sets weights; in practice the team runs it.

  • Evaluation, queue order and crowning run in the team's services; no outside-validator guide exists.
  • On 2026-11-13 all three permit holders send the same four-king row: uid 242 40%, uids 176, 9 and 37 20% each.

Getting started

  1. Check hardware: a 220 GB model needs an 8x H200/B200-class node.
  2. Clone the repo, make a Python 3.11+ environment, install the miner extras and create an Ed25519 hotkey with btcli.
  3. Run the register command (it can spend TAO; check-only mode never pays).
  4. Pick a competition from the competitions JSON, train on the public datasets, then upload and mark ready. One submission per hotkey, irreversible.

Caveats

  • Rules move fast (rebuilt 2026-10-21; MIX07 on 11-04; Horizon duels and four competitions on 11-12); the guide lags the repo. Trust the dashboard and competitions JSON.
  • Pay starts about 6 hours after a crowning (commit-reveal); uid 37, crowned 14.3 h before the read, is paid.
  • The owner key pair changed around 2026-08-14 to 08-15; who holds it now is not verifiable. Per chat, the Dendrite team (also SN97) operates it.
  • Chat after 2026-10-29 was not read (archive down).
