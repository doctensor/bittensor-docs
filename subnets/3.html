What it is

Teutonic is a competition to train one shared language model, Teutonic-II-110B-A7B. Miners submit full checkpoints; a challenger that cuts the king's loss gap to a pinned reference model (Horizon) by a set margin is crowned and earns emission.

How it works

Miners

Miners submit a full checkpoint with the repo's miner tool. Each hotkey gets one irreversible submission, shared across all competitions; the miner picks MAIN2, MIX07, MIX08 or MIX09.

Validators

The team's validator verifies each checkpoint against its on-chain commitment; a remote GPU evaluator then scores whole documents for the challenger, the king and a pinned reference model, Horizon. A challenger wins if the lower bound of its cut in the king's deficit against Horizon exceeds the margin (0.0005 bits per byte).

Incentive

Rewards are paid in alpha: 40% of miner rewards to MAIN2, 20% each to MIX07, MIX08 and MIX09, hours after a crowning.

Roles and requirements

Miner High barrier

Trains and submits a full checkpoint of the shared model.

  • The model is about 220 GB in bf16; a checkpoint must support 16,384 positions.
  • Training data is public (packed-text manifest, plus RefineCode for code); kings' models are public; upload credentials are free.

Validator High barrier

Checks submissions and sets weights; in practice the team runs it.

  • Evaluation, queue order and crowning run in the team's services; no outside-validator guide exists.
  • Four uids hold permits, three set weights: all give uid 252 40% and uid 20 20%; uid 204 adds uids 202, 47, uids 217 and 244 uids 247, 32 (20% each). Uid 252 (MAIN2 king) gained a permit on 11-22 with 1,146 alpha and has set no weights.

Getting started

  1. Check hardware: a 220 GB model needs an 8x H200/B200-class node.
  2. Clone the repo, make a Python 3.11+ environment, install the miner extras and create an Ed25519 hotkey with btcli.
  3. Run the register command (it can spend TAO; check-only mode never pays).
  4. Pick one of MAIN2, MIX07, MIX08 or MIX09 from the competitions JSON, train on the public datasets, then upload and mark ready.

Caveats

  • Rules move fast (MAIN2, MIX08, MIX09 on 11-19; margin 0.0005 on 11-16); the guide and README lag the repo. Trust the dashboard.
  • Pay trails a crowning by hours (commit-reveal): uids 202 and 47 (crowned 11-22 14:29Z, 15:53Z) are paid at 22:14Z; uid 32 (12:44Z) and kings 149, 113 (18:03Z, 19:27Z) are not.
  • The owner key pair changed around 2026-08-14 to 08-15 and its coldkey on 11-18; the holder is not verifiable. Per chat, the Dendrite team (also SN97) operates it.
  • Chat after 2026-10-29 was not read (archive down).
