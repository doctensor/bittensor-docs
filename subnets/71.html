What it is

Leadpoet (SN71) runs a daily contest in which miners improve a public sales-research agent that returns up to five companies, with evidence, for a buyer request. A winner that beats the baseline by 8+ points becomes the new baseline and earns miner rewards. The team sells a sales product; its website never mentions Bittensor.

How it works

Miners

A miner forks the public baseline agent and edits it; it takes a buyer request and returns at most five companies with evidence. The code keeps the AGPL-3.0 licence, runs in a sandbox and passes an AI code review. Models need an approved zero-data-retention route that returns full reasoning text.

Validators

The team's gateway assigns scoring work and signs the weights. Validators with a permit and 75,000+ effective stake run each agent on 10 hidden requests; smaller ones only fetch the signed weights. On chain (2026-10-31) all 8 permit holders put most weight on the owner uid.

Incentive

Each day the best eligible agent is re-scored against the baseline (the last champion). It is crowned only if it wins by 8+ points (0-100 scale), and its code becomes the next baseline. It also needs usable reasoning records for 80%+ of requests. Slots pay by margin (table below); unclaimed shares go to the owner uid, a burn target.

Getting started

  1. Clone leadpoet/leadpoet (Python 3.11) and register a hotkey on subnet 71 (burn about 0.0005 TAO).
  2. Fork the baseline agent (lab branch of leadpoet-sales-agent); keep its AGPL-3.0 licence beside harness.py.
  3. Edit run_icp to return at most five companies in the round's schema.
  4. Choose OpenRouter models from the approved list: zero-data-retention route, full reasoning text.
  5. Submit with scripts/lab_arena_miner.py (interactive) and your API keys before 00:00 UTC.

Caveats

  • Reward rules changed on 10-08, 10-21, 10-23 and 10-24, with a one-off exception on 10-29; expect more.
  • The team runs the gateway and says it competes with its own hotkey; no entry checked (10-18 to 10-22) was on the owner's coldkey.
  • Validators copy the team's signed weights: chain weights show configuration, not independent judgment.
  • Claims that operators enter many hotkeys a day are unverified. No revenue, customer or buyback figure is public.
