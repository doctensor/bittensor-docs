What it is

Leadpoet (SN71) runs a daily contest in which miners improve a public sales-research agent that returns up to five companies, with evidence, for a buyer request. A winner that beats the baseline by 5+ points becomes the new baseline and earns miner rewards. The team sells a sales product; its website never mentions Bittensor.

How it works

Miners

A miner forks the public baseline agent and edits it. The code keeps the AGPL-3.0 licence, runs in a sandbox and passes an AI code review.

Validators

The team's gateway assigns scoring work and signs the weights. Validators with a permit and 75,000+ effective stake run each agent on 10 hidden requests; smaller ones only fetch the signed weights.

Incentive

Each day the best eligible agent is re-scored against the baseline. It is crowned only if it wins by 5+ points (8 before round 11-11), and its code becomes the next baseline. It also needs usable reasoning records for 80%+ of requests. Slots pay by margin; unclaimed shares go to the owner uid, a burn target.

Reward rules

Slots are cumulative; a win under +5 earns the title but no reward. New winners take every tier cleared (+5 = 15%, +10 = 40%, +15 = 75% in total); the 11-03 winner keeps 20 / 15 / 15% until replaced. Each slot halves every 140 epochs, no floor; first halving 11-11.

Getting started

  1. Clone leadpoet/leadpoet (Python 3.11) and register a hotkey on subnet 71 (burn about 0.0005 TAO).
  2. Fork the baseline agent (lab branch of leadpoet-sales-agent); keep its AGPL-3.0 licence beside harness.py.
  3. Edit run_icp to return at most five companies in the round's schema.
  4. Choose OpenRouter models from the approved list: zero-data-retention route, full reasoning text.
  5. Submit with scripts/lab_arena_miner.py (interactive) and your API keys before 00:00 UTC.

Caveats

  • Rules change often: rewards 10-08 to 10-24, cutoff 11-06, scoring code 11-07, re-score path 11-09, margin and slots 11-10, slot fix 11-11.
  • The team runs the gateway and says it competes with its own hotkey; no entry checked (10-18 to 10-22) was on the owner's coldkey.
  • Validators copy the team's signed weights: chain weights show configuration, not independent judgment.
  • The team runs scoring and review and has paused, retried and re-scored rounds (11-01 to 11-10).
  • Claims that operators enter many hotkeys a day are unverified. No revenue, customer or buyback figure is public.
