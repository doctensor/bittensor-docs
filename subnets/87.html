What it is

Subnet 87 (Provenonce, with Bitstarter.ai) is built around Proof of Assurance: checking how autonomous (AI agent) work was done against a declared contract. A miner gets a case with permitted evidence and returns one verdict; validators hold hidden cases and score it. Public runs are on testnet with team-run miners; outside miners can only apply to an unweighted shadow cohort.

How it works

Miners

Each case is an approval check (was an approval carried past a changed condition?) or a release-workflow check (does a release trace break its grammar?). The miner returns findings, no material deviation, or an abstention.

Validators

Validators issue hidden cases and score each reply: detection 0.60, evidence 0.25, calibration 0.15; an integrity failure scores zero. Truth comes from private executors, so the public verifier reports scoring as UNVERIFIED.

Incentive

Per method, weight = (score minus 0.60, floored at 0) squared, normalised. The public repo only dry-runs this; the program that sets weights is private. Mainnet split is 0/0/18/41/41% (burn/recycle/owner/validator/miner); the miner share is burned.

  • Guide: docs/guides/miner-guide.md. Native Windows is unsupported.
  • The signed endpoint needs a Valkey-compatible store (noeviction) and a registered testnet 582 hotkey.
  • The guide publishes no hardware or timing figure.
  • On 2026-10-30 the shadow allowlist is empty; applications from 2026-10-09 and 2026-10-26 have no reply.

  • Mainnet 87: 12 permit holders, all weight uid 0; 4 had not set weights for over 5 tempos.
  • Testnet 582: one permit holder (the team's), still setting weights on 2026-10-30.

Getting started

  1. Use Linux, macOS or WSL2. Install git, curl and uv.
  2. Clone provenonce-ai/sn87-provenonce-public; read the README and docs/guides/miner-guide.md.
  3. Run the public verifier (no wallet). Expect UNVERIFIED; not re-run for this page.
  4. Run the sn87-miner launcher locally first; the team asks where it breaks.
  5. Shadow cohort (testnet 582): register a hotkey, serve the signed endpoint behind TLS, announce it, open the application issue.
  6. No mainnet miner path is documented. Questions go to the team Telegram group.

Caveats

  • No miner earns on mainnet 87: all 12 permit holders weight owner uid 0 and the miner share is burned (2026-10-30).
  • Testnet weights go to two team-run uids; a matched baseline tied the references and the repo keeps that result.
  • Scoring truth is private, so scoring stays UNVERIFIED by design. This page did not re-run the verifier.
  • The whitepaper (v0.7.2) calls its economics uncalibrated hypotheses; only the HTML was read. Who runs the mainnet validators was not read.
