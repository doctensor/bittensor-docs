What it is

Subnet 87 (Provenonce, with Bitstarter.ai) is built around Proof of Assurance: checking how autonomous (AI agent) work was done against a declared contract. A miner gets a case with permitted evidence and returns one verdict; validators hold hidden cases and score it. Public runs are on testnet with team-run miners; outside miners can join an unweighted shadow service there, and none has.

How it works

Miners

Each case is an approval check (was an approval carried past a changed condition?) or a release-workflow check (does a release trace break its grammar?). The miner returns findings, no material deviation, or an abstention.

Validators

Validators issue hidden cases and score each reply: detection 0.60, evidence 0.25, calibration 0.15; an integrity failure scores zero. Truth comes from private executors, so the public verifier reports scoring as UNVERIFIED.

Incentive

Per method, weight = (score minus 0.60, floored at 0) squared, normalised. The public repo only dry-runs this; the program that sets weights is private. Mainnet split is 0/0/18/49/33% (burn/recycle/owner/validator/miner) since 11-14 (was 41/41); the miner share is burned.

Getting started

  1. Use Linux, macOS or WSL2. Install git, curl and uv.
  2. Clone provenonce-ai/sn87-provenonce-public; read docs/MINERS.md and docs/guides/miner-guide.md.
  3. Run the public verifier (no wallet); expect UNVERIFIED.
  4. Run the sn87-miner launcher locally first; the team asks where it breaks.
  5. Shadow service (testnet 582): register a hotkey, serve the endpoint behind TLS, add the published signer with --trusted-sender, announce it, open the application issue.
  6. No mainnet miner path is documented. Questions go to the team Telegram group.
