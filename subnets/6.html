What it is

Numinous scores forecasting agents rather than individual predictions. Miners upload a Python agent that, every interval, re-forecasts each live prediction-market event inside a validator sandbox with a limited set of tools and data. The team says the aim is better and better forecasters that it uses in its own product and forecasting API.

How it works

Miners

Write an agent that returns a probability (and a short reasoning text) for each live event, carrying a small memory blob between runs. Upload it with the numi CLI. The sandbox allows OpenAI, OpenRouter, Lightning Rod and the team's Numinous Signals (news feed, corpus search, causal drivers) plus free Indicia OSINT signals. Execution must finish within 240 seconds and the code must be under 2 MB. Hardcoding market prices into the agent is rejected.

Validators

Validators run each agent in a Docker sandbox behind a signing proxy. Scoring happens in the team's backend, not in validator code: validators fetch finished weights from the team API and set them on chain. Per the repo docs, each forecast is scored against the market's own price: the squared error of the agent's probability minus the squared error of the market price, measured against the price seven days later or the resolved outcome. Lower is better and matching the market scores zero.

Incentive

Repo docs (last updated 2026-09-22) describe one active pool: the re-forecasting pool. A miner must cover at least 85% of event intervals over 14 days, new miners carry a confidence penalty for roughly two weeks, and roughly the top 20 are paid in proportion to the squared margin over the 21st-best. In chat on 2026-09-30 the team said a second pool now exists: emissions are 90% this pool and 10% a reasoning-quality pool that goes almost entirely to the top five miners. The team also said the new Forecasting the Graph competition will get at least half of emissions and run alongside the current one.

Getting started

  1. Read the miner setup guide in the repo and install the numi CLI.
  2. Register a hotkey on subnet 6 (chat on 2026-09-14 quoted about 0.2 TAO; the repo says cost varies).
  3. Create a Numinous Signals key at eversight.numinouslabs.io and an inference key (OpenRouter is fine), then link them with numi.
  4. Test the agent locally against the example agents, then upload it with numi upload-agent. Check the current upload rules in chat first.

Caveats

  • Upload rules conflict: repo docs say one upload every 3 days, chat in September mentioned a 60-day cooldown, and on 2026-10-09 the team said one agent per hotkey for life. The repo was last updated 2026-09-22.
  • Repo docs list the reasoning pool as inactive; chat from 2026-09-30 says it is live at 10%. Docs lag chat.
  • Weights are computed by the team backend and were not checked against chain data.
  • On 2026-09-16 the team said its own agents run on the subnet and sit in the top 20, to keep its API quality high.
  • No revenue or buyback amounts were found; Forecasting the Graph scoring details were not published when this page was researched.
