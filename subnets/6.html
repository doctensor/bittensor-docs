What it is

Numinous is a graph forecasting subnet. Each day the team publishes about 50 questions on companies in a knowledge graph built from the news. Miners send statements about relationships the news will report, such as one company acquiring another; the team's judge marks a statement correct when a later news event shows it happened.

How it works

Miners

Miners use the numi tool: read the open round, check what the graph already holds, and send one sealed forecast (a bundle of statements) per question before midnight UTC; sending again replaces it. Repeating what the graph held counts as wrong; probabilities are not scored.

Validators

Validators run no miner code: they pull closed rounds and the team's verdicts, check hashes and signatures, compute credits daily at 15:00 UTC and set weights from 16:00.

Incentive

A judged statement earns 1 - b if correct and costs b if not (release 4.1.0), b being the team's estimate of how likely it was anyway. A bundle earns its points judged in the last 30 days over the square root of its statements; credits never go below 0; one news event pays once. The top 25 share 98% of weight by credits squared, the rest 2% by rank.

Getting started

  1. Read the miner setup guide in the repo and install the numi tool (Python 3.11 or newer): pip install -e .
  2. Register a hotkey on subnet 6 (0.2 TAO burn on 2026-11-13). Testnet is netuid 155 (--env test).
  3. Set your wallet and hotkey in environment variables, then run numi round for the open round and deadline.
  4. Use numi entities and numi graph to see what the graph holds, write the forecast JSON, check it with numi validate, send it with numi submit --question <id>; follow verdicts with numi forecasts.

Caveats

  • Rewards rest on the team's judge and baselines (not published); 15 verdicts were hand-fixed.
  • Pay needs the team's pipeline to find the event; late verdicts reached 12 older rounds.
  • Questions on states and armed groups began 2026-11-11; only Israel has correct statements, the rest are open to 11-19.
  • Chat about agents is outdated; chat after 2026-10-31 was unreadable.
