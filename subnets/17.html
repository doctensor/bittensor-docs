What it is

404-GEN is a competition subnet run by the 404 team. A miner's Python program sends a picture to OpenAI models through a team-run recording service and gets back Three.js code for the object. Each round's best program wins all miner rewards.

How it works

Miners

Each round a miner fixes a public repo and commit on chain. Once prompts and a seed are published, the program runs on 128 images through the team's recording witness pod and saves one Three.js module per image within 24 hours.

Validators

The team's judge duels renders with a vision-language model (four angles, then a feature checklist; ties are draws), in submission order: an entry must beat the leader by 7% to qualify, then the current holder by 7% to take over; the last holder wins. Each entry that takes the lead needs a replay of its recorded calls (now run by a team worker) and a source audit; a failed check drops it and the chain is rebuilt.

Incentive

The leader gets all miner weight until beaten. Split: owner 18%, validators 41%, miners 41%, nothing burned.

Roles and requirements

Miner Medium barrier

Writes a public Python program that turns each prompt image into one Three.js module.

  • Each round has 128 images; output is one self-contained Three.js module per image (no imports, assets or randomness).
  • Repos must stay public through audits and after a win (team rule, 2026-10-26).
  • The team can add allowed models during a round (guide, 2026-11-13).
  • Each final-save render has a 150 s deadline (preview 30 s); use witness client 0.2.19 or later (the guide pins 0.3.0); 0.2.17 stops reading at 150 s (output spec, 2026-11-13).

Validator High barrier

Runs a weights-setter that copies the team's published leader onto the chain; the team runs the judging.

  • The repo does not say outsiders can run the judge, replay or audit steps.

Getting started

  1. Follow the miner guide's quickstart: install the SDK wheels, start from the team's base-miner repo.
  2. Register a hotkey on subnet 17 and lock 100 alpha for it from your coldkey.
  3. Add your OpenAI key (or a Codex login); fix your repo and commit on chain before prompts appear.
  4. Take the prompts and seed from the state repo and generate within 24 hours.
  5. Validators: run the weights-setter from the subnet repo.
