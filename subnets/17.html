What it is

404-GEN is a competition subnet run by the 404 team. A miner writes a Python program that sends a picture to OpenAI models through a team-run recording service and gets back Three.js code that builds the object. Every three days the best program wins all miner rewards. This phase replaced the open-source one on 2026-10-28.

How it works

Miners

Each round a miner fixes a public repo and commit on chain. Once prompts and a seed are published, the program runs on 128 images through the witness, a team-run pod that records every OpenAI call, and saves one Three.js module per image within 24 hours.

Validators

The team's judge compares renders of two miners' outputs with a vision-language model. A challenger must beat the sitting leader by 7%, then pass a replay of its recorded calls and a source audit. Permit holders run a weights-setter that copies the published winner onto the chain.

Incentive

Winner stays in: the leader gets all miner weight until beaten. The split is owner 18%, validators 41%, miners 41%, nothing burned. Since 2026-10-28 the seat is held by the hotkey that won the last Three.js round, with its entry replaced by the team's base-miner code; the chain does not link it to the owner.

Roles and requirements

Miner Medium barrier

Writes a public Python program that turns each prompt image into one Three.js module.

  • Each round has 128 images; output is one self-contained Three.js module per image, with no imports, assets or randomness.
  • The nominal cap allows up to $640 per round (128 x $5); the team says the whole budget cannot be used.
  • Repos must stay public during the build, audits and after a win, or the entry is disqualified (team rule, 2026-10-26).

Validator High barrier

Runs a weights-setter that copies the team's published leader onto the chain; the team runs the judging.

  • The repo does not say outsiders can run the judge, replay or audit steps.
  • On chain, 14 hotkeys hold permits and 10 set weights, all with the same top uid (2026-10-30).

Getting started

  1. Read the launch quickstart in the miner guide on the witness branch.
  2. Register a hotkey on subnet 17 and lock 100 alpha from your coldkey for it.
  3. Build the witness and renderer clients and start from the team's base-miner repo.
  4. Add your OpenAI key (or a Codex login with a ChatGPT plan) and fix your repo and full commit on chain before the prompts are published.
  5. Take the prompts and seed from the state repo, run through the witness pod and save each result within 24 hours.
  6. Validators: run the weights-setter from the subnet repo.

Caveats

  • The competition is days old; clients and rules changed almost daily from 2026-10-26 to 2026-10-28.
  • The live system runs from an unmerged branch; main still describes the old phase.
  • Round 0 was undecided on 2026-10-30, so the seat, and the pay that goes with it, may change.
  • Weights are validator opinions, not payouts. The witness server was read as documentation only.
