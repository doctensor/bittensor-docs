What it is

Yanez pays miners for synthetic identity data: face variations, fake screen replays and cloned voices. The team says it helped build its Passive Liveness v3 check; it also offers an ID app and agent approvals.

How it works

Miners

Miners run the repository's miner on a GPU. For each seed face they return six synthetic variations (one a screen replay) and, since 2026-10-19, cloned voice clips (five styles in the 11-24 code).

Validators

Validators send challenges, pass submissions to the team's grading service and set weights. Eight hold permits; the partner hotkey sets no weights and the other seven all rank it first.

Incentive

Stored emission split: 18% owner, 49% validators, 33% miners. By code the miner side is 50% partner hotkey (UID 14), 45% manual-review reputation, 5% live grading; unused reputation share goes to the partner.

How scoring works

  • Docs of 11-24: each of five faces, a screen replay and five voice clips scores 0 to 5; a face or replay earns 5 only if it breaks the detector, 3 if not.
  • Docs: faces 50% of the reviewed score, screen replay 25%, voice 25%, but Sandbox collects no review score and pays live grading only (one random face slot a round, new /grade_v3 rubric); an empty reputation cache sends the 45% reputation share to the partner.

  • Face dashboard (before similarity penalties): 379 of 430 hotkeys positive, behind 72 coldkeys (largest 30); the miner feed pays 81.

Getting started

  1. Check the economics first: one hotkey takes 95%, Sandbox pays live grading only and scores decay 0.05 per allocation.
  2. Prepare the GPU and a Hugging Face token; run scripts/miner/setup.sh, open port 8091, start neurons/miner.py --netuid 54 under pm2.
  3. Vary models, prompts, accessories and backgrounds: near-identical images are penalised.
  4. For voice, implement generate_voice_clone (MIID/miner/voice_generator.py), called once per clip with a style and noise level.

Caveats

  • Scoring, review and the liveness check run on team servers; chain weights are not payouts.
  • UID 14 has an unknown controller: it is swept daily near 14:00 UTC, sets no weights and has a permit only above about 1,100 alpha; the team denies self-mining. The owner's 85% of dividends is unexplained.
  • Revenue and client figures are second-hand from the owner's 10-30 update, not tied to the subnet.
