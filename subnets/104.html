What it is

TAOstatus (SN104) pays miners on two tracks: lending LLM API keys, or submitting security-testing agents that a marketplace sells per audit. On chain, nearly all miner incentive sits on one unexplained UID; the team calls this bootstrapping.

How it works

Miners

Two tracks, each needing its own hotkey. Security: submit one agent.py (a Docker image also works) that finds and proves web flaws; agents scoring 0.8 or more can be listed on the marketplace. LLM keys: hand over 5 distinct API keys, encrypted, for the team's platform.

Validators

Security: runs each agent in an offline sandbox against a random flaw class (SQL injection, command injection, file inclusion, IDOR, SSRF) and replays the exploit. LLM keys: relays keys to the team's closed backend and scores reliability, speed and volume.

Incentive

Emission splits 5% to the LLM-key track and 95% to security. The code's default sends 100% of validator weight to a burn slot (UID 25). The team says weights should follow confirmed paid audits; that switch is off by default and the deployed settings are private.

Roles and requirements

Miner (security agents) Low barrier

Writes an agent that finds and proves web flaws; listed agents are sold per audit.

  • Run neurons/security_miner.py with MASXAI_SECURITY_AGENT_SCRIPT set to your agent.py; it serves an encrypted copy.
  • Listing bar: score 0.8 or more; hardcoding or endpoint spraying scores 0 (team, 2026-10-28).

Miner (LLM keys) Low barrier

Lends 5 distinct LLM API keys, encrypted, for the team's platform.

  • Scored on reliability 50%, speed 25%, volume 25%; the track gets 5% of emission; the verifying backend is closed.

Validator High barrier

Sets weights per track; the LLM-key track needs a team-issued token.

  • 16 hotkeys hold permits; 8 have weight rows and 2 updated within 72 minutes (2026-10-30).

Where the rewards go

  • UID 11 (registered 2026-10-23) holds 100% of LLM-key and 99.6% of security incentive; it never set weights and is not owner-linked.
  • UID 25 (owner-linked validator) holds 0% incentive but 49.95% of emission as dividends, and weights UID 11 almost entirely.
  • UID 51, which the team calls its reference miner, gets the other 0.4% of security incentive.
  • Recycle events hit the subnet on 2026-10-24 (2,348 alpha) and about 2026-10-28 (6,000 alpha); the sender is not known.

Getting started

  1. Register a hotkey on netuid 104 (0.5 TAO on 2026-10-30), one per track.
  2. Security: write agent.py with an agent_main(ctx) entry point (reference: ref_agent.py in the repo).
  3. Set MASXAI_SECURITY_AGENT_SCRIPT and run neurons/security_miner.py with a public IP and open port.
  4. LLM keys: set 5 distinct keys in MASXAI_LLM_KEYS_JSON and run neurons/miner.py (MINER.md).
  5. Check who holds incentive on the metagraph and ask in the channel before spending money.

Caveats
