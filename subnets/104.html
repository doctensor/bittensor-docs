What it is

TAOstatus (SN104) pays miners on two tracks: lending LLM API keys, or submitting security-testing agents that a marketplace sells per audit. On chain, nearly all miner incentive sits on one unexplained UID; the team calls this bootstrapping.

How it works

Miners

Two tracks, each needing its own hotkey. Security: submit one agent.py (a Docker image also works) that finds and proves web flaws; agents scoring 0.8 or more can be listed on the marketplace. LLM keys: hand over 5 distinct API keys, encrypted, for the team's platform.

Validators

Security: runs each agent in an offline sandbox against a random flaw class and replays the exploit. LLM keys: relays keys to the team's closed backend and scores reliability, speed and volume.

Incentive

Emission splits 5% to the LLM-key track and 95% to security.

Roles and requirements

Miner (security agents) Low barrier

Writes an agent that finds and proves web flaws; listed agents are sold per audit.

  • Run neurons/security_miner.py with MASXAI_SECURITY_AGENT_SCRIPT set to your agent.py; it serves an encrypted copy.
  • Listing bar: an average of 0.8 over all five flaw classes (one class alone caps at 0.2); hardcoding or endpoint spraying scores 0 (team, 2026-10-28).

Miner (LLM keys) Low barrier

Lends 5 distinct LLM API keys, encrypted, for the team's platform.

  • Scored on reliability 50%, speed 25%, volume 25%; the track gets 5% of emission; the verifying backend is closed.

Validator High barrier

Sets weights per track; the LLM-key track needs a team-issued token.

  • 16 hotkeys hold permits; 8 have LLM-key weight rows and 11 security rows (2026-11-13).

Where the rewards go

  • UID 11 (registered 2026-10-23) holds 100% of LLM-key and 99.57% of security incentive; it never set weights and is not owner-linked.
  • UID 25 (owner-linked validator) holds 0% incentive but about 50% of emission as dividends, and weights UID 11 almost entirely.
  • UIDs 47 and 7 earn nothing; the owner's validator dropped them on 11-05, weighted each about 0.2% on 11-11 and dropped them again by 11-13. UID 51, the team's reference miner, has 0.35% of security weight and earned 0.43% on most reads, 0.0% on 11-05.
  • Alpha was recycled on 2026-10-24 (2,348), about 10-28 (6,000), 2026-11-02 (13,800), 2026-11-06 (13,700) and 2026-11-11 (14,800); the last three match UID 11 stake drops; its stake is about 5,200 and regrowing.

How security scoring works

  • Each round tests one random flaw class (SQL injection, command injection, file inclusion, IDOR or SSRF). A run scores 0.5 for the planted secret, 0.8 if the exploit replays, 1.0 for the exact endpoint, up to 40% less for over 1,000 requests.
  • A miner's score is the average over all five classes; a class not retested for 2 hours counts as 0. Scoring on confirmed paid audits instead is off by default.

Getting started

  1. Register a hotkey on netuid 104 (0.5 TAO on 2026-11-13), one per track.
  2. Security: write agent.py with an agent_main(ctx) entry point (reference: ref_agent.py in the repo).
  3. Set MASXAI_SECURITY_AGENT_SCRIPT and run neurons/security_miner.py with a public IP and open port.
  4. LLM keys: set 5 distinct keys in MASXAI_LLM_KEYS_JSON and run neurons/miner.py (MINER.md).
  5. Check who holds incentive on the metagraph before spending money.
