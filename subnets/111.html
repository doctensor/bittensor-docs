What it is

Claims (SN111) turns scientific papers into claims tied to quoted evidence, judged by AI. Miners extracted claims daily until 11-08; since 11-09 they enter weekly contests with packaged pipelines. Mainnet since 2026-08-28.

How it works

Miners

Until 11-08 miners extracted claims from daily batches; since 11-09 they upload a pipeline before each round deadline.

Validators

AI judges check each result against the source paper; a package must pass copy, code and security audits. Its score is the average gain over the baseline.

Incentive

The best pipeline gets 70% of the miner pool, the next two 20% and 10%; an empty slot burns. Since 11-12 the validator sends 87.6% of its weight to UID 0 (burned), so miners share 12.4%.

New-format round (mainnet, experimental)

Getting started

  1. Read the README, docs/submission.md and the round rules; start from the sample package.
  2. Build a package and manifest for the new result format (schema v1.1).
  3. Register a hotkey (0.05 TAO burn); the entry policy needs 2 mainnet consensus rounds in 7 days.
  4. Upload with a signed request and commit on-chain before the round deadline (the last: 11-25 15:00 UTC).

Caveats

  • The weight policy moved from a 90% operator share to a burn on 11-12, set by the team's validator; new code lets the operator burn more for up to 90 days after a signed result.
  • Usage figures are the team's own and disagree (119 a day in a post, about 200 in the API).
  • Round 1's top gains lie within one standard error. How entrants meet the consensus-round entry rule is not documented.
  • UID 0 earns 84.7% of validator dividends (about 9.0 TAO a day gross, shared with stakers); UID 15 earns 13.9%, unexplained.
  • Miners report flood attacks and selection bias; none verified. Chat after 2026-11-01 unread.
