What it is

Refinery (SN125) pays for research that helps open language models train better. Challenge 1 asks for optimizers with a lower validation loss than the best so far; Challenge 2 (open since 2026-10-19) asks for a refiner that decides what a fixed model learns from.

How it works

Miners

Miners write an optimizer or refiner in Python, test it on their own compute and prepay evaluation credits. A commit with no credit is rejected.

Validators

The team validator trains each submission on one rented B200 for up to 20 hours. Optimizers are scored on held-out loss, refiners on a benchmark suite; a winner needs a confirming second run.

Incentive

Miners get 41% of emission, half per challenge. A confirmed gain earns credit that halves every 14 days; a pool pays only as far as credit covers a reference level that rises for 56 days. The unpaid share goes to uid 0 (owner slot), which burns it.

Roles and requirements

Miner Medium barrier

Writes an optimizer or refiner, serves its source, prepays an evaluation credit and reveals the code when asked.

  • Fee = estimated cost of one full run plus 10%, priced against a TAO/USD reference (docs: $250 default). A credit returns only for validator-side failures.
  • Commit the hash of one Python file (under 1 MB), then reveal it. Only validator uid 203 can query your source server.
  • A new best must beat the frontier by the bar (0.03 nats; 0.02 suite points for refiners) and pass a second run. You license the operator to publish your source, credited to your hotkey.

Validator High barrier

Trains and scores submissions and sets weights; only the team's validator (UID 203) may query miners.

  • 12 permit holders, 11 set weights within one tempo; how the 10 outside ones get their vector is undocumented.

Getting started

  1. Use Linux and Python 3.12, install the repo requirements, read MINING.md and start from the optimizer or refiner template.
  2. Verify the fee, treasury and validator in the signed round announcement before sending funds.
  3. Register a hotkey, open a public port, fund credits, then commit and reveal your source.

Caveats

  • Dashboard figures are team-published; the latest burn (51%) matches the chain exactly.
  • The refiner suite is a placeholder by its own spec and the held-out loss gate is off: all 14 results are worse than baseline on held-out loss (2.86 to 3.24 vs 2.59). The review rule is not retroactive.
  • The team says it runs no miner (2026-09-16); the chain fits but cannot prove it.
  • The six-week review (about 2026-10-20) has no recorded outcome; a pause would be an explicit decision (schedule page).
  • The fee is priced in dollars against a TAO price the repo fixes at $250 (file dated 2026-09-06); the live setting is unseen.
