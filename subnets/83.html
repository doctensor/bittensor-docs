What it is

CliqueAI asks miners to find large cliques (groups of mutually linked vertices) in random graphs of about 300 to 900 vertices. Validators fetch each graph from a team-run service, query random miners within 6 to 30 seconds and score validity, size and uniqueness. The code is public; the graph supply is closed.

How it works

Miners

Run a server that returns a clique for each graph it receives. The reference miner uses a NetworkX solver, with an optional graph-neural-network solver. Since April 2026 every eligible miner has equal odds of being queried; stake no longer matters.

Validators

Per round a validator picks one of four graph sizes, fetches a graph from the team's service, relabels it and queries random miners. An answer counts only if it is a clique that cannot be extended. Score = size score times (1 + difficulty) plus uniqueness (1 divided by the number of identical answers); ratings are a slow moving average.

Incentive

Ratings go through a sigmoid and a power curve so the top half of miners hold about 80% of the weight; validator code sends nothing to UID 0. Emission splits 41% miners, 41% validators and stakers, 18% owner.

Roles and requirements

  • Invalid or extendable cliques score 0; identical answers share the uniqueness score.

Validator High barrier

Fetches graphs from the team's service, queries miners and sets weights.

  • Each validator returns saved ratings only to a request signed by the owner.

Who earns the rewards

  • Per uid the split looks wide: 241 uids earn, the top one 1.4%.
  • By coldkey on 2026-11-14: six hold 232 uids and 99.95% of incentive; 24 others hold 0.05%.
  • No validator permit sits in these groups. The top uid kept moving: 30 (2026-11-05), 20 (11-06), 14 (11-07, 11-08), 26 (11-09), 2 (11-11), 61 (11-13), 117 (11-14).
  • Thirty-five sampled uids, in all six groups, registered 2026-08-13 to 09-03; none has weights or a permit.
  • Stake is concentrated: the owner coldkey holds 30.2% of staked alpha, the top five 71.0%; none of the six earning coldkeys is in the top ten (2026-11-14).
  • The chain cannot show who controls a coldkey. Members allege one operator does; the team denies it (2026-09-26).

Getting started

  1. Clone the repo and read docs/mechanism.md; it lags the code, and the website lags further.
  2. Start a miner with ./start_miner.sh: wallet, hotkey, --netuid 83, --subtensor.network finney, public axon IP and port.
  3. Replace the default NetworkX solver in miner.py; test_algorithm.py is a local check.
  4. Validators: ./start_validator.sh; it must reach the team's graph service and hold 1,000 TAO of permit stake.
  5. If v0.0.18 merges, miners must serve the new sealed-graph request; check the repo before registering.
