What it is

VoiceGuard is a Bittensor subnet project by the Cazure team that aimed to detect AI-generated voices, clone voices to build training data for detectors, and offer speech-to-text. The repository describes three kinds of miner work (transcription, voice cloning, deepfake detection) scored by validators with Whisper, speaker-similarity and audio-quality models. The project had an earlier mainnet slot (SN44) that its investor dissolved in August 2024; this page covers the 2024-2025 rebuild, whose netuid 253 is a testnet slot. Nothing indicates it ran on mainnet.

How it works

Miners

Per the README, miners answer three request types: transcribe a segment of a YouTube video (with a Whisper large model), clone a voice from a reference clip and a text, and say whether an audio clip is real or AI-generated. The repository ships a Whisper transcription path, a YourTTS-based cloning path and a detection path that runs an audio-classification model and returns a probability. The detection model folder is not in the repo; the download script fetches it, together with datasets, partly from a team-run server whose address is hard-coded in the script. The README asks for Python 3.10 or newer, a dedicated GPU with 16 GB or more and a fast network link.

Validators

For cloning, the validator picks a sentence and a reference clip from a Common Voice dataset, transcribes the miner's audio with Whisper, gives zero if the text match is below 0.8, and otherwise scores 0.5 speaker-embedding similarity, 0.25 mean-pitch similarity and 0.25 a MOSNet quality score. For detection it asks about real or fake audio from a team-run server and multiplies correctness, the miner's confidence, and batch accuracy and F1. For transcription it scores 0.7 text correctness (word overlap, semantic similarity, edit distance, BLEU) and 0.3 speed. Each type is kept as a moving average (default weight 0.1 on the newest result).

Incentive

Validators combine the three scores as 20 percent transcription, 40 percent cloning and 40 percent detection, and set any miner's score to zero when its transcription score is zero. As committed on 2025-01-23, the validator loop queries only one hard-coded UID, its transcription branch can never run and its detection branch is never reached, so only cloning is queried and the combine step would zero every miner. That looks like a debug state and was not run. On the testnet, no UID holds incentive or dividends as of 2026-10-21. Chain weights beyond that count were not read.

Getting started

  1. Install Bittensor, clone Cazure8/voiceguard-subnet, then run pip install -r requirements.txt and pip install -e . (use Python 3.10.x and pip install TTS if you want the bundled cloning model).
  2. Run python3 voiceguard/utils/download.py to fetch datasets and the detection model. Part of the data comes from a team-run server hard-coded in the script; whether it is still up was not tested.
  3. Optionally set a proxy URL in a .env file to avoid YouTube rate limits on transcription tasks.
  4. Create a testnet wallet, get test TAO and register a hotkey on testnet netuid 253 (the registration burn was 0.0005 test TAO when read on 2026-10-21).
  5. Start the miner with neurons/miner.py, passing --netuid 253 --subtensor.network test and your wallet, axon IP and port. The README's miner example omits the network flag and its validator example still uses netuid 44, so set both yourself.

Caveats

  • Testnet only. Nothing here describes mainnet participation, emissions or token economics; mainnet has no netuid 253 (chain read 2026-10-21) and no mainnet registration plan has been stated since 2025-04-23.
  • On the testnet (read 2026-10-21), the subnet has 14 neurons, 7 validator permits, no UID with incentive or dividends, and the freshest weight-setting among its validators was more than 1.5 million blocks old, roughly 215 days at about 12 seconds per block. No evidence of a working miner or validator was found.
  • Who owns testnet 253 was not checked and the subnet has no on-chain name. The link to the VoiceGuard team rests on the README roadmap (testnet UID 253), the channel name and the registration date matching the team's launch post.
  • README and code disagree: the README says validators send three request types and pay 20/40/40, while the last committed validator loop only queries cloning, on a single UID. The detection reward function is also called with a parameter name it does not accept, and a code comment and the reward disagree on whether a probability above 0.5 means fake or real. None of this was run.
  • The README's status link and validator example point at netuid 44, the team's earlier mainnet slot that was dissolved in August 2024.
  • The datasets, detection model and test audio depend on a team-run server addressed by a hard-coded IP in the code. The team's Miner Hubs site (taoscribe.ai) did not resolve from the research machine on 2026-10-21.
  • The whitepaper and the Q2-Q3 2025 roadmap items (more audio hours, Chrome extension, iOS app, film industry partner, real-time API) were not verified.
  • The channel archive also holds older discussion of the team's earlier subnets; treat anything dated before December 2024 as history of a different codebase.
