What it is

Miners train sparse autoencoders (SAEs), tools that read a model's internal activations, for one pinned model, OLMo-2 7B layer 16. An evaluator scores how much accuracy each SAE keeps; the champion takes the reward.

How it works

Miners

Miners train an SAE (32,768 features) on their own GPUs and run the miner service on a Linux machine with a public IPv4 address. Each evaluation costs 10 work tokens (WT), bought with SN37 alpha at 1 WT per alpha.

Validators

The chain allows one validator permit (cut from 64 on 2026-10-10). Its evaluator splices each SAE into the model and measures the loss recovered; its code is not public.

Incentive

Config v36 (11-07) sets burn to 0 and splits rewards into three lanes: this competition 30%, two test lanes 35% each; on chain the test lanes' 70% goes to UID 204, which the config names. The champion's share of its 30% scales with its SN37 alpha (about 16% at 100 alpha, 95% at 10,000); the rest is burned. A challenger must beat the champion by 0.003, or a quarter of the gap if larger. Payout needs a paid result under 12 hours old.

Roles and requirements

Miner Medium barrier

Train an SAE for the pinned model and submit it; only the champion earns.

  • Pay: the champion (UID 243) makes about 1.69 TAO a day (gross, 2026-11-07); UID 204 gets 5.39 from the test lanes.
  • Docs (11-04): staying eligible costs 10 WT per 12 hours, about 20 alpha a day, against about 650 earned.
  • A failed run still costs 10 WT unless the failure is infrastructure (refund-eligible).

Validator High barrier

Run the evaluator and set weights. Closed in practice: one permit, evaluator code not public.

  • The one permit is under the owner's coldkey; its hotkey holds 65% of alpha (owner 26 points, rest delegated; 2026-11-07).

Getting started

  1. Read INCENTIVES.md and lanes/lane1.md; the miner asks you to confirm them.
  2. Use a Linux server with a public IPv4 address; register a hotkey on subnet 37 (burn 0.0005 TAO) and hold alpha.
  3. Install per the README, make a hotkey-only wallet copy, fill in .env and run aurelius-miner serve --netuid 37 --port 8091.
  4. Buy WT with aurelius-miner fund (preview, then --execute); check the runtime pin first.
  5. Train an SAE with SAE-Lens 6.46.0, check it with aurelius-sae check, then upload and track it with aurelius-sae status.

Caveats

  • The docs call the rules an open beta; the signed config is authoritative and rewards may be adjusted retroactively.
  • Chain weights are one validator's opinions, not payouts. The champion's identity and score are not public.
  • Why UID 204 gets 70% (not owner-linked on chain, yet named in the config) and why the throne moved is not public; docs omit the new lanes.
  • A stake-retention mechanism is built but disabled and unpublished.
  • Chat after 2026-10-31 unreadable on 2026-11-07; team reply unchecked.
