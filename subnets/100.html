What it is

Cortex calls itself an autonomous research network: the team runs the challenges and a gateway that seals each epoch's scores, and validators submit them. Bounty rewards bug reports; HyperTrain is a research-stage attempt at verifiable shared training. Formerly Platform, then BASE.

How it works

Miners

Bounty miners file reproducible bug reports; HyperTrain miners train in rounds while other nodes replay samples to audit them.

Validators

Validators download the gateway's sealed vector, verify it against the chain, recompute the weights and submit them.

Incentive

Bounty pays one point per report the team marks valid, cumulatively. HyperTrain rewards would vest over about ten rounds.

Why nothing is paid

  • Chain split: 18% owner, 41% validators, 41% miners (2026-11-14). The miner share lands on uid 0, the owner's own hotkey, and is burned. That uid holds 50.0% of emission (72.3% on 2026-11-08): its validator has set no weights since 2026-11-08 08:50 UTC, passed the 5,000-block activity cutoff and lost its dividends.
  • A challenge that fails, is not on the team's container list or has no open topic gets no score and its share burns to uid 0; on 2026-11-14 all three answered empty.
  • Bounty must load its feed within 120 s; 21,000 reports took 37 s (2026-10-16), so 131,305 (11-07) would need about 4 minutes: arithmetic, not a statement.

Where the code work is

  • The unmerged v3 branch took about 810 commits 2026-10-26 to 10-31, none since. Team drafts ADR 0017 and 0018 propose one HyperTrain code change (finalize, lock, audit schedule); the proof so far is 31M-parameter TEST runs. v3 touches nothing in src/cortex, config or deploy: by code, a merge changes neither the roles nor who is paid.

Getting started

  1. Bounty: install the cortex CLI (Python 3.12+, uv, libsodium), register a hotkey, and ask the team to authorise pairing with a dedicated Cortex Chat account.
  2. HyperTrain: needs an RTX 5090; run the self-check, join, then send the signed request to the operator.
  3. Validators: run scripts/run-validator.sh with --verify-only first, then with a registered wallet.

Caveats

  • The burn's cause is unconfirmed: explanations come from public code and arithmetic, and the live setup's code branch is unknown.
  • Bounty counts are the team's own (last read 2026-11-07; board unreachable since 2026-11-08), reviewed with an AI agent; none published since 2026-10-21 was marked duplicate or invalid, unexplained.
