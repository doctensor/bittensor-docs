What it is

Cortex calls itself an autonomous research network: the team runs the challenges and a gateway that seals each epoch's scores, and validators submit them. Bounty rewards bug reports; HyperTrain is a research-stage attempt at verifiable shared training. Formerly Platform, then BASE.

How it works

Miners

Bounty miners file reproducible bug reports; HyperTrain miners train in rounds while other nodes replay samples to audit them.

Validators

Validators download the gateway's sealed vector, verify it against the chain, recompute the weights and submit them.

Incentive

Bounty pays one point per report the team marks valid, cumulatively. HyperTrain rewards would vest over about ten rounds.

Why nothing is paid

  • Chain split: 18% owner, 41% validators, 41% miners (2026-11-06). The miner share lands on uid 0, the owner's own hotkey, and is burned. That uid holds 73.9% of emission (50.4% on 2026-11-03): its validator dividends returned when it set weights again on 2026-11-03. Until about 2026-10-19 it held about 70%.
  • A challenge that fails, is not on the team's container list or has no open topic gets no score and its share burns to uid 0; on 2026-11-06 all three answered empty.
  • Bounty must load its feed within 120 s; 21,000 reports took 37 s (2026-10-16), so 131,229 would need about 4 minutes: arithmetic that fits the stuck status, not a team statement.

Where the code work is

  • The unmerged v3 branch took about 810 commits 2026-10-26 to 10-31, none since. Getting started

  1. Bounty: install the cortex CLI (Python 3.12+, uv, libsodium), register a hotkey, and ask the team to authorise pairing with a dedicated Cortex Chat account.
  2. HyperTrain: needs an RTX 5090; run the self-check, join, then send the signed request to the operator.
  3. Validators: run scripts/run-validator.sh with --verify-only first, then with a registered wallet.

Caveats

  • The burn's cause is unconfirmed: explanations come from public code and arithmetic, and the live setup's code branch is unknown.
  • Bounty counts are the team's own, reviewed by operators with an AI agent; no report published since 2026-10-21 was marked duplicate or invalid, which this page cannot explain.
  • Validators are told to read their profile from /v1/trust; both public hosts answer 404 (2026-11-06).
  • Not researched: product and partnership claims; chat after 2026-11-01 (archive down); no bounty report independently verified.
