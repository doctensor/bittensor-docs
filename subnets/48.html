What it is

Quantum Compute (SN48), run by qBitTensor Labs, is the job side of Open Quantum, a platform where users run circuits on real quantum processors (IonQ, Rigetti, IQM, AQT) and pay in dollars. Miners submit the jobs and earn alpha. Usage and savings figures are the team's own.

How it works

Miners

Version 1 miners had to own or operate a quantum processor. The 2.0 code sends each circuit through a provider adapter (only Open Quantum exists), whose organization account pays per job; nothing checks QPU access. A miner needs 5,000 alpha staked, a public address and credits.

Validators

A validator pulls jobs from the Open Quantum API, sends each to an eligible miner, bans miners whose lease expires or proofs fail, and sets weights from a frozen platform snapshot, not from chain data.

Incentive

The snapshot gives each miner's job cost; a miner is owed cost times a markup (code fallback 1.2). If the total fits the miner emission, weights follow cost share, so miners get the whole emission, not only what is owed; otherwise rank order pays until it runs out.

Getting started

  1. Ask the team first: the site says mining needs a quantum computer, the guide says coming soon.
  2. Miner (2.0 code): Python 3.12, SDK v11, a hotkey on netuid 48, 5,000 alpha staked, a public axon, PROVIDER=openquantum with an organization id and SDK key, credits above 50.
  3. Validator: ask the team to onboard the hotkey, then run neurons/validator.py with the axon off.

Caveats

  • Who controls the miners' coldkey and the owner's is not shown; the team says it runs the miners and pays compute in dollars (unverified).
  • Weights come from a snapshot behind a closed API, so costs, prices and the markup cannot be rechecked.
  • Weights are opinions, not payouts; which validators run the 2.0 code is unknown.
  • Open mining is unconfirmed: at the last full check (2026-10-26) no uid had registered since about 2026-10-09.
  • Usage, growth, traffic share and buybacks are team statements; docs list five processors, the team's report six systems.
