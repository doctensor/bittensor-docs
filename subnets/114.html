What it is

SOMA, built by the company Dendrite, pays miners for compressors that shrink the context a coding agent re-sends to its model without breaking its tasks. Entries are scored against an uncompressed baseline in two-week rounds. The team adapts winning code for its paid app; winning code stays private.

How it works

Miners

A miner writes a Python compressor and uploads it with a signing script and an OpenRouter key, which pays for the grading runs. Code must not be obfuscated and stays private. Each 14-day round has 7 days of uploads with a public-task screen (stage 1), then 7 days of hidden tasks (stage 2) and full evaluation. Round 12 grades on openai/gpt-6-luna; round 13 (uploads 2026-11-03 to 2026-11-10) switches to Claude Code with Claude Haiku 5.5 on Azure.

Validators

Validators grade runs in Docker and set weights, but do not compute them: they fetch the weights from the SOMA platform (all weight goes to burn UID 0 if it is down and nothing is cached). The team reviews top code by hand and flags winners as approved; only approved winners count.

Incentive

Each task scores quality against the baseline plus the log of weighted-token savings. Seven contests by task-size group share the prize, the all-groups one taking 25%. Stage 1 drops entries that lose over 0.05 of success or use more tokens than baseline (code defaults); the top 20% of passers, at least 60, reach full evaluation. Winners are paid in the next round. Emission is 18% owner, 41% validators, 41% miners; no burn since 2026-06-23.

Getting started

  1. Register a hotkey on netuid 114 (0.25 TAO); read the miner docs and prompting rules: breaking them fails review.
  2. Run tasks locally with SOMA-benchmark's base miner (Docker, OpenRouter key); don't copy the OpenClaw compressor unchanged.
  3. Take model settings from the Discord round post; the written guide lags.
  4. Upload in the round 13 window, 2026-11-03 14:30 to 2026-11-10 14:30 UTC.

Caveats

  • Trust: weights come from the team's platform, winners need a team-set approval and winning code is private. Self-mining accusations are unproven.
  • Docs lag the rules: the run-logs endpoint is undocumented, live stage 1 settings are not public and the repo has nothing yet on round 13's harness.
  • Stage 1 is contested: 101 of 199 round 12 entries failed it. Miners say it punishes extra agent turns; the team says it drops entries that cost more or lose quality.
  • Round 11 review figures differ: the dashboard lists 22 failed reviews against the team's 14; the ten highest scores belong to failed entries.
