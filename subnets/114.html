What it is

SOMA, built by the company Dendrite, pays miners for compressors that shrink the context a coding agent re-sends to its model without breaking its tasks.

How it works

Miners

A miner writes a Python compressor and uploads it with a signing script and an OpenRouter key, which pays for the grading runs. Code must not be obfuscated. Each round has about 7 days of uploads with a public-task screen (stage 1), then about 7 days of hidden tasks (stage 2) and full evaluation. Round 14 runs 2026-11-17 to 12-01 (settings not read); round 13 used Claude Code with Haiku 5.5 on Azure (the code default).

Validators

Validators grade runs in Docker and set weights, but do not compute them: they fetch the weights from the SOMA platform. The team reviews top code by hand and flags winners as approved; only approved winners count.

Incentive

Each task scores quality against the baseline plus the log of weighted-token savings. Seven contests share the prize: all sizes 25%, each pair of sizes 15%, each single size 10%. Stage 1 drops entries that lose over 0.05 of success or use more tokens than baseline; the code default sends the top 20% of passers (at least 60) to full evaluation, but round 13 scored 240 and failed six in review. Winners are paid in the next round (round 13 since 2026-11-17). Many other entries get a small fixed weight (value not public): 62 uids earn now (240 until 11-17); the 57 outside the top five hold 0.1%. Pay to uids still splits miners and validators evenly, despite the 2026-11-09 split change.

Getting started

  1. Register a hotkey on netuid 114 (at least 0.5 TAO); read the miner docs and the prompting rules (rewritten 11-17): breaking them fails review.
  2. Run tasks locally with SOMA-benchmark's base miner (Docker, OpenRouter key); its Claude Code backend is on main. Don't copy the OpenClaw compressor unchanged.
  3. Take model settings from the Discord round post; the written guide lags.
  4. Round 14 uploads close 2026-11-24 14:30 UTC and evaluation runs to 12-01.

Caveats

  • Trust: weights come from the team's platform and winning code is private; self-mining accusations are unproven.
  • Docs lag the rules: the run-logs endpoint is undocumented and live stage 1 settings are not public.
  • Stage 1 is contested: 134 of 199 round 12 entries ended Not Qualified, 10 of 259 in round 13. Miners say it punishes extra agent turns; the team says it drops costlier or worse entries.
  • Review decides winners: the ten top round 11 scores failed review, as did four of the five highest in round 12 and the top three in round 13.
