What it is

SOMA, built by the company Dendrite, pays miners for compressors that shrink the context a coding agent re-sends to its model without breaking its tasks. The team adapts winning code for its paid app; winning code stays private.

How it works

Miners

A miner writes a Python compressor and uploads it with a signing script and an OpenRouter key, which pays for the grading runs. Code must not be obfuscated and stays private. Each 14-day round has 7 days of uploads with a public-task screen (stage 1), then 7 days of hidden tasks (stage 2) and full evaluation. Round 13 (uploads 2026-11-03 to 11-11, evaluation to 11-17) uses Claude Code with Haiku 5.5 on Azure (the code default).

Validators

Validators grade runs in Docker and set weights, but do not compute them: they fetch the weights from the SOMA platform (all weight goes to burn UID 0 if it is down and nothing is cached). The team reviews top code by hand and flags winners as approved; only approved winners count.

Incentive

Each task scores quality against the baseline plus the log of weighted-token savings. Seven contests share the prize: all sizes 25%, each pair of sizes 15%, each single size 10%. Stage 1 drops entries that lose over 0.05 of success or use more tokens than baseline (code defaults); the top 20% of passers, at least 60, reach full evaluation. Winners are paid in the next round. Qualifying entries also get a small fixed weight (value not public): 242 uids earn, as many as the dashboard then listed as qualifying, and the 238 outside the top four hold 0.4% together. Pay to uids still splits miners and validators evenly, despite the 2026-11-09 split change. Contest burn ratio: 0% since 2026-06-23.

Getting started

  1. Register a hotkey on netuid 114 (0.25 TAO); read the miner docs and prompting rules: breaking them fails review.
  2. Run tasks locally with SOMA-benchmark's base miner (Docker, OpenRouter key); its Claude Code backend is on main. Don't copy the OpenClaw compressor unchanged.
  3. Take model settings from the Discord round post; the written guide lags.
  4. Round 13 uploads closed 2026-11-11 14:30 UTC; evaluation runs to 11-17. Round 14 was not listed on 2026-11-12.

Caveats

  • Trust: weights come from the team's platform, winners need a team-set approval and winning code is private. Self-mining accusations are unproven.
  • Docs lag the rules: the run-logs endpoint is undocumented and live stage 1 settings are not public.
  • Stage 1 is contested: 134 of 199 round 12 entries ended Not Qualified. Miners say it punishes extra agent turns; the team says it drops costlier or worse entries.
  • Review decides winners: the ten top round 11 scores failed review, as did four of the five highest in round 12; the top valid score is 0.088.
