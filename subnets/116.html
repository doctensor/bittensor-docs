What it is

Run by Carbon Physics, Inc. Researchers and AI agents compete to design fast models that stand in for slow physics simulations; validators rebuild and test each design. Live since 2026-10-04; mining happens on a test network for now.

How it works

Miners

Miners submit a reproducible recipe (backbone, training steps, settings, seeds, compute budget), not trained weights. They practise on public cases; scoring uses hidden exam cases. Carbon offers a local app, data kits, a research agent (Graphite) and MCP.

Validators

A validator rebuilds the recipe on its own data in an offline worker, then runs mandatory physics checks (conservation, boundaries, stability); failing one voids the result. Public score code weights physics, robustness and accuracy as a geometric mean. The owner says half the score is 'design value', which is not public.

Incentive

No miner is paid today: emission splits 18% owner, 41% validators, 41% miners, but the miner share burns and all four permit-holding validators give 100% of weight to uid 0 (2026-11-07). The design pays a challenge's winner in full for 24 hours, then halves it daily, burning the rest; no mainnet policy is public.

Roles and requirements

Miner Medium barrier

Designs a training recipe for a challenge; practice is free, graded on hidden exam cases. Nothing paid yet.

  • Docs: the install stops below about 28 GiB of memory; a 16 GB machine cannot run practice.
  • A recipe is submitted, not weights: no starting weights; fitted constants must fit 32 KiB (docs, 2026-11-02).
  • Known issue (2026-10-30): a Cooling recipe using prior_krr is refused; start with MeshGraphNet.
  • New 2026-11-03: Motor and Cooling data kits make practice data locally with Docker (Motor 12-24 min a case, Cooling 0.5-1 core-hour).
  • Docs (2026-11-04): run a tested backbone first as the baseline for your own recipe.

Validator Barrier unknown

Rebuilds candidates, runs the exam and sets weights. All four permit holders weight only the owner's uid 0, yet dividends reach a general validator.

  • Dividends (2026-11-07): owner uid 64%, uid 1 35%, uids 34 and 11 about 1% together; uids 1 and 34 were general multi-subnet validators on 2026-10-24.
  • Repo code publishes winner weights through an owner-run publisher, at most once per 72-minute epoch.

Getting started

  1. Mining is not paid; you can practise for free, no wallet needed.
  2. Use Ubuntu 22.04 or 24.04 (or WSL2) with 32 GB RAM and Docker.
  3. Run the installer: ~/carbon/scripts/install_miner.sh --pytorch --service; it opens the Control Center.
  4. To submit, register a hotkey on subnet 567 (free test TAO from the faucet).
  5. Watch #116 for the mainnet date.
