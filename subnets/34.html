What it is

BitMind ran SN34 as a detector-versus-generator contest for AI-made media. Since 2026-10-22 it is Yugos: miners train a router that picks the provider, model and effort for each request, scored on quality, cost and time by a benchmark the team hosts. The team also sells routing as an API at yugos.ai.

How it works

Miners

A miner submits a trained router (model.py, model.safetensors, models.json). It returns one model choice per turn, which must come from the trained weights; keyword rules, lookup tables and prompt edits are banned. A compliance review and a private wording check run before grading. A hotkey may submit 3 new ZIPs per 24 hours.

Validators

Validators fetch the team's signed result, check its hash and age, map champion hotkeys to UIDs and set weights. Grading, cost and time are measured in the team's hosted service.

Incentive

A challenger must beat the reigning champion on the same questions (chat 40%, math and code 35%, agentic 25%): net value (extra correct answers minus extra spend and time) must clear quality gates and a bound above 0.2. The champion gets 85%, the previous one 10%, the one before 5%; one hotkey can hold two seats.

Getting started

  1. Check the dashboard and team channel first: contest v0.3.0 is open (2026-11-12) and rules change fast.
  2. Install the yugos package (Python 3.11+); start from examples/starter-router and replace its fixed choice with weight-driven routing.
  3. Train the router (its choices must survive rewording), list every allowed provider and model in models.json, and test locally with your own keys.
  4. Register a hotkey on SN34 (0.5 TAO burn on 2026-11-12), then ycli pack and ycli submit; fund the run on the linked card page ($300 reserved).

Caveats

  • Grading, compliance and wording checks run in the team's closed service; validators do not re-grade.
  • Dashboard spend is what miners paid, not what they earn; weights are opinions, not payouts.
  • Support is thin: stuck runs and locked escrow were reported on 2026-10-28 to 2026-10-30.
  • #mind after 2026-11-01 was not read (archive down).
